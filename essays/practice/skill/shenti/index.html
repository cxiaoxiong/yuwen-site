审题与立意

找任务、抓关键词、判断材料关系、概括核心矛盾，写出一句切题的立意；再学会判断偏题和套题。

练完能拿到一道陌生的题，十分钟内读准任务，写出一句切题、聚焦的立意。

这一组的自查

每个训练有自己的自查；这几项是这一组都要问的。用语和第21课的交卷前检查表一致，不打分，只答“是”或“否”。

1

一道题走完审题五步

示范高考真题 · 2024年新课标Ⅰ卷
题面 · 2024年新课标Ⅰ卷 · 问题会越来越少吗

阅读下面的材料，根据要求写作。

随着互联网的普及、人工智能的应用，越来越多的问题能很快得到答案。那么，我们的问题是否会越来越少？

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

看一遍完整的审题流程：读材料 → 找核心 → 找关系 → 明任务 → 定立意。不写作文，只看每一步得到什么。

步骤 问自己 这道题得到的
读材料 几句？每句在做什么？ 两句。第一句陈述现象：问题能很快得到答案；第二句提出问题：我们的问题是否会越来越少？
找核心 哪个词必须写？ “问题”。“互联网”“人工智能”是背景，不是核心（第7课）。
找关系 核心之间什么关系？ “答案越来越容易得到”与“问题是否越来越少”：表面看是此消彼长，要追问是不是真的（第16课）。
明任务 要我做什么？ “引发了你怎样的联想和思考”：对这个问题表态并说理，不是介绍人工智能。
定立意 一句判断，切题吗？ 答案越容易得到，越需要会提出问题的人。

为什么不选别的立意

  • “人工智能改变生活”——只写了背景，没碰“问题”，偏题。
  • “问题会越来越少”——可以写，但要说清是哪一种问题变少；不分类就直接同意，等于把材料的问句当成了结论。
  • “我们要学会提问”——方向对，但没有回应材料里“答案越来越多”这个前提，扣题不紧。

关键一步在“找核心”：先给“问题”分类——能被检索、被回答的问题，会越来越快地得到答案；需要人自己提出、自己判断的问题，不会因此减少。分清了这一点，立意就有了支点（第15课）。

自查
  • 我能说出材料里哪一句是背景、哪一句是核心吗？做不好 → 高考题型与审题迁移
  • 我的立意回答了材料的问句吗？做不好 → 审题与立意

做不好，回哪一课高考题型与审题迁移审题与立意核心概念阐释

审题残缺是什么样子

示范高考真题 · 2026年全国一卷
题面 · 2026年全国一卷 · 你对哪一个词语的理解变了

阅读下面的材料，根据要求写作。

词语是表达思想情感的载体，也是展现社会生活变化的窗口。当前，世界之变、时代之变、历史之变正以前所未有的方式展开。青年是常为新的，在你的成长过程中，你对哪一个词语的理解发生了变化？这变化有你成长的印记，对你有特殊的意义……

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

看三种“沾了边却没审全”的开头，学会对照题目的几个要求逐项检查。

这道题的要求可以拆成三项：一个词语；对它的理解发生了变化；变化里有你成长的印记。《阅卷现场》汇编所附的这道题的阅卷总结，把“只抓住‘词语’或只抓住‘成长’”“单纯解释词语，没有个人成长轨迹”“只写成长故事，全程不围绕选定词语展开”列为审题残缺。下面三个开头是本站按这几种毛病拟写的：

开头甲： “坚持，是滴水穿石的毅力，是绳锯木断的恒心。古往今来，坚持成就了无数伟人……” ——只解释词义，没有“变化”，也没有“我”。三项只做到一项。

开头乙： “那年夏天，我第一次离开家去参加夏令营，在陌生的城市里……” ——只写成长故事，迟迟不出现那个词。如果全篇都不围绕一个词展开，就离题了。

开头丙： “小时候，我以为‘家’就是那套老房子；后来搬了三次家，我才明白，‘家’是有人等你的地方。” ——一个词（家），一个变化（从房子到等你的人），一个成长印记（搬家）。三项都在。

检查的办法：把题目的要求逐项列出来，在自己的开头里一项一项找。找不到的那一项，就是要补的（第1课）。

自查
  • 我把题目的要求逐项列出来了吗？做不好 → 审题与立意
  • 每一项在我的开头里都找得到吗？做不好 → 高考题型与审题迁移

做不好，回哪一课审题与立意核心概念阐释高考题型与审题迁移

转折句的重点在哪一半

支架基础高考真题 · 2023年全国甲卷
题面 · 2023年全国甲卷 · 时间的仆人

阅读下面的材料，根据要求写作。

人们因技术发展得以更好地掌控时间，但也有人因此成了时间的仆人。

这句话引发了你怎样的联想与思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

只读这一句材料：圈出转折词，分清前后两半各说什么，判断重点，写一句立意。

提示

按下面的空格填：

  1. 转折词是：
  2. 前半句说的是一个（事实 / 现象 / 观点），内容是：
  3. 后半句说的是一个，内容是：
  4. 重点在半句，因为
  5. 立意（一句判断）：
自查
  • 我的立意里有“仆人”这一层意思吗？做不好 → 高考题型与审题迁移
  • 我没有把立意写成“技术是把双刃剑”这样的套话吧？做不好 → 辩证分析
  • 我注意到后半句说的是“也有人”，不是“所有人”吗？做不好 → 概念辨析与条件边界
参考答案与解析
  1. 转折词：“但”。
  2. 前半句是事实：技术发展让人们更好地掌控时间。
  3. 后半句是现象：也有人因此成了时间的仆人。
  4. 重点在后半句。转折复句的重心通常在转折之后；而且“因此”说明，变成仆人的原因恰恰是让人掌控时间的技术（第19课的“看转折的重点”）。
  5. 立意示例：技术给了我们掌控时间的工具，能不能做时间的主人，要看我们怎样使用工具。

注意：写成“技术有利有弊”，就把重点放回了前半句和后半句的平均，等于没有读出转折。

做不好，回哪一课高考题型与审题迁移辩证分析

三个人物，一个主题词

支架进阶高考真题 · 2022年新高考Ⅱ卷
题面 · 2022年新高考Ⅱ卷 · 选择·创造·未来

阅读下面的材料，根据要求写作。

中国共产主义青年团成立100周年之际，中央广播电视总台推出微纪录片，介绍一组在不同行业奋发有为的人物。他们选择了自己热爱的行业，也选择了事业创新发展的方向，展示出开启未来的力量。

有位科学家强调，实现北斗导航系统服务于各行各业，“需要新方法、新思维、新知识”。她致力于科技攻关，还从事科普教育，培育青少年的科学素养。有位摄影家认为，“真正属于我们的东西，是民族的，血脉的，永不过时”。他选择了从民族传统中汲取养分，通过照片增强年轻人对中国文化的认同。有位建筑家主张，要改变“千城一面”的模式，必须赋予建筑以理想和精神。他一直努力建造“再过几代人仍然感觉美好”的建筑作品。

复兴中学团委将组织以“选择·创造·未来”为主题的征文活动，请结合以上材料写一篇文章，体现你的认识与思考。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

逐则概括材料里的三个人物，找出他们的共同点，再把共同点接到征文主题“选择·创造·未来”上。不写全文。

提示
  1. 每个人一句话，格式：“他/她选择了，创造了。”
  2. 三句放在一起，看共同点落在哪里（第6课的“逐则概括 → 比较”）。
  3. 再读任务：谁组织的？什么活动？主题词有几个？三个词之间是什么关系？
自查
  • 三个人物我都概括到了，没有只写一个吗？做不好 → 复杂材料审题与扣题
  • 主题词“选择”“创造”“未来”三个都在我的立意里吗？做不好 → 审题与立意
  • 我注意到这是给团委征文写的，读者是同学吗？做不好 → 审题与立意
参考答案与解析
  • 科学家：选择了科技攻关和科普教育，创造了“新方法、新思维、新知识”，还培养青少年的科学素养。
  • 摄影家：选择了从民族传统中汲取养分，创造了能增强文化认同的作品。
  • 建筑家：选择了改变“千城一面”，创造了“再过几代人仍然感觉美好”的建筑。

共同点：都选择了自己热爱、又朝向长远的方向，并在其中创造；创造的东西都指向未来（下一代的素养、文化认同、几代人的感受）。

三个词的关系：选择是起点，创造是过程，未来是方向。立意示例：选择热爱、敢于创造，才能开启未来。

任务：复兴中学团委的征文，读者是同学，文章要落到“我们这一代怎样选择、怎样创造”。

做不好，回哪一课复杂材料审题与扣题审题与立意

身份、对象、场合、文体

支架基础高考真题 · 2019年全国Ⅱ卷
题面 · 2019年全国Ⅱ卷 · 五个时间节点，五选一的任务

阅读下面的材料，根据要求写作。

1919年，民族危亡之际，中国青年学生掀起了一场彻底反帝反封建的伟大爱国革命运动。1949年，中国人从此站立起来了！新中国青年投身于祖国建设的新征程。1979年，“科学的春天”生机勃勃，莘莘学子胸怀报国之志，汇入改革开放的时代洪流。2019年，青春中国凯歌前行，新时代青年奋勇接棒，宣誓“强国有我”。2049年，中华民族实现伟大复兴，中国青年接续奋斗……

请从下列任务中任选一个，以青年学生当事人的身份完成写作。

①1919年5月4日，在学生集会上的演讲稿。

②1949年10月1日，参加开国大典庆祝游行后写给家人的信。

③1979年9月15日，参加新生开学典礼后写给同学的信。

④2019年4月30日，收看“纪念五四运动100周年大会”后的观后感。

⑤2049年9月30日，写给某位“百年中国功勋人物”的国庆节慰问信。

要求：结合材料，自选角度，确定立意；切合身份，贴合背景；符合文体特征；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

自查

从画面走到寓意

支架进阶高考真题 · 2021年新高考Ⅱ卷
题面 · 2021年新高考Ⅱ卷 · 漫画：描红

阅读下面的材料，根据要求写作。

（唐光雨漫画作品，有改动）

[注]描红：用毛笔蘸墨在红模子上描着写字。

请整体把握漫画的内容和寓意写一篇文章，反映你的认识与评价、鉴别与取舍，体现新时代青年的思考。

要求：选好角度，确定立意，明确文体，自拟标题；

不要套作，不得抄袭；

不得泄露个人信息；

不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

按“说表层 → 找对应 → 抽道理 → 回任务”四步，读出漫画的寓意，写一句立意。

提示
  1. 说表层：四格分别画了什么？最后一格写出的是哪个字？
  2. 找对应：书法里的“逆锋”“中锋”“藏而不露”“缓缓出头”，像做人的哪些方面？
  3. 抽道理：从对应里抽出一个判断。
  4. 回任务：题目要你“反映你的认识与评价、鉴别与取舍”。这几个词提醒你什么？
自查
  • 我的立意里有“描红”这一层意思吗？做不好 → 复杂材料审题与扣题
  • 我回应了“鉴别与取舍”，而不是只赞美书法吗？做不好 → 辩证分析
参考答案与解析
  1. 表层：四格依次是“逆锋起笔，藏而不露”“中锋用笔，不偏不倚”“停滞迂回，缓缓出头”，最后在红模子上描出一个“人”字。
  2. 对应：写字的笔法对应做人的态度——内敛、正直、有分寸。
  3. 道理：写好一个“人”字，要守住方正的笔法；做好一个人，也要守住做人的准则。
  4. 回任务：“描红”是照着模子写。“鉴别与取舍”提醒你：哪些准则要守住（中正、内敛），描红是不是一辈子都要照着模子写？可以写“从描红到自运”——先守规矩，再形成自己的风格（第14课的条件化判断）。

立意示例：做人如写字，先在描红里守住方正，再在自运里写出自己。

做不好，回哪一课复杂材料审题与扣题辩证分析

四个立意，哪个切题

诊断基础高考真题 · 2024年全国甲卷
题面 · 2024年全国甲卷 · 坦诚交流与真正的相遇

阅读下面的材料，根据要求写作。

每个人都要学习与他人相处。有时，我们为避免冲突而不愿表达自己的想法。其实，坦诚交流才有可能迎来真正的相遇。

这引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

判断下面四个立意分别是切题、沾边、偏题还是套题，说出理由。

材料（本站拟写，供练习用）

立意甲：坦诚交流，才有可能迎来真正的相遇。

立意乙：学会与人相处，是每个人的必修课。

立意丙：为了避免冲突而沉默，会让我们错过真正理解彼此的机会。

立意丁：青年要勇于担当，在奋斗中书写青春华章。

提示

先找材料的核心：“坦诚交流”和“真正的相遇”，以及它们之间的“才有可能”；“避免冲突而不愿表达”是材料批评的做法。再拿每个立意去对：两头都扣住了吗？

自查
  • 我判断时，用的是材料里的关键词，不是凭感觉吗？做不好 → 高考题型与审题迁移
  • 我能说出“沾边”和“切题”的区别吗？做不好 → 复杂材料审题与扣题
参考答案与解析
  • 甲：切题。 直接回应核心关系，几乎就是材料的关键句。可以写，但最好再往前走一步，例如说清“真正的相遇”指什么（第7课）。
  • 乙：沾边。 只抓住了材料第一句的背景“学习与他人相处”，核心“坦诚交流”不见了。
  • 丙：切题，而且有针对性。 从材料批评的做法（避免冲突而沉默）切入，反过来说明坦诚的价值。
  • 丁：套题。 换一道题也能用，和材料的任何关键词都没有关系。

“沾边”是最隐蔽的偏题：读起来和材料有关，但核心概念被背景词替换了（第6课的“什么叫切题，什么叫只是沾边”）。

做不好，回哪一课审题与立意复杂材料审题与扣题高考题型与审题迁移

两则材料，一句立意

独立进阶高考真题 · 2023年全国乙卷
题面 · 2023年全国乙卷 · 吹灭别人的灯；一花独放不是春

阅读下面的材料，根据要求写作。

吹灭别人的灯，并不会让自己更加光明；阻挡别人的路，也不会让自己行得更远。

“一花独放不是春，百花齐放春满园。”如果世界上只有一种花朵，就算这种花朵再美，那也是单调的。

以上两则材料出自习近平总书记的讲话，以生动形象的语言说出了普遍的道理。请据此写一篇文章，体现你的认识与思考。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

写一句能同时解释两则材料的立意，并用一两句话说明它怎样覆盖每一则。

提示

两则分别从反面（吹灭、阻挡）和正面（百花齐放）说。先各用一句话概括，再找它们“合起来”的那句话（第6课 求同）。

自查
  • 我的立意能解释第一则吗？能解释第二则吗？做不好 → 复杂材料审题与扣题
  • 我没有只写“合作共赢”这样换一道题也能用的话吧？做不好 → 审题与立意
  • 立意是一句完整的判断吗？做不好 → 提出论点
参考答案与解析
  • 第一则：损害别人，不会让自己更好。
  • 第二则：只有一种，再美也单调；多种并存，才是春天。
  • 合起来：自己的光明和繁荣，不靠压低别人；别人的存在，正是共同繁荣的条件。

立意示例：自己的光明不以压低别人为代价，多样共存才能共同繁荣。

说明：前半句回应第一则（吹灭别人的灯，不会让自己更光明），后半句回应第二则（百花齐放春满园）。注意不要写成“成就别人就是成就自己”：第一则只说损害别人无益于自己，并没有说帮助别人一定有益于自己，从材料推不出这一层（第16课）。题目说两则材料“说出了普遍的道理”，可以从个人写到国家、文明，但要守住“彼此成就”这条主线。

做不好，回哪一课复杂材料审题与扣题关系型思维

三段文字的共同点

独立进阶高考真题 · 2025年全国一卷
题面 · 2025年全国一卷 · 老舍、艾青、穆旦：三段文字

阅读下面的材料，根据要求写作。

他想要给孩子们唱上一段，可是心里直翻腾，开不了口。

——老舍《鼓书艺人》（见全国一卷阅读II）

假如我是一只鸟，

我也应该用嘶哑的喉咙歌唱

——艾青《我爱这土地》

我要以带血的手和你们一一拥抱，

因为一个民族已经起来

——穆旦《赞美》

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

逐段概括三段文字，找出共同点，写一句立意。只做审题，不写全文。

提示
  • 第一段标明出自本卷阅读题。先回到原文语境想一想：“开不了口”是因为什么（第19课 读写结合）？
  • 三段的作者不同、时代不同，共同点不在字面上。可以从“说不出 / 嘶哑地唱 / 带血地拥抱”这三种表达状态去找。
自查
  • 三段我都概括了，立意能解释每一段吗？做不好 → 复杂材料审题与扣题
  • 我的立意不只是“热爱祖国”四个字，写出了三段材料共同的那一层吗？做不好 → 关系型思维
  • 立意里有“我”能说的话，不只是复述诗句吗？做不好 → 审题与立意
参考答案与解析
  • 老舍：心里翻腾，想唱却开不了口——情感太深，一时说不出。
  • 艾青：即使喉咙嘶哑，也要歌唱——在苦难中也要发声。
  • 穆旦：以带血的手拥抱——经历苦难之后的觉醒与团结。

共同点（之一）：深沉的情感，在苦难的时代找到表达的方式；说不出、嘶哑地唱、带血地拥抱，都是一个民族在苦难中的心声。

立意示例：苦难中的歌唱，是一个民族最深沉的声音。

也可以从“表达”本身入手：真正的情感，常常不在流利的言辞里。无论哪一种，都要能解释三段，而不是只挑一段写。

做不好，回哪一课复杂材料审题与扣题高考题型与审题迁移关系型思维

题面 · 2022年全国乙卷 · 跨越，再跨越

阅读下面的材料，根据要求写作。

北京：双奥之城
2008年奥运会、残奥会 2022年冬奥会、冬残奥会
比赛成绩 中国奥运代表团名列金牌榜第一，奖牌榜第二；残奥代表团名列金牌榜第一，奖牌榜第一。均创历史最好成绩 中国冬奥代表团名列金牌榜第三，奖牌榜第十一；冬残奥代表团名列金牌榜第一，奖牌榜第一。均创历史最好成绩
群众体育 全民健身事业蓬勃发展 “三亿人参与冰雪运动”成为现实
科技亮点 世界跨度最大钢结构场馆“鸟巢”；场馆污水处理再生利用率达100% 智慧场馆和智慧服务；“分钟级”“百米级”精准气象预报
交通支持 全国第一条高铁京津城际铁路开通，助力奥运 京张智能高铁冬奥列车开行；全国高铁运营里程超4万公里，居世界第一
国家经济 国内生产总值：31.4万亿元（2008年） 国内生产总值：114.4万亿元（2021年）

双奥之城，闪耀世界。两次奥运会，都显示了中国体育发展的新高度，展示了中国综合国力的跨越式发展，也见证了你从懵懂儿童向有为青年的跨越。亲历其中，你能感受到体育的荣耀和国家的强盛；未来前行，你将融入民族复兴的澎湃春潮。卓越永无止境，跨越永不停歇。

请结合以上材料，以“跨越，再跨越”为主题写一篇文章，体现你的感受与思考。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

读表格，找出两次奥运之间“跨越”在哪里；再读文字材料，找出“你”在哪里。写一句立意，检查它有没有套题。

提示
  1. 表格每一行都在比较 2008 年和 2022 年，挑两行说出“跨越”。
  2. 文字材料里有一句写到“你”：从懵懂儿童到有为青年。
  3. 主题是“跨越，再跨越”：两个“跨越”，说明不止一次，还要继续。
自查
  • 我的立意同时写到了国家的跨越和“我”的跨越吗？做不好 → 审题与立意
  • “再跨越”这一层，我写到了吗？做不好 → 核心概念阐释
  • 把“奥运”换成别的事，我的立意还能原样用吗？能，就是套题。做不好 → 审题与立意
参考答案与解析
  • 国家的跨越：从“鸟巢”到“智慧场馆”，从第一条城际高铁到高铁里程世界第一，经济总量从 31.4 万亿元到 114.4 万亿元。
  • “我”的跨越：两次奥运之间，“你”从懵懂儿童成长为有为青年。
  • “再跨越”：材料结尾“卓越永无止境，跨越永不停歇”，指向未来。

立意示例：我与国家一同跨越，下一次跨越，要靠我们这一代去完成。

套题检查：“青年要奋斗”换到哪道题都能用；而“双奥之间，我和国家一同长大”离开这道题就说不通——这才是扣住了材料。

一句问句的审题

迁移进阶精选模拟 · 上海市2025届浦东新区一模
题面 · 上海市2025届浦东新区一模 · 履行责任是否意味着放弃自由

一个人履行责任是否意味着放弃自由？ 请写一篇文章，谈谈你对这个问题的认识和思考。 要求：(1)自拟题目；(2)不少于800字。

精选模拟：本站审题要点 →

本次只练

换到一道上海一模题：限时十分钟，读题、找核心概念、写一句立意。只写立意和一段不超过 100 字的说明。

讲评《在责任中探寻自由的真谛》 · 68分（满分70）

提示
  • 问句的关键词是“意味着”。它问的是一种必然联系。
  • 先问自己：自由有几种？履行责任时，让出去的是哪一种？
自查
  • 我回答了“是否意味着”，有明确的态度吗？做不好 → 审题与立意
  • 我区分了不同的“自由”，没有把它当成一个词就写下去吗？做不好 → 概念辨析与条件边界
  • 我没有只写“责任很重要”，把“自由”丢掉吗？做不好 → 高考题型与审题迁移
参考答案与解析

立意示例：履行责任会让我们放弃一部分随心所欲的自由，却不意味着放弃自由。

说明：先承认履行责任有代价（时间、选择），再说明它不等于放弃自由——自主地承担责任，本身就是自由的一种。这样既回答了“是否意味着”，也给自己留出了论证的空间。

这道题的命题分析把立意分了几档：只看到“履行责任时需要放弃一些自由”，或只看到“履行责任时也获得一些自由”，都不全面；两面都看到，才算好；能进一步说清两者怎样互相转化，才算深刻。本站讲评《在责任中探寻自由的真谛》可以对照着读。
