修改与升格

按“审题 → 论点 → 论证 → 结构 → 语言”的顺序诊断，再动手改一处：段落升格、提纲升格、局部重写。

练完能读一篇作文，说出最该改的一处在哪里、属于哪一类，并把它改好。

主要回到阅卷标准与自评修改与升格高级谋篇议论文语言表达

怎么用这一页

10 个训练，用到全国卷真题 7 道。按顺序做：先看示范，再带支架练，再独立练，最后迁移。每个训练只练一件事，“本次只练”写清楚了；提示、自查、参考答案都先收起，自己做完再展开。做不好，按卡片底部回到对应的课。

这一组的自查

每个训练有自己的自查；这几项是这一组都要问的。用语和第21课的交卷前检查表一致，不打分，只答“是”或“否”。

  • 先查审题，再查论点、论证、结构，最后才改语言？做不好 → 修改与升格
  • 改完以后，中心论点更清楚了？做不好 → 修改与升格
  • 每个保留的材料后面都补上了分析？做不好 → 修改与升格
  • 删掉了假、大、空的话，论证还在？做不好 → 议论文语言表达
  • 每一段能用一个动词说出它做什么？做不好 → 高级谋篇

把一篇点评对到六个维度上

讲评高考真题 · 2026年全国一卷
题面 · 2026年全国一卷 · 你对哪一个词语的理解变了

阅读下面的材料，根据要求写作。

词语是表达思想情感的载体，也是展现社会生活变化的窗口。当前，世界之变、时代之变、历史之变正以前所未有的方式展开。青年是常为新的，在你的成长过程中，你对哪一个词语的理解发生了变化？这变化有你成长的印记，对你有特殊的意义……

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

读一篇 60 分考场作文的点评，把每一句评价对到第21课的六个维度上。修改之前，先学会读懂评价在说哪一方面。

点评原句 维度
“我”的“世界”范围逐渐扩大，认识“世界”的层次不断深化 切题与任务（落实了“理解的变化”）
写作时不仅能够符合题意，而且所有的叙述既集中又深入 切题与任务；中心与观点
用“我”的成长经历、感受、认知、思考等贯穿起来，一气呵成，整体感很强 结构与推进
援引佛教意象、名著、名句、史实、社会现象等材料，都能紧紧地围绕文章的情感脉络和主要观点 论证与分析（材料服务观点）
文字表达准确到位且富于文采 表达

结尾段用“我的心略大于这个世界”“为爱留着我的余地”收拢全文

这一句评的是结构（收束）。

一句点评可以同时对应两个维度。读别人的点评时这样对一遍，修改自己的文章时，就知道每一类问题该回哪一课（第21课的“点评对应维度”）。

讲评《我的心，略大于这个世界》 · 60分（满分60）

做不好，回哪一课阅卷标准与自评

一张三栏修改单

示范高考真题 · 2023年新课标Ⅱ卷
题面 · 2023年新课标Ⅱ卷 · 自己的空间

阅读下面的材料，根据要求写作。

本试卷语言文字运用Ⅱ提到的"安静一下不被打扰"的想法，在当代青少年中也不鲜见。青少年在学习、生活中，有时希望有一个自己的空间，放松，沉淀，成长。

请结合以上材料写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

看一个开头段怎样按“原文 → 问题 → 修改后”三栏修改，并且先改审题和论点，最后才改语言。

本站拟写的开头：

“在这个快节奏的时代，每个人都需要空间。空间是心灵的港湾，是灵魂的栖息地。我们要拥有自己的空间，让生命更加精彩。”

原文 问题 修改后
每个人都需要空间 审题：材料说的是“青少年”“有时”希望有“自己的空间”，被放大成“每个人都需要空间”，核心概念丢了“自己的”（第7课） 我们这个年纪，有时需要一个自己的空间
空间是心灵的港湾，是灵魂的栖息地 论点：两个比喻，没有判断；材料给了“放松，沉淀，成长”，没有用上（第2课） 这个空间不是逃避，而是让人放松、沉淀，再重新出发的地方
让生命更加精彩 语言：空话，删掉之后意思不少（第12课） 删去，换成中心论点：给自己留一个空间，是为了更好地成长

修改后的开头：

“我们这个年纪，有时需要一个自己的空间。这个空间不是逃避，而是让人放松、沉淀，再重新出发的地方。给自己留一个空间，是为了更好地成长。”

顺序：先改审题（范围、核心概念），再改论点，最后才删空话（第22课）。如果先去润色“心灵的港湾”，就是在原地打转。

做不好，回哪一课修改与升格提出论点核心概念阐释

只写词义的开头怎么改

诊断基础高考真题 · 2026年全国一卷
题面 · 2026年全国一卷 · 你对哪一个词语的理解变了

阅读下面的材料，根据要求写作。

词语是表达思想情感的载体，也是展现社会生活变化的窗口。当前，世界之变、时代之变、历史之变正以前所未有的方式展开。青年是常为新的，在你的成长过程中，你对哪一个词语的理解发生了变化？这变化有你成长的印记，对你有特殊的意义……

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

下面这个开头审题不全。说出缺了题目的哪一项要求，然后改写（100 字以内）。

材料（本站拟写，供练习用）

“责任是什么？责任是父母的养育之恩，是军人的保家卫国，是医生的救死扶伤。责任重于泰山，每个人都应当承担起自己的责任。”

提示

把题目的要求逐项列出来：一个词语、理解的变化、成长的印记。在开头里一项一项找（审题与立意专项的“审题残缺是什么样子”）。

自查
  • 改后的开头里有“从前我以为……后来……”这样的变化吗？做不好 → 审题与立意
  • 有“我”的经历，不只是一串别人的例子吗？做不好 → 审题与立意
  • 我选的词仍然是“责任”，没有换题吗？做不好 → 核心概念阐释
参考答案与解析

缺的是变化和成长的印记：只解释了“责任”是什么，没有“我”对它的理解怎样变化。三项只做到一项。

改写示例：

“小时候，我以为‘责任’是大人的事，是写在作业本上‘按时完成’的那四个字。直到那年外婆生病，我第一次独自去医院送饭，才明白责任不是别人交给我的任务，而是我心里放不下的人。”

改后有一个词（责任），一个变化（从“任务”到“放不下的人”），一个成长的触发点（外婆生病、独自送饭）。按第22课的顺序，审题的问题要最先改：审题对了，后面的论点和材料才有方向。

做不好，回哪一课修改与升格审题与立意核心概念阐释

套话论点怎么改

诊断基础高考真题 · 2023年全国甲卷
题面 · 2023年全国甲卷 · 时间的仆人

阅读下面的材料，根据要求写作。

人们因技术发展得以更好地掌控时间，但也有人因此成了时间的仆人。

这句话引发了你怎样的联想与思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

下面开头的中心论点是套话。按“原论点 → 问题 → 修改后”改一句。

材料（本站拟写，供练习用）

“科技是一把双刃剑，它在给我们带来便利的同时，也带来了一些问题。因此，我们要辩证地看待科技。”

提示
  • 这道题的核心是什么？“仆人”“掌控时间”在哪里？
  • 把“科技”换成“网络”“金钱”“竞争”，这句话还能用吗？
  • 第22课：“沾边 → 切题 → 更有深度”。
自查
  • 修改后的论点里有“时间”和“仆人 / 主人”吗？做不好 → 高考题型与审题迁移
  • 修改后的论点换到别的题目就不能用了吗？做不好 → 提出论点
  • 修改后的论点有态度，不是“辩证地看待”吗？做不好 → 提出论点
参考答案与解析
原论点 问题 修改后
我们要辩证地看待科技 套话：没有“时间”，没有“仆人”，换到任何科技题都能用；“辩证地看待”没有说出看待的结果 技术给了我们掌控时间的工具，能不能做时间的主人，取决于我们是否先想清楚时间要用在哪里

修改后的论点有题目的核心（时间、主人），有条件（是否先想清楚），有态度。

做不好，回哪一课修改与升格提出论点高考题型与审题迁移

5

一处引用错了，怎么办

诊断进阶精选模拟 · 上海市2025届浦东新区一模
题面 · 上海市2025届浦东新区一模 · 履行责任是否意味着放弃自由

一个人履行责任是否意味着放弃自由？ 请写一篇文章，谈谈你对这个问题的认识和思考。 要求：(1)自拟题目；(2)不少于800字。

精选模拟：本站审题要点 →

本次只练

这篇 60 分作文第四段引用弗洛伊德的说法有误，点评没有指出。判断错在哪里，再决定：改正，还是删去换别的论证。

材料（灰底引文摘自讲评作文或点评，其余为本站说明）

“本我”指的则是遵守社会规则与法度，履行责任的我

讲评《履行责任与精神自由》 · 60分（满分70）

提示
  • 弗洛伊德的“本我”“自我”“超我”各指什么？如果自己也说不准，第22课的建议是什么？
  • 改正以后，这个理论还能支持“履行责任基础上实现精神自由”吗？
自查
  • 我说清了原文错在哪里吗？做不好 → 论据选择与分析
  • 我的处理（改正或删去）让这一段的论证更可靠了吗？做不好 → 修改与升格
  • 我知道交卷前检查表里哪一项会查出这个问题吗？做不好 → 阅卷标准与自评
参考答案与解析

错在哪里：在弗洛伊德的说法里，本我是本能冲动，自我在本能与现实之间调节，超我是内化了的道德和社会规范。原文把“遵守规则、履行责任”归给了本我，正好说反了。

处理：

  • 改正：如果要用，应写成“遵守规则、履行责任，更接近超我的约束”。但这样一来，原文“超我是追寻自由的我”的说法也站不住，整段要重写。
  • 删去（更稳妥）：这一段的观点是“履行责任与精神自由可以统一”，换成一个自己有把握的例子来证明，比用一个说不准的理论好。

交卷前检查表里的“论据真实，能说出出处，引用没有错？”这一项，查的就是这类问题。第22课：引用要可查证，不确定的，宁可不用。

做不好，回哪一课论据选择与分析修改与升格阅卷标准与自评

删、补、换：给论据升格

诊断进阶高考真题 · 2019年全国Ⅰ卷
题面 · 2019年全国Ⅰ卷 · 热爱劳动，从我做起

阅读下面的材料，根据要求写作。

“民生在勤，勤则不匮”，劳动是财富的源泉，也是幸福的源泉。“夙兴夜寐，洒扫庭内”，热爱劳动是中华民族的优秀传统，绵延至今。可是现实生活中，也有一些同学不理解劳动，不愿意劳动。有的说：“我们学习这么忙，劳动太占时间了！”有的说：“科技进步这么快，劳动的事，以后可以交给人工智能啊！”也有的说：“劳动这么苦，这么累，干吗非得自己干？花点钱让别人去做好了！”此外，我们身边也还有着一些不尊重劳动的现象。

这引起了人们的深思。

请结合材料内容，面向本校（统称“复兴中学”）同学写一篇演讲稿，倡议大家“热爱劳动，从我做起”，体现你的认识与思考，并提出希望与建议。

要求：自拟标题，自选角度，确定立意；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

下面这段演讲稿的主体段只有材料，没有分析。按第22课的顺序升格：先改观点，再给论据做“删、补、换”。

材料（本站拟写，供练习用）

同学们，劳动是光荣的。袁隆平院士一辈子在稻田里劳动，被称为“杂交水稻之父”。古人说“一粥一饭，当思来处不易”。我国的航天员在太空中完成了许多任务。我们的父母每天辛勤工作。所以，我们要热爱劳动。

提示
  • 先改观点：“劳动是光荣的”太泛，演讲稿的任务是倡议同学“热爱劳动，从我做起”，材料里还有“花点钱让别人去做”的说法。观点句能不能换得更有针对性？（论点先于论证）
  • 删：观点定了，哪个材料和它的关系最远？
  • 补：保留的材料后面，补一句分析，说清它怎样证明观点。
  • 换：如果剩下的材料撑不起新观点，换一个贴合的。
自查
  • 我删掉的是关系最远或最空泛的材料吗？做不好 → 修改与升格
  • 每个保留下来的材料后面，都有一句分析吗？做不好 → 议论段深化与论证方法
  • 改后的观点句扣住了演讲稿的任务吗？做不好 → 提出论点、情境与任务适应
参考答案与解析
  • 先改观点：观点句改为“劳动的价值，不在于做了多大的事，而在于亲手去做”，回应材料里“花点钱让别人去做”的说法，也扣住“从我做起”。
  • 删：航天员的例子（证明的是科技成就，和日常劳动关系远）；“父母每天辛勤工作”（空泛，没有具体事实）。
  • 补：在袁隆平和古语后面各补一句分析，都落到“亲手去做”。
  • 换：剩下两个材料已能撑起新观点，不必再换。

升格示例：

同学们，劳动的价值，不在于做了多大的事，而在于亲手去做。袁隆平院士成名之后，仍常年下到稻田里察看秧苗。稻子长得怎样，报告里写不全，要亲眼看、亲手摸。古人说“一粥一饭，当思来处不易”，来处之所以不易，正因为每一粒米都经过了一双双手。花钱请人代劳，省下的是力气，丢掉的是对生活的这份体会。所以，热爱劳动，就从亲手做好身边的一件事开始。

做不好，回哪一课修改与升格提出论点情境与任务适应论据选择与分析议论段深化与论证方法

删掉假大空的话

诊断基础高考真题 · 2024年新课标Ⅱ卷
题面 · 2024年新课标Ⅱ卷 · 向未知之境

阅读下面的材料，根据要求写作。

本试卷现代文阅读I提到，长久以来，人们只能看到月球固定朝向地球的一面，“嫦娥四号”探月任务揭开了月背的神秘面纱；随着“天问一号”飞离地球，航天人的目光又投向遥远的深空……

正如人类的太空之旅，我们每个人也都在不断抵达未知之境。

这引发了你怎样的联想与思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

下面这段话读起来很有气势，但大多是空话。按第12课、第22课的“删、改、顺、省”修改，改后不超过原文的一半。

材料（本站拟写，供练习用）

浩瀚宇宙，星辰大海，无数先辈前赴后继，用血汗铸就了辉煌的篇章。正如人类的太空之旅，我们每个人也都在不断抵达未知之境。我们要勇敢地奔赴未知，在广阔天地中绽放青春光芒，谱写属于新时代青年的壮丽诗篇，为实现中华民族伟大复兴贡献自己的力量！

提示
  • 一句一句问：删掉这一句，意思少了什么？少不了的，才是有用的话。
  • 哪一句是材料原话？抄材料不算自己的观点。
  • 留下来的话里，“未知之境”对“我”来说具体指什么？
自查
  • 我删掉的句子，删后论证没有受影响吗？做不好 → 议论文语言表达
  • 改后的段落里，有一句我自己的判断，不是材料原话吗？做不好 → 修改与升格
  • 改后的话具体到能想象出一个场景吗？做不好 → 议论文语言表达
参考答案与解析

逐句看：

  • “浩瀚宇宙……辉煌的篇章”：空泛的铺排，没有判断，删。
  • “正如人类的太空之旅……未知之境”：抄材料原话，删或改成自己的话。
  • “绽放青春光芒……壮丽诗篇……贡献自己的力量”：口号连用，换到哪道题都能用，删。

改后示例：

对航天人来说，未知之境是月球背面；对我们来说，可能是第一次独自面对一道没有思路的难题，第一次离开家去一座陌生的城市。抵达未知，不靠一句口号，而靠在不知道答案时，仍肯往前走一步。

改后只有原来一半长，但有一个判断（靠往前走一步），有具体场景，也扣住了“我们每个人也都在不断抵达未知之境”。

做不好，回哪一课议论文语言表达修改与升格

按点评补过渡、改长句

诊断进阶精选模拟 · 上海市2025届金山区一模
题面 · 上海市2025届金山区一模 · 用常识看待事物

生活中，人们往往用常识去看待事物，做出判断。 对此，你怎么看？请写一篇文章，谈谈你的认识与思考。 要求：（1）自拟题目；（2）不少于800字。

精选模拟：本站审题要点 →

本次只练

这篇 59 分作文的点评指出两处不足：段与段之间过渡突兀，长句断句不当。只改这两处：写一句过渡句，改一个长句。

材料（灰底引文摘自讲评作文或点评，其余为本站说明）

点评原话：

从“常识的时效性”跳到“全新未知领域的局限”时，缺少一段清晰的过渡

第三段的段首是“常识具有很强的时效性”，第四段的段首是：

常识在某些领域并不具有普适性。

第四段里的一个长句：

只有在一次次思想和外界碰撞中，在一次次问题和经验的摩擦交手中，我们才能翻越常识所局限我们的藩篱，打破尝试为我们设置的认识牢笼，走向真理的灯塔。

讲评《于常识中破伪，于实践中见真》 · 59分（满分70）

提示
  • 过渡句要说清两段的关系：前一段说常识在时间上有局限，后一段说常识在范围上有局限。用一句话把“时间”和“范围”接起来（第18课的段与段之间）。
  • 长句：数一数有几个比喻（藩篱、牢笼、灯塔）？“常识所局限我们的藩篱”通顺吗？“尝试”是不是错字？
自查
  • 我的过渡句说出了两段之间的关系（并列，还是推进）吗？做不好 → 高级谋篇
  • 改后的长句只用一个比喻，语法通顺吗？做不好 → 议论文语言表达
  • 我只改了点评指出的地方，没有顺手改动别的内容吗？做不好 → 修改与升格
参考答案与解析

过渡句示例（放在第四段段首）：“常识不仅会随着时间过时，即使在同一时代，它也有管不到的地方。”

这一句先回收上一段（时间），再引出这一段（范围），读者就知道两段是从两个方面谈常识的局限。

长句修改示例：“只有在思想与现实的一次次碰撞中，我们才能越过常识的局限，走近真理。”

改了三处：三个比喻只留下意思（越过局限、走近真理）；“常识所局限我们的藩篱”句式杂糅，改为“常识的局限”；“尝试”应为“常识”，是错别字。

做不好，回哪一课高级谋篇议论文语言表达修改与升格

提纲升格

独立进阶高考真题 · 2025年全国二卷
题面 · 2025年全国二卷 · 梦，以及把梦赠予他人

阅读下面的材料，根据要求写作。

“昨夜闲潭梦落花”“我欲因之梦吴越”“铁马冰河入梦来”……梦往往以一种独特的方式呈现我们的感受和期冀，为我们打开更浩瀚的天空。我们也常常向别人讲述自己的梦，用文字记录自己的梦，以行动实现自己的梦。

如果有一天，我们能够将梦赠予他人……

以上材料引发了你怎样的联想和思考？请写一篇文章。

要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字。

真题页：审题提示、立意方向、同题作文 →

本次只练

下面是一份“流水账”提纲。按第18课“一段一个动词”的方法升格：先给每段写出它的功能，再调整、合并或删去。

材料（本站拟写，供练习用）

  1. 开头：引用三句写梦的诗句。
  2. 写李白梦游天姥。
  3. 写陆游“铁马冰河入梦来”。
  4. 写我小时候的梦。
  5. 写梦想很重要，青年要有梦想。
  6. 结尾：让我们一起追梦。
提示
  • 每段用一个动词说它做什么：引出、举例、举例、叙述、号召……有没有一段在“论证”？
  • 材料最后一句“如果有一天，我们能够将梦赠予他人……”，这份提纲用上了吗？
  • 第22课：调整结构之前，先看中心论点在哪里。
自查
  • 升格后的提纲有一句明确的中心论点吗？做不好 → 修改与升格
  • 每一段都能用一个动词说出功能，而且都在推进中心论点吗？做不好 → 高级谋篇
  • 材料里的“赠予他人”有着落了吗？做不好 → 分论点与观点句进阶
参考答案与解析

原提纲的问题：没有中心论点；第2、3段都是“举例”，原地转圈；第5段是口号；“赠梦”没有出现。

升格示例：

  • 中心论点：梦的可贵，不只在于照亮自己，更在于能赠予他人。
  • 第一段（界定）：从诗句看梦——梦呈现感受和期冀（借用材料里的诗句，一句带过）。
  • 第二段（论证）：讲述和记录，让个人的梦被别人理解——陆游的梦写进诗里，后人读到了他的家国之思。
  • 第三段（推进）：实现梦，让梦成为别人的现实——一个人的梦想，可以成为许多人的路。
  • 第四段（回应）：梦是私人的，能赠予吗？能赠予的不是梦本身，而是梦里的期冀和勇气。
  • 结尾（收束）：回到“将梦赠予他人”。

原来的“我小时候的梦”可以并入第二段作为一个例子，或者删去；“让我们一起追梦”的口号删去。

做不好，回哪一课高级谋篇修改与升格分论点与观点句进阶
