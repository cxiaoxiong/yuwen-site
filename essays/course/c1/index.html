第一阶段 · 基础写作 · 第1课

审题与立意

读题定题

从这里开始：先把题读准，再把立意定稳，最后才谈怎么写。本课只讲一则材料的审题立意；多则材料、寓意材料、漫画材料留到第6课。

学习目标

  • 准确说出材料的核心意思，不停留在复述材料。
  • 找出题目里的任务句和限制条件，知道“要我写什么、写给谁、不能怎么写”。
  • 提出切题、明确、集中的立意，并能写成一句完整的判断。
  • 会用几条标准判断两个立意谁更好，能说出偏在哪里。

这一课讲什么

  1. 简单材料审题四法提炼中心、抓关键词句、由果溯因、对象分析，遇到一则材料先选哪一种。
  2. 写作任务与要求领会读出任务句、写作身份与对象、限制条件，不只读材料。
  3. 立意标准正确切题、集中、新颖、深刻，会判断一个立意好不好。

核心认识

教材怎么说

选择性必修上册第二单元“审题与立意”：“审题与立意，通俗地说，就是先了解‘要我写什么’，然后确定‘我要写什么’。”审题要“抓住关键，弄清题旨”，“重点思考题目中的核心概念是什么，应该如何界定，可以从哪些方面立意”；立意“基本的要求是要‘立’在题目或给定材料的范围之内”，还应当具体、明确，体现独特性。（原文见选择性必修上册第二单元 · 单元研习任务）

下面三句是本课按教材的说法整理的：

  • 审题回答“材料和题目要我写什么”：审得对或不对，有明确的标准。
  • 立意回答“我要写什么”，也就是确定写作的中心：在审对的前提下，立意还有高下之分。
  • 任务与要求回答“以什么身份、面对谁、完成什么、有哪些限制”：材料读对了，任务没读对，照样失分。

新材料作文没有唯一的最佳立意，同一则材料可以有几个都站得住的立意。所以判断立意不问“是不是标准答案”，而问“对不对、好不好”。

子专题一：简单材料审题四法

简单材料指只有一则、内容不复杂的材料。做法是：先判断这则材料属于哪一类，再选一种方法，最后检查立意有没有落在材料上。

1. 提炼中心法

  • 什么时候用：材料是一个人、一件事或一个小故事。这是最常用、也最稳妥的一种。
  • 怎么做：① 用一句话说清“谁做了什么、结果怎样”；② 问“这件事说明了什么道理”；③ 把道理改成一句可以做论点的判断。
  • 一个短例子：苏联作家盖达尔的皮箱很旧，小学生说与他的名气“不协调”，他答：如果皮箱大名鼎鼎而我随随便便，那更糟。 概括：盖达尔和小学生关于皮箱破旧的对话 → 道理：身外之物可以随随便便，做人不能 → 观点：做人不应该随随便便。
  • 容易犯的错：停在“概括”这一步，把复述当成立意；或者从故事里另找一个和中心无关的道理。

2. 抓关键词句法

  • 什么时候用：寓言、名言警句、话题类材料。材料里有明显的评议性词句。
  • 怎么做：① 圈关键词：材料评议的对象、反复出现的词；② 找关键句：表达观点、态度的句子，常在结尾；③ 把词和句合起来，问“为什么……”“有什么……”“怎样……”。
  • 一个短例子：“烟火气是家人团坐，灯火可亲；烟火气是国泰民安，岁月静好……寻常烟火，就是最美的风景。” 关键词：烟火气；关键句：寻常烟火，就是最美的风景 → 立意如：守护寻常烟火，离不开你和我；珍惜眼前的岁月静好。
  • 容易犯的错：把关键词圈成一大串，或只抓词不看句，最后拿一个词当题目就开写。材料要从整体着眼，不能纠缠局部细节。

3. 由果溯因法

  • 什么时候用：材料先给出一个现象或结果，再让你想“为什么”，多见于寓言和哲理类材料。
  • 怎么做：① 找结果；② 推原因，原因要能在材料里找到依据；③ 把原因说成观点。
  • 一个短例子：孩子把苹果横着切，切面里出现一颗五角星。 结果：出现五角星 → 原因：孩子没有按常规竖着切 → 观点：创造性思维能得到意料之外的成功。
  • 容易犯的错：只写“结果很好”或“结果很坏”，不追问原因；或者推出的原因材料里根本没有。

4. 对象分析法

  • 什么时候用：材料里有不止一个人或对象，每一个都能成为写作角度。
  • 怎么做：① 列出材料里的对象；② 分清主次，哪个是重点，哪个是陪衬；③ 各用一句话概括他的行为、态度或品质；④ 从最重要的对象，或从对象之间的关系，选一个立意。
  • 一个短例子：亲友互赠礼物，有人觉得与其精挑细选，不如直接送钱。 对象一：送礼的人 → 立意：用心送礼，衣袖留香；对象二：收礼的人 → 立意：礼物姓“礼”不姓“物”。
  • 容易犯的错：每个对象都想写，立意散成几块；或只看见一个对象，漏掉材料真正讨论的对比。

选哪一种？

一件事或一个故事，先用提炼中心；有一句明显的评议，先抓关键词句；先有结果再想原因，用由果溯因；出现几个人物，用对象分析。同一则材料可以用两种方法互相印证。

子专题二：写作任务与要求领会

审题不只是读材料。要看三块：材料本身，材料后面的引导语（任务句），以及“要求”里的限制。只读第一块，容易写成“材料读对了，题目做错了”。

先圈什么、再找什么、最后对什么：

  1. 先圈任务句：材料后面那句“请……”“你怎么看”。它决定你要做什么。
  2. 再找身份、对象和场合：有没有说“给谁写”“以什么身份写”“在什么场合用”。
  3. 最后对限制条件：文体、字数、范围、关键词个数，一条一条对。

任务句怎么读

任务句怎么问 它要你做什么
“引发了你怎样的联想和思考？”（2023年新课标Ⅰ卷） 从材料出发联想，最后落到自己的思考和观点
“对于‘刷脸取纸’这一举措，你怎么看？” 必须对这件事表态，不能扩大成泛泛的“节约”“科技”
“请结合以上材料，以‘跨越，再跨越’为主题写一篇文章”（2022年全国乙卷） 主题已给定，围绕它写，不能另起一个主题

新课标Ⅱ卷这类读写结合的题，材料来自试卷其他部分：先弄清“读”的那段说了什么，再看“写”的要求朝哪个方向，最后把两者放在一起找角度。

身份、对象、场合

这些内容不是每道题都有，有的题有，就必须照做。下面几道题都在“历年高考作文”里，可以对照原题看：

  • 2019年：面向本校同学写演讲稿，倡议“热爱劳动，从我做起”，并提出希望与建议。对象是同学，文体是演讲稿，目的是倡议。
  • 2020年：班级读书会上写发言稿，齐桓公、管仲、鲍叔三人，对哪个感触最深。身份是发言者，只选一个人。
  • 2018年：文章将装进“时光瓶”，2035年开启，给那时18岁的一代人读。对象和时间都已给定。
  • 2017年：写文章帮助外国青年读懂中国，从给出的词里选两三个关键词并使之形成有机关联。目的和数量都有限定。

常见的限制条件

“选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于800字”，逐条读：

  • 选准角度、确定立意：给你自由，但立意要自己定，而且要“准”。
  • 明确文体：文体不限，但文体要清楚，不能写得四不像。
  • 自拟标题：题目要自己拟，不能没有。
  • 不要套作、不得抄袭；不得泄露个人信息：写作纪律，文中不要出现真实的校名、人名。
  • 有些题还有“不要脱离材料内容及含意的范围”“（诗歌除外）”，这是对立意范围和文体的限制。

新材料作文既有限制，也有自由：范围要守住材料，角度、立意、题目、文体则由你自己选。

子专题三：立意标准

先分清：审题有对错，立意有高下。审对了，才谈得上立意的好坏。

《新材料作文》列出高考作文对立意的四点要求：

标准 意思 怎么自查
正确 思想内容正确，并且切合题意 立场和材料一致吗？材料里有依据吗？回答了任务句吗？
集中 一篇文章只有一个中心 能不能用一句话说清？“多中心等于没有中心”
新颖 有自己的发现和感受 是不是别人一看就想到的那一句？
深刻 见人所未见，发人所未发 有没有往下问一层“为什么”“怎么样”

“正确”和“集中”回答“对不对”，“新颖”和“深刻”回答“好不好”。基础阶段先保证前两条，再追求后两条。

这四条和教材的要求是对得上的：教材说立意要“立”在材料范围之内（正确），要具体、明确，“不能大而化之，泛泛而论”（集中），还要体现独特性，“写出一个独特的‘我’”（新颖、深刻）。

立意要写成一句完整的判断，不要只写一个词。例如“故事”是话题，“好的故事是有力量的”才是立意。

判断一个立意：先判断它是否切题，再对材料、任务句逐项检查，最后看它是不是只有一个中心。

  • 对材料：立场有没有背离？有没有另起炉灶，或添了材料里没有的东西？
  • 对任务：有没有回答任务句？范围有没有被无端放大？
  • 对中心：核心概念是不是只有一个？贪多、次要概念抢主位，都会让文章不聚焦。

典型例题

例1　基础材料：2023年新课标Ⅰ卷

材料的大意：好的故事可以表达沟通、触动心灵、改变命运、展现民族形象……“故事是有力量的”。题目问：引发了你怎样的联想和思考？（原题见「历年高考作文」2023年。）

  • 先判断：材料在评议“好的故事”，用抓关键词句法。
  • 再做：关键词是“好的故事”；关键句是结尾的“故事是有力量的”。四个“可以”是举例，“……”说明还可以往下拓展。
  • 最后检查：由关键词和关键句可以问：好的故事为什么有力量？有什么力量？怎样发挥故事的力量？

一轮资料给出了三个都能成立的立意方向：聆听他人的好故事，也要叙写自己的好故事；向世界讲好中国故事；好故事教会我坚强、勇敢和自律。

例2　带明确任务：2020年

材料写齐桓公、管仲、鲍叔。任务句：三人中你对哪个感触最深？要求写读书会的发言稿。（原题见「历年高考作文」2020年。）

  • 先判断：材料里有多个对象，用对象分析法；题目还规定了身份和文体，属于有明确任务的题。
  • 再做：对象分析：齐桓公不计前嫌；管仲感恩知遇、建功立业；鲍叔慧眼识才、甘居其下。再看任务：“哪个感触最深”只选一个，“发言稿”要有说话的对象感。
  • 最后检查：三个人都写一遍，是没有回答任务句；写成一般的议论文，没有发言稿的对象和语气。参考立意如：知人虚己，以国为重。

例3　容易偏题的对比：“刷脸取纸”

某地公厕出现“刷脸取纸”设备，同一个人每隔9分钟才能取一次，目的是防止个别人过度取纸、造成浪费。各界褒贬不一。题目问：对这一举措，你怎么看？

下面四个立意，哪两项切题？

A. 科技，令生活更美好　　B. 科技有助道德自律　　C. 节约资源，人人有责　　D. 杜绝不文明行为，需标本兼治

查看答案

B、D。用由果溯因：结果是“刷脸取纸”上线，原因是要防止过度取纸。B 抓住了科技用来督促自律；D 抓住了要标本兼治。

A 没有涉及“防止过度取纸、造成浪费”这个关键内容，说的是科技的一般好处；C 忽视了任务句“对这一举措你怎么看”，把范围放大成泛泛的“节约”。

常见错误

  1. 只抓表面词语：抓住材料里的一个词就开写，不看整体和结论句。
  2. 立场背离材料：材料批评的，立意却在肯定。例如材料批评“假鸡汤”，写“善意的鸡汤无须辨真伪”。
  3. 与材料关联不大：立意本身没错，但材料讨论的不是这个。例如同一则材料，写“读书的力量是伟大的”。
  4. 添加材料里没有的内容：凭感觉臆测，写出材料中根本没有的词和意思。
  5. 忽略任务句，范围放大：任务问“怎么看这一举措”，立意却写成一个泛泛的大道理。
  6. 不集中：一个立意里同时放进几个概念，或者写得空泛，读者不知道你要说什么。

课堂小练

小练1　提炼中心

一位画家把自己满意的画放到街上，旁边写：“请把你认为不完美的地方画上圈。”晚上，画上画满了圈。老者建议他换个方式：另画一幅同样的画，写上“请把你认为完美的地方画上圈”，结果画上同样画满了圈。

用提炼中心法：写出概括、道理，再写出一个立意。

参考答案

概括：同一幅画，只因提示语不同，评价截然不同。 道理：换一种方式，人们对同一事物会有不同的评价。 立意示例：换个方式结果大不同；不同的标准，不同的结果；做好自己最重要，你难以让所有人都满意。

小练2　找任务和限制

比较两道题的“要求”，各圈出任务句、身份或对象、限制条件，再说说两道题差在哪里。

  • 题一（画家题）：“自选角度，确定立意，明确文体（诗歌除外），自拟标题；不要脱离材料内容及含意的范围作文；不要套作，不得抄袭；不少于800字。”
  • 题二（2019年）：“请结合材料内容，面向本校同学写一篇演讲稿，倡议大家‘热爱劳动，从我做起’……并提出希望与建议。要求：自拟标题，自选角度，确定立意；不要套作，不得抄袭；不得泄露个人信息；不少于800字。”
参考答案

题一：文体可以自选，但诗歌除外；立意不得脱离材料内容和含意；没有规定身份和对象。 题二：文体已经定为演讲稿，对象是本校同学，目的是倡议，还要提出希望与建议；题目要自拟，角度和立意可自选。 差别：题一限制在“范围”和“诗歌”，题二限制在“身份、对象、文体和内容”。

小练3　比较立意

网上流传“哈佛凌晨4点半图书馆灯火通明”，后来有人查证，这个景象并不存在，许多人却信以为真。材料对这类“假鸡汤”持批评、反思的态度。

下面哪两项立意最不适合？

A. 善意的“鸡汤”无须辨真伪　　B. 读书的力量是伟大的　　C. 莫被“鸡汤”遮蔽双眼　　D. “鸡汤”虽好，明辨为妙　　E. 不做盲从的“鸡汤族”

参考答案

A、B。A 的立场背离材料：材料是批评的，它却说“无须辨真伪”。B 本身没有错，但材料讨论的是“假鸡汤”，不是读书的力量，与材料关联不大。

课后训练

下面的真题都在「历年高考作文」里，在本页“相关资源”里可以直接进入。先自己做，再看范文和点评。

  1. 2022年（“本手、妙手、俗手”）：用抓关键词句法，写出关键词和关键句，再各拟三个立意，按“正确、集中、新颖、深刻”排序。
  2. 2013年（三个家庭对捐助的不同态度）：用对象分析法，说明三种态度各是什么，再写出两个立意；并写出题目对范围有什么限制。
  3. 2017年、2018年、2019年：每题写出任务句、写作对象或场合、限制条件各一句，不需要写全文。
  4. 2023年（完成典型例题1）：从三个立意里选一个，写成一句完整的判断，作为下一课“提出论点”的起点。
  5. 全国卷读写结合题：2023年新课标Ⅱ卷、2024年新课标Ⅱ卷的材料来自同一份试卷的阅读部分。各圈出任务句和限制词，再拟一个立意。
