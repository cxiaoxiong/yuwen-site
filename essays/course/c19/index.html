第四阶段 · 高考综合 · 第19课

高考题型与审题迁移

读题定题思辨

前面十八课，每一课解决一个具体问题。第四阶段不再讲新的知识，而是把它们放到真实的高考写作场景里用。

第四阶段的顺序是：

应题 → 适应任务 → 自评 → 修改

这一课只解决第一步：面对一道没见过的作文题，先做什么，再做什么，遇到什么情况该调用前面哪一课。

学习目标

  • 记住一个从读材料到选结构的流程，遇到陌生题能照着走。
  • 会用几个问题判断这道题的材料形态，不靠背题型名称。
  • 会找出材料的核心，并区分“核心”和“背景”。
  • 会读出写作任务，知道它对立意和结构的限制。
  • 能对一道真题说出：这道题该调用第1–18课的哪几课。

这一课讲什么

  1. 题型判断不背题型名称，用几个问题判断这道题的材料形态，决定调用前面哪几课。
  2. 抓核心从材料里找出真正要写的概念、关系或问题，删繁就简。
  3. 明任务读出身份、对象、范围和重点：这道题到底要你做什么。
  4. 典型题型样本用不同年份的真题，练一遍“读材料到选结构”的流程。

核心认识

  • 题型会变，流程不变。 一轮复习在分析2023年新课标Ⅰ卷时说，这道题“以极其概括的单概念‘好的故事’取代近两年流行的‘关系型’作文形式”。可见命题的形态每年都在变，靠背名称来应对，会落后。
  • 审题是一个流程，不是一个灵感。 一轮复习这一讲的标题是“精准审题——明类型，抓核心，重任务”；每道例题的分析，都固定看三处：材料含意、创设情境、写作任务。
  • 立意的质量，早在审题时就定下了基调。 一轮复习的说法：“一篇文章的优劣高下，其实早在审题立意阶段就定下了基调。”
  • 审题的目的是调用已有的能力，不是发明新的方法。

迁移流程

下面这条流程是本课整理的，它把前面的课串起来：

读材料 → 找核心 → 找关系 → 明任务 → 定立意 → 选结构

步骤 问什么 调用
读材料 几则？是现象、名言、概念、事件，还是图？材料自己有没有观点？ 第1课 审题四法
找核心 哪些词是必须写的？哪些只是背景？ 第1、7、15课
找关系 核心之间是什么关系？材料里有没有几种说法？ 第6、13、14、16课
明任务 谁写、写给谁、写什么、重点在哪？ 第1、20课
定立意 切题吗？聚焦吗？有深度吗？ 第1、6、22课
选结构 材料和任务提示怎样排？ 第3、9、17、18课

这不是七步、八步的固定套路。每一步花多少时间，看题而定；有的题第三步几乎不用，有的题第四步是关键。

子专题一：题型判断

用问题，不用名称

面对一道题，问这几个问题：

问 如果是…… 该想到
几则材料？ 多则 第6课：先判断几则之间是互补、求同、对比，还是因果
单概念，还是几个概念的关系？ 几个概念 第13课：抓关系；第15课：辨析概念、写条件
材料里有没有几种不同的说法？ 有 第11课 针对性；第17课 回应反方
有没有转折、条件，或者“但也有人”的句子？ 有 第14课 辩证；第15课 条件边界；重点往往在转折之后
是不是在问“为什么”“怎么办”？ 是 第16课 因果与追问
有没有明确的身份、对象、文体？ 有 第1课 读任务；第20课 适应任务
是图或漫画吗？ 是 第6课 寓意揭示

一道题可以同时对应几个问题。比如2019年的演讲稿题：有明确对象（同学），材料里有三种说法（要回应），要提“希望与建议”（有任务），所以要调用第11、17、20课。

一轮复习的分类：只作观察角度

一轮复习在这一讲里，分类型举了六道2021—2023年的真题。它点名的类型有：概念类（概念可以是单一的，也可以是二元或三重的关系）、读写结合类、名言类、漫画类，另外还有以热点事件或人物、古典名著情节等为载体的题。

这个分类的价值，是提醒你这几年的命题在哪些方向上变化：有的从其他试卷模块里衍生出来（2023年新课标Ⅱ卷），有的以两则语录并举（2023年乙卷），有的用一个故事或情节作载体。

但它不是一张需要背的表。原因有三：

  1. 一轮复习自己说，2023年新课标Ⅰ卷的“单概念”，正好取代了前两年流行的“关系型”。类别是随年份变的。
  2. 一道题往往同时属于几类：2019年演讲稿题，既是有明确任务的题，也是材料里有几种说法的题。
  3. 学生要做的，是判断这道题要调用什么能力，不是给它贴哪个标签。

对照使用

遇到陌生题，先问上面的七个问题；如果想对照一轮复习的分类，可以事后看一眼“这道题属于哪一类”，作为经验积累，不要在考场上先去归类。

子专题二：抓核心

材料的三层

一轮复习在每道例题里，都用“材料含意”一行，分析材料的层次。它大致做三件事：

  1. 看句子之间的关系。 例：2023年新课标Ⅰ卷的材料由两层构成：第一层列举“好的故事”的作用（列举末尾的“……”表示不完全列举，是“撬开想象的支点”），第二层“故事是有力量的”是总结，是主旨，“更是写作的关键”。
  2. 看转折的重点。 例：2023年全国甲卷“人们因技术发展得以更好地掌控时间，但也有人因此成了时间的仆人”。一轮复习的判断：这是一个转折复句，前半句陈述事实，后半句陈述现象，“命题强调的重点应当是后半句”。
  3. 看核心概念。 例：2023年新课标Ⅱ卷：第一句概述现象，第二句阐释，引出核心概念“自己的空间”，指出其意义——“放松，沉淀，成长”。

“元”：删繁就简

《新材料作文》第8讲把审题的核心叫作“元”，并指出：写不好的一个原因，是没有“厘清材料情境中的‘元’，在具体立意中没有‘切中’核心概念去立意，或挖掘的核心概念过多，将次要概念融入形成自我干扰，不够聚焦，导致‘元’的冗余”。

它的对策是：“细读材料快速定位核心关键词，精简元为一元、二元、三元，做到删繁就简”，然后“快速找到元与元之间的逻辑关系”。（这一讲的完整升格例，见第22课。）

三步检查

  1. 画出材料里的关键词。
  2. 把关键词分成“必须写”和“背景”。
  3. 核心不超过三个。超过，就再删。

子专题三：明任务

第1课讲过任务句怎么读。这里加一层：任务对立意和结构的限制。

一轮复习在每道例题里，有一行叫“写作任务”，它读出了几类限制：

限制 例 出处
范围 2023年新课标Ⅰ卷：要求围绕“故事是有力量的”写作 一轮复习
重点 同题：写作中要“重点凸显学生的‘联想和思考’” 一轮复习
身份 同题：“强调‘我’的存在，立足‘好的故事’对‘我’的影响” 一轮复习
选材方向 2023年新课标Ⅱ卷：“在学习、生活中”提供选材方向；“有时希望有一个自己的空间”限定了写作者的身份必须“有我在场” 一轮复习
对象与场合 2018年：写给2035年18岁的一代人；2019年：面向本校同学的演讲稿；2020年：班级读书会的发言稿；2017年：帮助外国青年读懂中国 站内真题

前面几项决定写什么，最后一项决定怎么写——这是第20课要讲的。

子专题四：典型题型样本

下面是不同年份的样本。每一行只写这道题在审题上的重点，和该调用的课。题目本身、范文和点评，见课程页的相关资源；2019 年以后的全国卷各卷作文题，全部在高考真题页，每道题都附审题提示。

同一道题的“一轮复习式”分析

以2023年新课标Ⅱ卷为例，看一轮复习怎样分析：

  • 材料含意：一句现象，一句阐释；核心概念“自己的空间”；意义是放松、沉淀、成长。
  • 创设情境：这是材料里给出的真实情境，试题让考生思考这个空间的意义。
  • 写作任务：“在学习、生活中”“有我在场”“围绕以上材料”。
  • 立意角度：角度一：青少年需要独立成长的空间（引议联结结构）；角度二：寻一方净土，让自己放松、沉淀、成长（总分总）。

这一套分析，用在任何一道题上，都是“材料含意→情境→任务→立意→结构”，与上面的流程一致。

方法步骤（合起来）

  1. 读材料：一句一句读，标出每句在做什么。
  2. 找核心：删到不超过三个。
  3. 找关系：多则、多概念、几种说法。
  4. 明任务：身份、对象、范围、重点。
  5. 定立意：用一句话写出，对照第1课的立意标准。
  6. 选结构：由关系和任务提示，选第3、9、17、18课里合适的。
  7. 写下调用了哪几课，作为提纲的第一行。

典型例题

例1　陌生题走一遍流程

材料（教学示例）：有人说，手写正在消失，不必再练；也有人说，手写让人慢下来，更值得珍惜。请写一篇文章，谈谈你的思考。

参考答案（示例）

读材料：两句，两种说法，相反。 核心：手写；（不必再练 / 更值得珍惜）。不超过三个。 关系：材料里有两种说法，需要判断，各自的条件是什么。调用第14、15、17课。 任务：“谈谈你的思考”，没有指定对象；文体自定，议论。 立意（示例）：手写的价值不在于“用不用”，而在于它带来什么，是否可以被别的方式代替。 结构：可以先承认“不必再练”有一定道理（第17课），再指出它忽略了什么，最后立起自己的判断（第9课 对照式或第3课 总分总）。

例2　2019年，看该调用什么

2019年的演讲稿题：材料写了三种不愿意劳动的说法，要求面向本校同学，倡议“热爱劳动，从我做起”，体现认识与思考，并提出希望与建议。请说出这道题该调用哪几课，各解决什么。

参考答案（示例）

第1课：读任务——演讲稿，对象是同学，要倡议、要有认识与思考、要提希望与建议。 第11课：针对性——回应材料里的具体说法，建议要具体。 第17课：回应反方——三种说法都是现成的反方。 第18课：谋篇——三个说法怎样安排：做成分论点，还是合并回应。 第20课：情境适应——演讲的语气和现场感。

例3　判断重点

“青年既要仰望星空，也要脚踏实地。”这句话重点在哪里？该调用哪一课？

参考答案（示例）

有两个核心：仰望星空、脚踏实地。“既要……也要……”是并存关系，重点不在其中一个，而在两者怎样兼得。调用第13课（并存关系）和第14课（辩证，不折中）。

常见错误

  1. 先想立意，再回头看材料。
  2. 只看材料的第一句，忽略转折之后的重点。
  3. 核心概念太多，立意散。
  4. 任务只看了文体，没有看范围和重点。
  5. 靠题型名称套方法，不看这道题实际要什么。
  6. 材料里明明有几种说法，一个也没有回应。

课堂小练

小练1　找重点

“技术让人们获取信息更快，但也让人们更难专注。”这句话的重点在哪里？

参考答案（示例）

转折句，重点在后半句“更难专注”。立意应围绕“技术之下如何专注”，而不是只夸技术。（对照一轮复习对2023年全国甲卷的分析。）

小练2　读任务的限制

2018年的题要求“想象它装进‘时光瓶’留待2035年开启，给那时18岁的一代人阅读”。这句话对写作有哪些限制？

参考答案（示例）

对象：2035年18岁的一代人；场合：时光瓶，若干年后才读；隐含文体：写给未来的人，可以是书信。它决定了称呼、语气，以及要介绍“我这一代”和对“你们”的期望（见第20课）。

小练3　写出调用的课

2021年《体育之研究》的材料里有“滥用其强”“勤自锻炼”。这两个词提醒你调用哪几课？

参考答案（示例）

第14、15课：材料自带条件。“强”不是无条件的好，要写清楚在什么条件下强是好事，在什么条件下反而变坏。

课后训练

  1. 选三道不同年份的真题，各走一遍流程，只写“核心、关系、任务、立意”四行，并写出该调用的课。
  2. 找一道你认为“很难分类”的题，说明：它同时涉及哪几个问题。
  3. 用“删繁就简”的办法，给2022年“本手、妙手、俗手”提炼核心，看一看是一元、二元，还是三元。
  4. 对照一轮复习对2023年四道题的分析，看它们的“写作任务”一行，各限制了什么。
