第四阶段 · 高考综合 · 第20课

情境与任务适应

读题定题段落与论证表达与修改

第1课教了怎样读任务句：身份、对象、场合。第19课说，任务决定“写什么”，也决定“怎么写”。这一课讲“怎么写”：同一个观点，进入不同的高考情境，表达和论证要怎样调整。

这一课不是文体课。演讲、书信、时评，在高考里只是议论任务的几种情境。导与练的一句话说得清楚：书信体“只是外在形式，其本质仍属于议论文”。所以这里不讲应用文的格式大全，只讲“情境变了，要调整什么”。

学习目标

  • 遇到有情境的题，先问五个问题，再动笔。
  • 会在演讲里写出听众和现场，又不牺牲论证。
  • 会写一封对象明确、语气合适的议论书信。
  • 知道从现实事件切入的议论文，先做什么、再做什么。
  • 会把同一个论点，改写成不同情境里的版本。

这一课讲什么

  1. 演讲有明确听众和现场感，适度呼告和互动，但观点和论证不能让位给“演讲感”。
  2. 书信对象明确，语气适合对象，回应对方的处境或疑问，格式只是外壳。
  3. 时评型议论从现实事件切入，先判断，再分析原因或影响，最后亮出立场。
  4. 同一论点，不同情境谁在说、对谁说、为什么说、用什么语气、回应什么。

核心认识

教材怎么说

必修下册第五单元“写演讲稿”：“演讲是在特定的情境中阐述观点，写演讲稿要对听众作分析”，“只有对听众的期待和接受能力有正确判断，才有可能决定内容取舍”；同时“要围绕主题深入分析，把道理讲透彻，让人信服”。必修上册第六单元“议论要有针对性”：“写议论文，还要有读者意识，这也是一种针对性”，写作前要想“我的文章是为哪些读者写的”。（原文见必修下册第五单元、必修上册第六单元的单元学习任务）

  • 情境不改变议论文的本质。 论点、论据、分析，仍然是骨架。情境改变的是：谁说、对谁说、怎么说。
  • 情境要为论证服务。 有了对象，论证才有针对性（第11课）；有了现场，论证才更有说服力。为了“像演讲”而写空话，或为了“像书信”而抒情，都偏了。
  • 五个问题。 这是本课整理的检查工具，写作前用：
问 问什么
谁在说 我的身份是什么？（学生、青年、班长、晚辈、“世纪宝宝”）
对谁说 听众或读者是谁？他们知道什么、关心什么、可能怎么想？
为什么说 我想让对方相信什么，或做什么？
用什么语气 对长辈、对同龄人、对陌生外国朋友，语气一样吗？
回应什么 现场、对方的处境，或现实中的问题、疑问？

子专题一：演讲

导与练的特点

导与练总结演讲稿有四个特点：

  • 针对性：根据听众的年龄、职业、文化层次、心理状态确定内容，有的放矢；
  • 情感性：感情真挚，昂扬饱满；
  • 鼓动性：议题与听众息息相关，使听众产生共情；
  • 临场性：预判临场状况，根据听众反应即时调整。

结构上，包括称谓、开端、正文、结尾。开端常用开门见山、设问提要、引用名言、运用事例等。

站内例：现场感是怎样来的

《让心中燃起劳动之火》（2019年）第二段：

“劳动究竟是什么？也许你我都难以精准概括。但请大家环视四周：那堆砌整齐的一砖一瓦，是工人们的劳动；那干净整洁的一道一路，是清洁工的劳动；那骄傲成长的一草一木，是园丁们的劳动……甚至连我们写下的一笔一划，也是各自的劳动。”

“请大家环视四周”，让听众自己看到例子，不是作者一个人说。这是用现场来做论据。

《劳则生欢，劳则生慧》（2019年）的点评：“开篇即表明自己的学生身份，并明确演讲对象为学生群体。行文中、结尾处亦有互动性的表达，演讲色彩浓。”

《以鲍叔为模，修青年品德》（2020年发言稿）的点评：“文中多处出现‘同学们’，还有‘在场的各位’‘吾辈青年’等，口语色彩浓，发言稿的现场感强。”

演讲不能牺牲论证

同一份点评还说，这篇“论证说理有深度”，“每个分论点均是从材料中引出来的”，“分析论证层层递进”；《让心中燃起劳动之火》的点评则指出，作者“在加强文采的同时，并没有走向华而不实，这是由于作者善于选择丰富而具体的素材”。

也就是说，现场感是加在论证上面的，不是代替论证的。 反过来，《一屋不扫，何扫天下》的点评说它“说理用例充分，层次分明”，但“思想深度挖掘不够，‘希望和建议’部分稍显薄弱”——演讲稿的文体规范了，论证的深度仍是评价的重点。

导与练的一个技巧：预判质疑

导与练收了一篇学生演讲稿《青春的燃料，时代的火炬》，里面有这样一句：

“或许有同学会说：在空调房里刷题也算奋斗？在实验室里重复失败也算奋斗？我想告诉大家……”

导与练的赏析：“从‘或许有同学会说’的预判质疑，到走廊晨读的场景白描，巧妙唤醒听众的日常体验。”这里的预判质疑，就是第17课的“反方回应”；在演讲里，它还有一个功能——让听众觉得你在回答他心里的话。

演讲的检查

  1. 有没有称呼、开场、结束，而且不是空壳？
  2. 至少有一处，让听众“在场”？（环视四周、请想一想、你们是否……）
  3. 有没有回应听众可能的疑问？
  4. 拿掉呼告和口号，论证还剩多少？

子专题二：书信

格式：只讲这一点

导与练说，一般书信有称呼语、问候语、正文、祝颂语、署名、日期六个部分。格式错误在阅卷中会扣分，但格式不是这一课的重点，也不需要背更多规则。

导与练的一句提醒更重要：书信体议论文，“编造小故事，营造小情调，总结小哲理，抒发小情感，但逻辑层面轻淡无力、肤浅贫乏的习作，必与高分无缘”。

三个要点

导与练的书信要求里，有两条最值得抓：

  • 材料意识：书信体议论文的论题比较集中，常常就“某件事”“某个问题”展开，要“紧扣材料的核心事件”。
  • 读者意识：写作时“预设读者，假想存在某个感情倾诉对象、意见交流对象”，对象可以具体，也可以虚拟。

另外，语言要“得体”：“对长辈要谦恭，对平辈要尊重”；“研讨问题要心平气和，请教求助要谦虚诚恳”。

站内例：三封信

《给十八岁的你们的一封信》（2018年）——点评：“作者个人身份定位和读者对象的设定很清晰，‘我’与‘你们’之间的身份切换很自如，内在的心灵沟通很平和畅顺，整篇文章都体现了跟预设的读者对象在进行着思想交流，读者对象感很清晰。”不足：“思考还不够深刻，最后的名人名言是谁说的不能坐实”。

《以青春芳华，谱写时代乐章——给2035年“18岁新一代”的一封信》（2018年）——点评：“开篇第一时间交代作者写作身份‘世纪宝宝’，明确写作对象‘18岁的新一代’”，“主体部分双向并行，既扣紧材料行文，又扣引导语”，“结尾再次点题，并回应任务”；不足：“缺乏一定过渡衔接”。

《给外国友人的一封信》（2017年）——点评：“读者意识鲜明”。一个细节值得看：

“你们或许感到惊诧：城墙难道不是战争的产物吗？是，但又不全是。”

作者预判了外国朋友会有的疑问，并回答了它。这是书信里的“回应对方的疑问”，方式与演讲里的“有同学会说”是一样的，也是第17课的反方回应。

书信里的“对方处境”

写给未来的人（2018年），对方不能回答，所以“回应处境”变成了想象对方的处境：你们的时代是什么样？“不需要‘请自觉排队’‘请勿随意扔垃圾’这些标语了吧？”（《给十八岁的你们的一封信》）想象要有依据，来自材料给出的时间线，不能空喊。

对比：《献给2035年的你》（2018年）的点评说它“对话意识较强，论述角度和对象比较明确”，“结构清晰”，不足在于“想象和思考还不够丰富和深刻”，“有些表达还不够严谨”。有了对象感，还要有想得深、说得准。

子专题三：时评型议论

资料从哪里来

时评不是高考作文规定的文体，但导与练选择性必修中册有专门的“时评写作”一课：

  • 特点：时效性、针对性、准确性、说理性、思想性（一轮复习的定义与此一致：时评是“对当前发生的新闻及新闻中的事实发表见解”）。
  • 结构：引—议—辩—联—结。引，概括材料，提出论点；议，分析事件的效果和原因；辩，用“诚然”“当然”一分为二地看；联，联系现实，由点到面；结，照应材料，深化论点。
  • 示范：用教材时评《以工匠精神雕琢时代品质》（必修上册第二单元）逐段标出这五步，并配有范文《莫让深情成羁绊》（未收入本站）。

另外，导与练《实践是检验真理的唯一标准》一课讲“时政评论类文体”的特点，要学习“破立结合和在演绎推理中展开论述”；《新材料作文》建议日常读报纸时评、网络新闻的评论积累论点。

本课这一部分较短，只做“从现实事件切入”这一件事。

四步

以下是本课整理的做法：

  1. 事件：用一两句话说清发生了什么，事实要准确（准确性）。
  2. 判断：对这件事作一个明确的判断，就是你的论点（针对性、思想性）。
  3. 分析：为什么会这样？会带来什么？——用第16课的因果与追问。
  4. 立场：你主张怎样？——如果有争议，用第17课 回应另一种看法。

站内例：从现象切入

《让心中燃起劳动之火》开头：“但揆诸当下，‘劳动无用论’却甚嚣尘上。因此，我希望借此次演讲，让同学们对劳动二字有更深刻的理解。”这是从一个现象切入，接着下判断，再分析。这不是时评，但它用了时评常用的入口：先说现象，再说为什么要谈。

提醒

  • 事件要真实，不能编。要用现实中的例子，先核实。
  • 事件只是入口。论证仍要落在论点上，不要写成新闻报道。
  • 不要把“时评腔”当作套话：一开头就是“近年来……”“随着社会的发展……”，往往什么也没说。

子专题四：评人物、评史事

2020年全国Ⅰ卷（广东卷同题）要在读书会上谈齐桓公、管仲、鲍叔中“感触最深”的一个。它是情境任务，也是一篇人物评论。导与练选择性必修中册有“史论写作”一课，正好用在这里。

导与练的说法

史论即历史评论，“是对历史人物、历史事件、历史现象等进行分析、评价的文章”。它从三篇课文里归纳出三条原则：

原则 意思 课文依据
论从史出，观点集中 观点依据客观史实；观点鲜明统一，不能自相矛盾 《五代史伶官传序》
叙述凝练，推论严密 叙述是选择性的，由评论的需要决定；层层推论 《六国论》
落脚现实，以古鉴今 评历史，是为了给今天以借鉴 《阿房宫赋》《六国论》

用到2020年的题上

  • 论从史出：只用材料给出的史实和你确实知道的史实。鲍叔“甘居其下”、司马迁“多鲍叔能知人”，都是现成的依据。
  • 观点集中：任务说只选一个人；选了鲍叔，就围绕“知人、荐贤、让位”写，不要三个人平均用力。
  • 叙述凝练：故事大家都读过，复述两三句就够，篇幅留给评价。
  • 落脚现实：听众是同学，最后要落到今天的青年能学什么（发言稿的现场感，见子专题一）。

导与练给这道题配的范文《荐贤助君得天地　让相为国霸春秋》选的就是鲍叔：先说三人都可敬，再说“最让我触动的当属……鲍叔”，然后用“胸襟博大”“情操高洁”等分论点展开，最后落到“新时代的青年”。（范文未收入本站。）

同一个论点，三种情境

下面用一个论点，示范情境怎样改变表达。论点：手写值得保留。（以下均为教学示例，其中“事件”为练习用的假设）

情境 谁对谁 开头示例 论证怎么调整
演讲 学生对全校同学 同学们，请你回想一下：上一次连续写满一页字，是什么时候？ 用听众的经验作论据；预判“打字更快”的疑问；有呼告和号召
书信 写给认为手写没用的朋友 小林：你上次信里说，手写太慢，不如打字。我想和你聊聊这件事。 回应对方的话，语气平等；用两人都熟悉的事例
时评 面向普通读者 某校（假设）恢复了每周一节书写课，有人说这是浪费时间。这件事值得一说。 先说事实，再判断；分析人们为什么有这种看法；再亮出立场

三个版本，论点相同：手写值得保留。不同的是：

  • 演讲用听众的经验说服；
  • 书信用对方的话说服；
  • 时评用事件和道理说服。

方法步骤（合起来）

  1. 读任务：身份、对象、场合、重点（第1课）。
  2. 问五问：谁在说，对谁说，为什么说，语气，回应什么。
  3. 定论点：论点不因情境而改变。
  4. 选一个“情境点”：演讲的现场，书信的对方处境或疑问，时评的事件。
  5. 写论证：论据和分析仍然是主体。
  6. 检查：把情境词拿掉，论证还站得住吗？

典型例题

例1　把书面语改成演讲

原句：劳动是创造财富的源泉，是实现人生价值的重要途径。

改成面向同学的演讲，要有听众，有现场，又不丢观点。

参考答案（示例）

同学们，我们每天走进的教学楼，每天踩过的走廊，是谁把它们打扫干净的？劳动不只是“辛苦”，它是我们眼前这一切的来源，也是我们能够站在这里的原因。 （观点：劳动创造价值，仍然清楚；用“教学楼、走廊”让听众在场。）

例2　书信的语气

下面这句写给长辈的信，语气有什么问题？“您的想法我觉得不对，现在都什么年代了。”

参考答案（示例）

语气生硬，缺少对长辈的谦恭。可改为：“我明白您的想法里有您的道理，只是想跟您商量一下，如今的情况和从前有些不同……” 先承认对方的道理，再提出自己的看法，这也是第17课的公平回应。

例3　给时评找事实

“近日，某地推行垃圾分类，居民纷纷抱怨麻烦。”这一句作时评的开头，够不够？

参考答案（示例）

不够。“某地”“居民纷纷”都太模糊，没有准确的事实（准确性）。要写出时间、事件、涉及的人或做法，读者才能判断你的评论有没有针对性。

常见错误

  1. 演讲稿只有称呼和口号，没有论证。
  2. 书信写成抒情小品，没有观点。
  3. 语气不分对象：对长辈、对同龄人、对外国朋友，一个口气。
  4. 对象只在开头出现，后面完全忘了。
  5. 时评开头空泛：“随着社会的发展……”
  6. 事件是编的，或说得含糊。
  7. 情境词很多，论点却变了。

课堂小练

小练1　找现场感

读《让心中燃起劳动之火》第二段，指出哪一句让听众“在场”，它证明了什么。

参考答案（示例）

“但请大家环视四周”。它用听众眼前看到的东西，证明“劳动就在你我身边”；现场感成了论据。

小练2　对方的疑问

读《给外国友人的一封信》，找出预判读者疑问的一句，说说作用。

参考答案（示例）

“你们或许感到惊诧：城墙难道不是战争的产物吗？是，但又不全是。”作用：让外国读者觉得作者在回答他们心里的问题，同时由此引到“长城作为贸易站”的论证。

小练3　换情境

把“读书要有所选择”写成一封给学弟学妹的信的开头，两三句即可。

参考答案（示例）

亲爱的学弟学妹们：你们刚入学不久，一定听到过“多读书”的鼓励。我想和你们商量的是另一件事：书太多了，怎样读，比读多少更要紧。

课后训练

  1. 读**《以鲍叔为模，修青年品德》**（2020年），标出发言稿的“现场词”，再说明去掉这些词，论证是否还成立。
  2. 比较**《给十八岁的你们的一封信》与《献给2035年的你》**：哪一封的“对方处境”写得更有依据？
  3. 选你写过的一篇作文，改成演讲稿的开头和结尾各一段，观点不变。
  4. 选一个近期的真实事件，用“事件—判断—分析—立场”四步写一个时评段。
  5. 用“手写值得保留”，或你自己的论点，写三个版本的开头，各三句。
  6. 全国卷情境任务：2019年全国Ⅱ卷五选一、2020年全国Ⅱ卷论坛演讲、2020年全国Ⅲ卷给高一新生的信：各写出身份、对象、文体和语气。
