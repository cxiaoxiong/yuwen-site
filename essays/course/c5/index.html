第一阶段 · 基础写作 · 第5课

文章塑形

谋篇表达与修改

文章的门面和收尾。这一课解决“基础可用”：标题看得懂，开头进得快，结尾收得住。

学习目标

  • 拟出一个扣题、明确、简洁、能体现中心意思的标题。
  • 写出一个不空泛铺垫、能快速进入材料并亮出观点的开头。
  • 写出一个回扣中心、回应材料、收束全文的结尾。
  • 通读全文，检查标题、开头、结尾是否指向同一个中心论点。

这一课讲什么

  1. 标题扣题、明确、简洁，能看出中心意思。
  2. 开头快速进入材料和任务，明确观点，不写大段空泛铺垫。
  3. 结尾回扣中心，回应材料或任务，收束全文，不机械喊口号。

核心认识

教材怎么说

必修下册第一单元“如何阐述自己的观点”：“意图清楚，观点明确，文章就容易有一个具体而鲜明的主旨。有些作文虽有观点却很空泛，这与写作意图不明有很大关系。”“几个方面说完后，适当作点小结，总结并强调自己的观点，起到加深印象或延伸思考的作用。”（原文见必修下册第一单元 · 单元学习任务）教师用书分析《劝学》：“基本上是每段阐述一个具体问题，而且总在文章的开头、结尾部分作出明确的交代”，第二段末句“君子博学而日参省乎己，则知明而行无过矣”“照应首句，收束了上文”。（课文见必修上册第六单元）

教材讲的是怎样阐述观点，没有专门规定开头、结尾怎么写。本课把它迁移到首尾：开头让读者尽早看清观点，结尾作小结、强调观点；《劝学》的“交代—照应—收束”就是课文里的现成样子。教材也没有专讲标题，标题的拟法来自一轮复习和本站整理，判断标准仍是“观点明确”。

  • 标题、开头、结尾，都是为中心论点服务的，三者说的应该是同一件事。
  • 开头的任务是尽快进入，结尾的任务是收束，都要短。开头“三五句成段”，结尾要像“豹尾”，简洁、明快、有力。
  • 塑形不是背模板。同一个开头方法，换一则材料就要换内容；套话读得再熟，用错了地方也没有分。

子专题一：标题

标准

先判断标题是否做到扣题、明确、简洁、能体现中心，再改，最后检查读者能不能看出你要证明什么。

三种基础拟法

一轮复习把这类标题称为“实力型标题”，它们直接亮出态度、观点和见解，让阅卷者一目了然。

拟法 做法 例（一轮复习引用的高考满分卷标题）
抓关键词，亮明观点 用材料的关键词，直接写出观点 品味美好故事，汲取奋进力量（2023新课标Ⅰ卷）；本固妙自生（2022新高考Ⅰ卷）
紧扣材料，亮出内容 标题里有材料的人、事、物、理，直陈观点 借技术之东风，做时间之主人（2023全国甲卷）
理顺思路，亮出层次 用提纲里的关键词，把文章的结构写进标题 听好·想好·讲好（2023新课标Ⅰ卷）

站内范文《学好本手，下出妙手，避免俗手》，标题本身就是一个完整的论点，一眼就能看出全文要证明什么。

两组对照：从话题到观点

原标题 问题 改成
《进步与退步》（2016，站内范文） 文章立意好，点评称它“能从寓意的角度立意”；但标题只给出两个词，读不出作者站在哪边 《鼓励进步，也给一时的退步留出空间》：直接用文章开头的中心论点，“一时的”限定了范围
《谈慈善》（本站虚拟的空泛标题） 只有话题，什么观点都装得进去 2013年站内范文《慈善需行之有道》《慈善，也要维护他人的尊严》：同一个话题，标题已经说出“慈善该怎样做”

改标题的办法：从开头找出中心论点那句话，压缩成一个短句。

带比喻、集句、押韵、热词的花式标题，等第12课学语言表达时再练。基础阶段标题清楚比漂亮重要。

容易犯的错

  • 标题只是话题词，读不出观点，如只写“故事”。
  • 标题和内容不一致，文章写的是另一回事。
  • 标题太长，或者太玄，读不懂。
  • 标题涵盖不了全文。站内范文《操故事巨椽，谱时代华章》的点评就说它“题目不精当，对文章的涵盖力不是太强”。

子专题二：开头

四个标准

导与练概括好开头有四点，基础阶段先抓前三点：

  • 准：准确点题，中心明确。
  • 短：简洁凝练，三五句成段。
  • 快：入题迅速，尽快点明观点或议论的话题。
  • 第四点“靓”（用修辞导入）等到第12课再练。

怎么写

一个稳妥的开头，做两件事：引出材料或任务 → 亮出中心论点。

先判断材料是什么，再选下面一种方法，最后检查有没有亮出观点。

方法 做法 效果
开门见山 开篇直接亮出观点 直陈观点，一语破的
引用材料 引材料 → 评材料 → 亮观点 紧扣材料，避免跑题、偏题
引用名言 引一句名言，再解释并亮出观点 有权威感，但要解释
设问开篇 提出问题，再作答，答案就是论点 引发思考

例（站内范文《学好本手，下出妙手，避免俗手》）：

围棋中的“本手、妙手、俗手”蕴含着无穷的生活智慧。本手是基础，妙手是创造，俗手损全局，故在生活中，我们应学好“本手”，下出“妙手”，避免“俗手”，方能走向成功。

引材料 → 点明启示 → 亮出中心论点，三句完成。

例（站内范文《故事的力量》，教师点评：开头“从读过的故事入笔，强调故事在人生中的重要性，再点明中心”）：从小到大我们读过的故事数不胜数……一个好的故事，自有它内在的力量。

例（导与练，设问开篇）：

你是否曾想过，在信息触手可及的今天，人类的问题会逐渐枯竭？……实则不然。答案的即时性恰似催化剂，在破解表象困惑的同时，又不断扩大认知的范围。

站内高考作文的四个开头

引材料原话 → 解释 → 亮论点（2021《强弱并非命定，人生由我决定》）：

毛泽东在《新青年》中指出:“生而强者不必自喜也，生而弱者不必自悲也。”生而强者未必是永远的强者，生而弱者未必是永远的弱者。强弱并非命定之数，人生的轨迹取决于我们个人。

点评：“开篇第一句引用材料中毛泽东……的话，并做具体分析，从而提出中心论点。”三句话，一句一个任务。

材料有几种做法，第一句就表态（2013《贫穷不坠其志，受助不忘奋斗》）：

三家人面临捐助的态度各有不同，而我更认同第二家人的做法。接受捐助，是对善意的感恩，声明偿还，则是不卑的态度，奋斗的志向，对未来的信心。

材料里三个家庭三种态度，作者不复述材料，直接选出一种并说明理由。点评说它“开头提出中心论点”。

先摆别人的看法，再亮出自己的观点（2014《数码时代更能唤起珍贵的记忆》）：

有人曾指出，科技发达的今天，人生过得越来越索然无味。人们纷纷怀念起黑白胶片的时代，以为它能收藏人生值得珍惜的瞬间。然而，愚以为，数码时代的技术，更能唤起许多永不褪色的记忆。

点评：“在讲述材料和一些人看法的基础上，开门见山表明了自己与之不同的观点。”有了对照，观点更醒目。

两句入题（2015《仰观宇宙，俯察万物》）：

伴随着现代科技的发展，人类得以借助电视、网络等手段认识自然。但若把科技当做感知自然的真正途径，在我看来，不免可悲。

第一句交代材料说的现象，第二句用“但”转出自己的判断。这篇没有教师点评，以上是本站的分析。

改一改：删掉与内容无关的句子

2023年站内范文《秉故事之炬，成磅礴之力》的开头：

青松寒不落，碧海阔逾澄。历史长卷徐徐铺开，好的故事宛如璀璨明珠，以其磅礴之力，促进表达沟通、触动心灵、启迪智慧，乃至改变一个人的命运，展现一个民族的形象……站在历史这头,吾辈应秉故事之炬，以成磅礴伟力。

教师点评：“开头‘青松寒不落，碧海阔逾澄’一句，与本文内容关系不大，有做作之嫌。”

改法（本站修改示例）：删去第一句，从“历史长卷徐徐铺开”写起。

为什么更好：第一句就进入材料的关键词，读者不用先猜这两句诗和故事有什么关系；文采要为观点服务，用不上的就删。

容易犯的错

  • 大段空泛铺垫，如“自古以来，人类社会不断发展……”，写了一大段还没进入材料。
  • 只引名言，没有解释，更没有亮出观点。
  • 开头很精彩，观点却不明确，甚至和后文对不上。
  • 观点和标题、分论点说的不是同一件事。

引用名言时，引文尽量不超过30字；引用之后要有一两句概括点评，点明核心话题。

子专题三：结尾

要求

导与练把结尾的要求概括为四点，这里先做前三点：

  • 结：归纳总结分论点，收束全文。
  • 扣：回扣材料、标题、中心论点。
  • 简：不拖泥带水，言简意赅。
  • 第四点“文”（用修辞增加文采）等到第12课再练。

三种常见问题

  • 冗长重复：把前文观点再说一遍，啰唆。
  • 虎头蛇尾：开头精彩，结尾草草收场。
  • 生搬硬套：结尾与全文内容不符，不协调。

怎么写

先判断全文的中心，选一种方法，再检查是否回扣中心。

方法 做法 例
总结归纳 总结全文，重申观点，常用“总之”“由此可见” 综上所述，贫困、疾病、失败、苦难皆不足惧，唯有丧失乐观精神才是致命的……乐观者定能直面人生，必会笑对风雨！（导与练）
首尾呼应 结尾照应开头，再次点明中心 开头“本手游刃有余，妙手才可练就”；结尾“以守正守拙为正道，练就出本手；以创新出巧为蹊径，幻化出妙手”（一轮复习，2022新高考Ⅰ卷优秀作文）
引言扣题 引与中心一致的名言，升华主题 “请党放心，强国有我”的青春誓言令人难忘……（导与练）
呼告号召 发出倡议，注意不空喊口号，要“融入时代，明确身份，情感真挚” 青年朋友们，请扛起肩头的责任，以踏实步履奔赴时代征程！（导与练）

祝福展望、巧用修辞等结尾，暂不训练。

站内高考作文的三个结尾

回扣中心（2013《贫穷不坠其志，受助不忘奋斗》）：

贫穷不坠其志，受助不忘奋斗。富翁施仁固然不是为了报答，但听到这个回答的时候，想必也是欣慰的吧。

先重申标题里的论点，再回到材料里的富翁。点评：“最后小结全文。文章首尾呼应，思路清晰……”

回扣材料（2016《分数不是衡量孩子的唯一标准》）：

要知道，一个孩子无论考了55分、61分、98分、还是100分，都值得他的父母，在他脸上留下爱的一吻。……

漫画里的四个分数、巴掌和吻，全部收回到一句话里。点评：“文章结尾表达期望，点到即止……”

联系现实，落到做法（2013《善行，我该如何安放你？》）：

……就必须行善者脱下救世主的眼镜，带上捐助对象的眼镜，扎根到他的世界中，问一句：“你需要什么，我们能共同努力改善些什么？”这才是有持久力量的真正慈善……

没有喊口号，而是给出一个具体做法：站到受助者那边，问一句他需要什么。点评：“以共同努力改善慈善的方式为愿望收束全文，回答了文章标题提出的问题。”

联系青年身份的结尾，见下面“典型例题”里的《学好本手，下出妙手，避免俗手》。

改一改：把口号换成回扣

题目：2021年新高考Ⅰ卷，毛泽东《体育之研究》谈强弱转化（见真题页）。

普通写法（本站虚拟，考场上很常见）：

青年朋友们，让我们不负韶华，奋勇拼搏，共创祖国美好的明天！

问题：换到哪一道题后面都能用；没有回到材料，也没有重申论点。

改后（本站修改示例）：

强与弱都不是命定的。生而强者，不把一时的优势当作永远的本钱；生而弱者，不把一时的差距当作终点。像材料里说的那样“勤自锻炼”，在日复一日的坚持中由弱变强，这是“体育之效”，也是我们这一代人成长的道理。

为什么更好：用材料原词“勤自锻炼”“体育之效”回扣材料；第一句重申论点；“青年”落到一个具体做法上，而不是一句口号。

容易犯的错

  • 只喊口号，没有回扣本文的论点。
  • 结尾引入了新话题、新观点。
  • 结尾重复前文，或者收得仓促。站内范文《操故事巨椽，谱时代华章》的点评说它“结尾有些仓促，不够有力”；《故事的力量》的点评说它“结尾重申故事的温度、内涵和力量，紧扣中心”，同时指出“结尾的收束力度不够”。

完整成文：通读三查

写完全文，从头到尾读一遍：

  1. 标题：能看出论点吗？
  2. 开头：有没有进入材料，亮出观点？
  3. 结尾：有没有回扣标题和开头的论点？

三个地方说的是同一个中心，文章才算“塑好了形”。

典型例题

例　2022年新高考Ⅰ卷

站内范文《学好本手，下出妙手，避免俗手》：

  • 标题：就是论点，扣材料的三个关键词。
  • 开头：引材料，直接亮出中心论点。
  • 结尾：“作为担当民族复兴大任的新时代青年，我们更应从中领悟‘本手、妙手、俗手’的智慧”，回到材料的三手，也回到青年的身份，再号召“打好基础，脚踏实地；敢于创新，出人意料”。

一轮复习的高分卷则用了另一种：开头写“本手游刃有余，妙手才可练就”，结尾回到同一句话，首尾呼应。

常见错误

  1. 标题只有话题词，看不出观点。
  2. 标题与全文对不上，或涵盖不了全文。
  3. 开头铺垫大段，迟迟没有进入材料。
  4. 开头只引名言，不解释、不亮观点。
  5. 结尾重复前文，或者引入新话题。
  6. 结尾只喊口号，没有回扣中心。

课堂小练

小练1　设问开篇

材料：随着互联网的普及、人工智能的应用，越来越多的问题能很快得到答案。那么，我们的问题是否会越来越少？请用设问开篇法写一个150字左右的开头。

参考答案（导与练示例）

你是否曾想过，在信息触手可及的今天，人类的问题会逐渐枯竭？当人工智能能在0.1秒内解答数学难题，当搜索引擎能呈现千万条现成答案，我们是否正在失去提问的能力？实则不然。答案的即时性恰似催化剂，在破解表象困惑的同时，又不断扩大认知的范围——每个已解之谜都会释放出更多待解的追问。

小练2　拟标题并写结尾

材料：有人总喜欢用自己的“尺子”去量别人，也有人总喜欢用别人的“镜子”照自己。用自己的“尺子”量别人量多了，容易失去朋友；用别人的“镜子”照自己照多了，容易失去信心。请拟一个标题，并写一个结尾段。

参考答案（导与练示例，仅供参考）

标题：在量度与映照间寻星河。结尾：与其执着于用僵化的“尺”去苛责他人的棱角，或沉迷于他人模糊的“镜”来否定自我的光芒，不如在心灵深处构筑一方澄澈天地……当“量度”与“映照”达成动态平衡，我们方能挣脱偏见的枷锁，在尊重差异、肯定价值的星河中，找到自己独一无二的坐标。

小练3　判断标题

比较下面两个标题，哪一个更能体现中心意思，为什么？

A. 关于本手、妙手、俗手　　B. 学好本手，下出妙手，避免俗手

参考答案

B。A 只是话题，读不出观点；B 直接亮出论点，标题就是论点句。

小练4　诊断并改写开头

材料：2023年全国甲卷，“人们因技术发展得以更好地掌控时间，但也有人因此成了时间的仆人。”（见真题页）有同学这样开头：

自古以来，人类社会不断发展，科技日新月异，给我们的生活带来了翻天覆地的变化。在这个伟大的时代，我们每个人都应该思考很多问题。

指出这个开头的问题，再用“引材料 → 亮观点”改写，三五句即可。

参考答案（本站示例）

问题：大段空泛铺垫，没有进入材料，也没有观点；换成别的科技题也能用。

改写：技术让我们能更好地掌控时间，可也有人被消息提醒、日程表和短视频推着走，成了时间的仆人。同样的技术，为什么有人掌控时间，有人被时间驱使？我以为，区别不只在技术，更在于人能不能守住对自己时间的主动权。

课后训练

  1. 用你在第2–4课写的分论点和主体段，补写标题、开头、结尾，再做“通读三查”。
  2. 2022年高考作文：站内同题范文有十篇，比较它们的标题，找出最扣题、最明确的一个，说明理由。
  3. 2018年高考作文题（时光瓶）：一轮复习引用的标题里有“上善若水，烟雨平生——写给2035年的你”，思考：这个标题是否扣住了任务里的对象和时间？
  4. 站内范文《操故事巨椽，谱时代华章》：读教师点评，为它重拟一个更能涵盖全文的标题，再改写结尾。
