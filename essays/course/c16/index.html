第三阶段 · 思辨进阶 · 第16课

因果、逻辑链与追问

段落与论证思辨

第11课教了分析句怎么写，第8课用追问拆过分论点。这一课把“分析”再往深里走一步：因果究竟是不是因果，链条上少没少一环，结论有没有说过头，怎样一层层追问下去。

链条上的位置：

分析句 → 概念关系 → 事理与逻辑链

这一课只在段与文的“说理”层面做训练，不做形式逻辑课程。反驳对方的推理漏洞，是第17课；把逻辑链当作全篇结构安排，是第18课；这里都不展开。

学习目标

  • 能区分先后关系和因果关系，能说出一个结果的多个原因和一个行为的多重结果。
  • 会把一段说理写成有中间环节的链条，不直接“跳步”。
  • 会用三个检查判断一段推理：前提、跳步、结论。
  • 会用“升、补、转”三种方法，写出事理链并点评。
  • 会用“是什么、为什么、怎么办”追问，并知道问完怎样进入论证。
  • 知道“四多”各指什么，能在自己的段落里各找一处。

这一课讲什么

  1. 逻辑链把“原因→中间环节→结果”“现象→危害→根源→办法”一步一步写出来，不从起点直接跳到终点。
  2. 逻辑推理三个检查：前提成不成立，推导有没有跳步，结论有没有超出前提。
  3. 事理链从事实提炼事理，写出推理链并点评：“升”“补”“转”三种用法。
  4. 三维追问是什么、为什么、怎么办；问什么，为什么问，问完怎样进入论证。
  5. “四多”一轮复习提升思辨的四个“多”：多发问，多用二元关系，多用环环相扣的推断，多用关联词。

核心认识

教材怎么说

选择性必修上册第四单元“逻辑的力量”：“规范的论证总是包含由多个判断构成的逻辑链条”；论证“往往不会详尽地呈现逻辑推理的每一个环节”，省略的隐含前提“只要有一个不成立，论点就值得怀疑”。教材举的日常逻辑错误里，“他出生时天昏地暗、飞沙走石，注定此生不凡”是强加因果，用14%的调查数据断言“大学生普遍缺少对传统文化的热情”是以偏概全。选择性必修中册第一单元“深化理性思考”：理性思考“要敢于质疑，勇于追问”。（原文见选择性必修上册第四单元、选择性必修中册第一单元）

  • 先后不等于因果。 “A 发生在 B 之前”，只是时间关系；要说“因为 A 所以 B”，要有理由。
  • 说理不能一步到位。 一轮复习指出，有些考生剖析事理，“直接从原因跨向结果，从起点跨向终点”，没有把步骤和道理“剖”开，就看不出说理。
  • 链条上的每一环，都要接得上。 一环接不上，整条链断。
  • 结论不能大于前提。 举了两个例子，不能得出“所有人都……”。
  • 追问是为了想透。 一轮复习的话：“以己昏昏，又怎能使人昭昭呢？”

子专题一：因果

不要把先后当因果

例（教学示例）：小王每次考试前都吃一个鸡蛋，成绩一直不错。“吃鸡蛋”在“成绩好”之前，但把它当作原因，需要理由。

导与练“议论文逻辑链”一课对论据与论点的要求是：这种关联是必然的，“而非主观臆想的、虚假的”。《新材料作文》论据一讲也说：议论文写作的思维过程是逻辑推理过程，前提——材料，必须真实确凿。

一个结果，多个原因

《新材料作文》审题一讲“由果推因法”的例题：游客打碎了房东的玻璃杯，打扫时把碎片和其他垃圾装进同一个垃圾袋。房东后来拒绝签租房合同，并把碎片挑出来，写上“玻璃碎片，危险！”

“为什么不租”，可以追问几个原因：游客打碎了杯子？打碎不是主要原因，房东当时说“不要紧”；把碎片混进垃圾袋，没有想到会伤到别人，才是。资料的判断是：他“意识不到碎玻璃和其他垃圾混在一起带给别人的潜在危害，证明其责任感不强”。

从这个例子可以学到，一个结果，可以列出几个原因，要分出主次：哪一个是引发的，哪一个是决定性的，哪一个只是背景。

原因之间有条件

一轮复习讲“转”时的例子：雷海为读诗夺冠。“读诗”是他的原因之一，但一轮同时提醒：“不是所有人都能幸运地从事自己热爱的事业”——“热爱”作为原因，是有条件的。

《新材料作文》的因果分析法：由事物发展变化的结果，推导出产生这种结果的原因。孟母三迁的分析，就是先追问“为什么孟母初居墓旁，孟子便每天只会学哭”，再回答“人有社会属性，一个人的发展方向与他所处的环境有直接联系”。

一个行为，多重结果

第8课已经讲过：结果可以并列，可以是好处，也可以是危害。这里补一点：把一个行为的结果排成“近期—长期”“个人—社会”，比单纯并列更有层次（见第14课的转换方向）。

因果自查

  1. 这是先后，还是因果？
  2. 原因只有一个吗？哪个是主要的？
  3. 原因成立有没有条件？
  4. 结果只有一个吗？

子专题二：逻辑链

资料里的两条链

第一条：问题链。 导与练“议论文逻辑链”一课：议论文行文遵循“提出问题—分析问题—解决问题”的思维逻辑链，围绕“是什么，为什么，怎么办”回答。

第二条：反例剖析链。 导与练在“反例剖析式”里给了一条链：“摆现象—析危害—挖根源—提方法”。示例（汉字书写等级标准）：

环 内容
摆现象 学生提笔忘字，不会写字；写字不规范
析危害 会影响思维的正确表达；影响社会交际
挖根源 电脑和网络普及，疏于提笔；社会重视不够
指办法 加强宣传；教师、家长带头；学校开设写字课

按资料的顺序是“危害在前，根源在后”。可以写成“现象→原因→影响→对策”，视论点而定，顺序可以调，环节不能缺。

“走两步”：原因→中间环节→结果

一轮复习讲“为什么”这一问，给了一个技法：“走两步”，即把事理的剖析路径分步展示出来，或从起点走向终点，或从原因导致结果，形成清晰的路线图和严密的逻辑推理链。

例：苏洵《六国论》：

  • 赂秦者：赂秦→力亏→破灭；
  • 不赂者：赂者丧→不赂者失强援→不能独完而丧。

因此，“原因→机制→结果”里的“机制”，就是中间的那一环、两环。

一轮复习里的短链

出处 链
《左传》 思→有备→无患
《易传》 变→通→久
毛泽东 侦察、思索→判断→决心→部署
学生习作《成功，在迷宫的那一端》 错误的判断→经验→正确的判断→成功
一轮材料 军队体恤士兵→士兵产生被尊重、关爱感→爱军、卫国→取得辉煌战绩

每一条链，都是每一环紧扣下一环；一轮复习的说法是“环环紧扣，严丝合缝”。

站内例：一条链，写了四环

范文《让爱双向流动》（2013年）第二段：

“当施舍者看到自己帮助的人懂得回报，哪怕不是对自己，而是对社会、他人，他已经看到自己所为的价值，这无疑让他产生了延续自己善举的动力。这是爱的付出，是爱的双向流动，也是爱的获得，社会因此受益。”

抽出链：受助者懂得回报→施者看到价值→产生延续善举的动力→爱双向流动→社会受益。五个环节，写在一段里，没有跳步。

而这篇文章第四段的反面例子，点评说“写得略嫌仓促，分析未够透彻”，正好是链条写短了。

站内例：一条链，写了三层

范文《融汇“本妙”，不落“俗套”》：

“正是一步步积蓄本手所体现的基础棋道，才能融会棋之义理于心中，下出画龙点睛、神来之笔的妙手。”

链：积蓄本手→融会棋理→下出妙手。“融会棋理”，就是中间那一环。没有这一环，“本手”到“妙手”就成了口号。

用关联词把链接起来

一轮复习“四多”的第四条：关联词语像“焊条”，可以把独立的句子焊成逻辑紧密的句群。例：一轮复习把陀思妥耶夫斯基的一段引文，改成了“要……就要……为什么要……因为只有……才能……”，形成“干大事业←有真本事←寂寞潜修”的链条，说教味变弱，论说力变强。

子专题三：逻辑推理

控制在高中议论文用得上的三个检查。

一查：前提是否成立

论点要成立，用来支持它的材料要真实、确凿，这是《新材料作文》论据一讲的要求。导与练“议论文逻辑链”一课的活动：一篇“既要温饱，更要环保”的作文，开头引卡耐基的名言，说“所谓幸福的家庭不是在物质上的丰富”，答案指出这是引用谬误：这句话围绕家庭幸福，和“环保”论点无关，引文与中心脱节。前提用错，后面的推导就靠不住。

二查：推导有没有跳步

同一篇现场作文写道：

“充裕的物质享受就像一副沉重的枷锁，严重地桎梏着人们，让他们深受其害，喘不过气来。事实证明，一个过分追求物质享受的人，必定是一个胸无大志的人，终究一事无成。”

从“充裕的物质享受”，到“过分追求物质享受的人”，到“必定胸无大志”，到“终究一事无成”：概念换了，环节跳了。答案对这篇作文的批评是：逻辑极端片面，忽视经济发展是生态治理的物质基础，违背辩证思维。

同一份答案还列了其余几处问题：行文缺少过渡，前文分析问题、后文谈做法，层次跳转生硬；自相矛盾，前后表述冲突；事例跑偏，赘述陶渊明的人格，没有扣住论点。（这里说的是文章的逻辑，怎样反驳这种逻辑，属第17课。）

三查：结论有没有超出前提

《新材料作文》分析概括一讲：概括时要尽量防止笼统浮泛，要防止“以偏概全”，要有量和态度的限制。例：从“中国女排经过顽强拼搏，终于又一次获得世界冠军”，可以概括出“经过顽强拼搏，可以取得成功”；“可以”和“必然”，程度不同。

也就是说：举两个例子，得不出“所有人都……”；一次成功，得不出“只要……就一定……”（限制的做法见第15课）。

补一步

发现断链，办法是补一步：

  • 原：读书使人进步，所以应该多读书。
  • 补：读书使人进步，因为读书让人接触到别人思考过的问题（中间环节）；所以，与其在原地琢磨，不如多读书。

子专题四：事理链

什么是事理链

一轮复习“聚焦思辨”讲“撬动思维”的第一条：作文题有时陈述的是一个事实，命题者要求的不是就事论事，而是从“特殊”推及“一般”，从“事实”中提炼出“事理”。其做法是：写出逻辑推理链，并给予点评。

三种用法：升、补、转（“升”“补”“转”）。

升：提升思辨的层次

从事实中提炼事理。一轮的例子：亚丁湾护航战士王新松突发重病，海军包机接回，他醒来后说“感谢祖国！”“等我好了，继续工作。”

逻辑推理链：军队体恤士兵→士兵产生被尊重、关爱感→爱军、卫国→取得辉煌战绩。

点评：由一个具体的事，看到“体恤士兵”与“战绩”之间的一般规律。

补：补全逻辑的链条

考生提炼出的事理，有时不成链条，“缺位”处，往往正是命题者预设的思维考量点。一轮的例子：清洁工与小偷殊死搏斗，动机是总经理经过时总说“你扫的地真干净”。

逻辑推理链：总经理给清洁工以赞美→清洁工产生被尊重感→爱上公司→主动与小偷殊死搏斗→保护了公司财产。

点评：中间的“被尊重感”“爱上公司”，正是补上的两环。

转：转换思维的方向

一轮的例子：外卖小哥雷海为读诗夺冠。

逻辑推理链：雷海为在苟且的生活中爱上诗词→用对诗词的热爱消解苟且，滋润生活→笑对生活→积极主动地为生活打拼→提升生活品位。

这一条链之后，再“转”：对于无法热爱又不得不接受的事物，不妨另辟蹊径。转向的方法，见第14课。

怎样练

  1. 读材料，用箭头写出它自己的链条（一句一步）。
  2. 检查有没有缺位的环节，补上。
  3. 再想：链条外面，还有没有没被说到的方向？
  4. 写一句点评：这条链证明了什么，为什么能证明。

子专题五：三维追问

一轮复习“聚焦思辨”以《六国论》为例，给了议论文构思的三个思辨维度：是什么、为什么、怎么办。

追问 问什么 为什么问 怎样操作 《六国论》里
是什么 界定概念，表明观点 要“精准”，要“独到” 五个思辨角度：向深处想（本质）、向前面想（原因）、向后面想（发展）、换角度想（新论）、合起来想（立体）；检验的标尺是“简明” “六国破灭，非兵不利，战不善，弊在赂秦。”着一“非”字推翻旧说，着一“在”字提出自己的观点
为什么 事物的结构、关系、规律、逻辑 议论文的魅力在理趣，功力在说理 “切一刀”：在“此与彼”“主与次”“内与外”“客观与主观”的交汇点上切入；“走两步”：把剖析路径分步展示 切成“赂者”与“不赂者”两个阵营；分别走出两条链
怎么办 亮出实招，解决实际问题 空喊口号无用，“一打宣言不如一个行动” 一联二思三亮：联系生活实际，反思当下，亮出合情合理合法合乎实际的措施 重用谋臣、礼贤下士、六国联合三策

一轮的说法：思辨“是什么”“为什么”，是“知”；思辨“怎么办”，是“行”。

问完，怎样进入论证

每一问的答案，是一个观点句，之后接第4课的材料、分析、小结：

  1. 问：是什么？ 答出一句界定或判断，作为观点句。
  2. 问：为什么？ 答出的原因或关系，拆成链条，就是分析句的骨架。
  3. 问：怎么办？ 答出的措施，落到可以做的事上，再用材料证明它可行。

一轮复习的例：三探

一轮的范文《认同传统向未来》，用“三探”行文：探寻“认同什么”，探明“为什么要认同”，探索“怎么来认同”。点评：“先后用了多个问号和疑问词，不断地追问，一步步地将对……的思辨推向了深入。”

注意：把三维追问整篇当作文章的框架，属于谋篇（见第18课）。这一课只练每一问怎样问透。第8课里用追问拆分论点，这一课往下走一步，看每一问自己的链条。

一轮复习的例：怎么办的落实

一轮的例子里，《蝶变春风最喜人，明年春色倍还人》（2022年全国乙卷）的片段，连发两问，前者向内，聚焦“‘小我’在‘大我’中如何自处”，后者向外，聚焦“‘小我’对‘大我’如何助力”，然后分别回答。点评认为，“两问”“两答”体现了对“强身与强国”辩证关系的思辨。

子专题六：“四多”

一轮复习“聚焦思辨”提升思辨能力的四个“多”，含义明确，每条有例子。以下忠实转述，不另加发挥。

四多 意思 一轮里的例子
多用疑问词、疑问句发问和追问 用“是什么”“为什么”“怎么办”三维发问追问，先把问题抛出来，倒逼自己想通、捋清 2022年全国乙卷片段，连发两问
多从包含“二元”乃至多元关系的视角切入 摆脱“一元论”线性思维，从二元、多元关系看事物和事物之间的关系，不提“非此即彼”的论断 2022年全国甲卷《灵活变通，三“用”互成》
多使用环环相扣的推断或推理句子 不要一步到位，把事理的剖析路径分步展示 “思→有备→无患”“变→通→久”，毛泽东的推理链，《成功，在迷宫的那一端》
多使用凸显逻辑关系的关联词语 关联词像焊条，把句子焊成紧密的句群 陀思妥耶夫斯基引文的升格

与本课其他内容的对应：第一多对应“三维追问”；第二多对应第13课；第三多对应“逻辑链”；第四多对应“用关联词把链接起来”。

方法步骤（合起来）

  1. 看因果：先后还是因果？原因有几个、哪个主要？
  2. 写链：用箭头写出“原因→中间环节→结果”，或“现象→危害→根源→办法”。
  3. 查三处：前提成立吗？有没有跳步？结论有没有大过前提？
  4. 补环：缺了哪一环，补一步。
  5. 追问：是什么、为什么、怎么办，各答一句。
  6. 焊句：用“因为……所以”“只有……才”“如果……那么”把句子接起来。

典型例题

例1　补链

材料：老师在班会上公开表扬了一位平时不起眼的同学，那位同学后来主动担任了值日组长。请写出一条逻辑推理链，并点评一句。

参考答案（示例）

链：老师公开表扬→同学感到被看见、被认可→愿意为班级做更多→主动担任值日组长。 点评：中间“被认可”一环，是“被表扬”和“主动担当”之间的关键。（对照一轮的“清洁工”例。）

例2　查跳步

下面一段有哪些问题？请改写：“很多成功的人都爱读书，所以只要爱读书，就一定会成功。”

参考答案（示例）

问题：由“成功者爱读书”（部分）推出“爱读书就一定成功”（全体）；把“必要条件”当成“充分条件”；“一定”超出了前提。 改写：许多成功的人都爱读书，读书让他们不断更新认识，这是成功的条件之一。

例3　三问

材料：某小区在楼梯间装了“爱心书架”，但没有人借书。请用“是什么、为什么、怎么办”各追问一句，并给出一个答案。

参考答案（示例）

是什么：这是一个“有设施、无参与”的现象。 为什么：借书没有登记、没人管理、书目不合居民需要。 怎么办：一联：联系其他小区的做法；二思：先做一次居民需求调查；三亮：设立志愿者值班，按调查更换书目。

常见错误

  1. 把先后当因果。
  2. 一步到位，原因直接跳到结果。
  3. 链条缺一环，读者接不上。
  4. 只有一个原因，没有分出主次。
  5. 举了个别例子，得出“所有”“必然”。
  6. 前提错了，引文与中心脱节。
  7. 只有问号，没有回答；或者追问没有落到论证。
  8. 关联词乱用，“因为……所以”里没有因果。

课堂小练

小练1　写链

读范文《让爱双向流动》第二段，写出那条链。

参考答案

受助者懂得回报→施者看到自己所为的价值→产生延续善举的动力→爱的双向流动→社会受益。

小练2　补一环

下面这条链缺了哪一环？“大量阅读→写出好作文”。

参考答案（示例）

缺：大量阅读→积累语言和思想→在表达中调用→写出好作文。“积累”“调用”是中间环节。

小练3　三个检查

用三个检查看这一句：“网络让人变得肤浅，所以网络必须被禁止。”

参考答案（示例）

前提：“网络让人肤浅”是否成立，没有证据。 推导：从“肤浅”到“必须禁止”，跳过了“是否有其他解决办法”。 结论：“必须禁止”远大于前提。

课后训练

  1. 读**站内范文《融汇“本妙”，不落“俗套”》**第二至四段，给每一段写一条链。
  2. 读**站内范文《进步与退步》**第四段，写出“不仔细推究其中的原因所在”一句的链条，说明哪一环是关键。
  3. 选一则一轮复习里的材料（王新松、清洁工、雷海为），按“升、补、转”各写一条新的链，并各写一句点评。
  4. 用《六国论》里“切一刀，走两步”的方法，分析一个你熟悉的现象（比如“手机依赖”）。
  5. 选一篇你写过的主体段，用“三个检查”找出一处跳步，用“补一步”改写。
  6. 找出你的一篇作文里的“因为……所以”，检查是否真的是因果。
  7. 全国卷追问题：2024年新课标Ⅰ卷问“我们的问题是否会越来越少”，顺着“为什么”追问两层，写出你的判断；2023年全国甲卷：人为什么会成为时间的仆人？
