第四阶段 · 高考综合 · 第22课

修改与升格

表达与修改

第21课的检查表找出了“否”。这一课回答：找到问题以后，先改哪里，怎样改。

这一课不重讲第1–18课。它只做一件事：把前面学过的方法，按一个顺序，用在一篇需要修改的文章上。

学习目标

  • 记住修改的顺序，不从语言开始。
  • 会诊断一篇文章的问题在哪一层：审题、论点、论证、结构、语言。
  • 会用“前后对照”的方式，改论点、改论据、补逻辑、调结构。
  • 会用“分点成文”把立意、分点、段落、全文连起来。

这一课讲什么

  1. 修改原则先改大问题，后改小问题；修改服务中心论点和任务，不只修辞藻。
  2. 论点优化原论点 → 问题 → 修改后：聚焦核心，删繁就简。
  3. 论据强化只有材料 → 加分析 → 更有效；删掉冗余，选贴合的而不是新奇的。
  4. 逻辑完善跳步 → 补中间环节，补过渡。
  5. 语言锤炼只做修改应用：删空话、改不准的词，语言的细项见第12课。
  6. 架构调整段落顺序改变后为什么更合理：从事例并排到问题—原因—办法。
  7. 审题升格沾边立意 → 切题立意 → 更有深度的立意，不设唯一标准答案。
  8. 分点成文立意 → 分点 → 段落 → 全文，把前面的方法合起来用。

核心认识

教材怎么说

选择性必修下册第四单元“文章修改”引叶圣陶的话：修改文章“其实就是修改思想，要把它想得更正确，更完美”。教材给出的顺序是：“修改文章首先要完善立意”，基本观点和“各部分的小观点”错误、片面或不够鲜明，就要提炼完善；“其次要增删材料”；“最后要调整结构”，包括先写哪些、后写哪些，层次段落和过渡接应；“还要推敲语言”。（原文见选择性必修下册第四单元 · 单元研习任务）

  • 修改不是把句子写漂亮。 一篇文章的问题，如果出在审题或结构上，改语言只是在原地打转。
  • 顺序是：

先审题 → 再论点（含分论点）→ 再论证（材料与分析）→ 再结构 → 最后语言

这个顺序以教材为根：教材的“完善立意”，本课拆成审题、论点两步；“增删材料”，本课扩成论证（材料够不够、有没有分析）；后两步和教材一样。它也和《新材料作文》第8讲的两个升格例一致：一个从“审题”入手（40分升到53分），一个从“分点”入手（45分升到56分）；两个例子都没有把语言当作第一步。

  • 大问题改对了，小问题会自己消失。 《新材料作文》升格例的再评：“全文更改面积很大，只因论点立意全部变化。”立意变了，原来的很多句子就不需要了。
  • 修改必须服务中心论点和任务。 每改一处，都要问：这一处改了以后，中心论点更清楚了吗？任务完成得更好了吗？

子专题一：先诊断，再动手

两种“病”，两种药

《新材料作文》第8讲里，两篇考场作文的“病”不同：

40分左右的作文 45分的作文
材料 叶夫图申科：世界上不存在没有意思的人 “蹄疾步稳”
病症 核心概念太多，论证散乱，“元”冗余 事例丰富，但没有分论点，缺少骨架
出在哪一层 审题（立意不聚焦） 论点（没有分论点，缺骨架）
药 审题升格：删繁就简，聚焦核心 分点成文：设分论点，删冗余事例

所以修改的第一步是诊断：这篇文章的问题，出在哪一层？

三栏修改单

动笔前，先填一张三栏表（本课整理）：

问题 在哪一层 怎么改（调用哪一课）
立意有五条，散 审题 找“元”，删到一到三个（第19课）
没有分论点 论点 设计分论点（第8、18课）
例子后面没有分析 论证 加分析句（第4、11课）
从A直接到B 论证 补中间环节（第16课）
段与段接不上 结构 调顺序、补过渡（第18课）
有“假大空”的话 语言 删或具体化（第12课）

子专题二：审题升格与论点优化

一个完整的升格例

材料：

“世上每个人都特别有意思，他们的命运就像行星的历史，每颗星有自己独有的一切，星际再也没有类似的世界。如果有人一辈子都很平凡，而且和平凡生活相处甚安，那么他的这种不引人注目，正是他在人间的有趣之处。”（叶夫图申科《世界上不存在没有意思的人》）

考场作文《安于无声听惊雷》，评价见第21课。升格作文《有味清欢，乐得平凡》。

先看材料，找“元”。 《新材料作文》的归纳：材料的“元”是“有意思（独特、有趣）”和“平凡”，从中要找到“独特有趣”和“平凡自安”之间的二元关系。考场作文的关键词有“每个人”“独有的一切”“再也没有相似”“一辈子平凡”“不引人注目”，一共太多。

再对比立意：

考场立意 升格后立意
一、生活不在于华丽，而在于从平实中孕育出美好 一、每个人都独特且有趣，但每个人也很平凡
二、和平凡生活相处甚安，其实也是一种幸运 二、与平凡生活相处甚安，是一件极有趣味之事
三、不引人注目不代表千篇一律，也可能是返璞归真的独特；平凡不代表平庸，也可能是默默无闻的伟大奉献 三、再平凡，也是限量版，能奋进且自洽的平凡最珍贵
四、真正的伟大，即在于以脆弱的凡人之躯而具有神性的不可战胜 —
五、生活就是于无声之处能有惊雷的坚强与惊艳 —

再对比标题： 《安于无声听惊雷》→《有味清欢，乐得平凡》。

《新材料作文》的对策归纳：

  1. 细读材料快速定位核心关键词，精简元为一元、二元、三元；
  2. 快速找到元与元之间的逻辑关系；
  3. 标题设置贴合元，不在核心概念之外随意化用；
  4. 小观点呈现三组即可，不必枝蔓。

升格的结果： 综合得分由40分左右，升到53分。（这里的分数是《新材料作文》一位教师的赋分。）

“原论点 → 问题 → 修改后”

论点优化就是做这样的三栏对照：

原论点 问题 修改后
生活不在于华丽，而在于从平实中孕育出美好（《新材料作文》） 没有扣住材料的两个核心——“独特有趣”和“平凡”，偏向了别的话题 每个人都独特且有趣，但每个人也很平凡（《新材料作文》）
网络不好（教学示例） 绝对化，没有条件（第15课） 网络本身不好不坏，关键看怎样使用（第14、15课）
成功需要努力（教学示例） 太泛，谁都同意，没有针对性 在快速变化的环境里，努力的方向比努力的强度更先决定成败（更具体，更有针对性）

沾边 → 切题 → 更有深度

“蹄疾步稳”的例子，可以看出立意的三个层次（本课分析示例，不代表唯一立意，也不代表唯一的升级路径）：

层次 立意 说明
沾边 做事要努力（教学示例） 材料里没有的词，只是“沾”了个边
切题 蹄疾步稳，方能行远；贪快念稳，事与愿违（考场作文） 回到了材料，但基本是把材料的话重复了一遍
更有深度 蹄疾与步稳看似矛盾，怎样兼得？——小步快走（升格作文） 提出了问题，并给出了自己的解决方案

“小步快走”只是升格作者的一个答案，不是“标准答案”。同一个问题，还可以有别的解决办法。升格的方向不是往“唯一正确”走，而是往“聚焦、有推进”走。

子专题三：论据强化

三步：只有材料 → 加分析 → 更有效

第4、11课已经讲过，论据后面要有分析。这里是修改时的三个动作：

  1. 删：不贴合的、重复的、枝蔓的，删。
  2. 补：每个保留下来的材料后面，补一句分析，说明它怎样证明论点。
  3. 换：如果材料与论点不贴合，换一个贴合的，而不是换一个“新奇的”。

（教学示例）

原：袁隆平研究杂交水稻几十年，成了“杂交水稻之父”。

加分析：袁隆平几十年不改研究方向，正是因为他把水稻的产量看作比个人名誉更重的事。他的坚持，不是固执，是对目标的看重。

更有效（再加一句小结，回到论点）：目标看得重，坚持才有方向。

站内和升格里的提醒

  • 删冗余：《新材料作文》：“分点前删掉不必要的冗余素材，让文章瘦身。”“蹄疾步稳”的考场作文超过千字，升格后“九百字左右，彻底完成了‘瘦身’”。
  • 不枝蔓：叶夫图申科的升格再评：“对于二舅的例子不枝蔓，回归到‘平凡’‘独特有趣’的二元上来。”
  • 贴合，而不是求新：同一评语：“最后用陶潜的事例贴地飞行去论述，材料贵在贴合而不是一味求新。”
  • 旧例子，新阐发：《新材料作文》第8讲建议：“着重克服论据陈旧问题。平时要注意挖掘课本中的例子作为论据，善于对旧例子从意义、作用等方面进行新的阐发。”
  • 引用要可查证：站内两篇点评，都指出了名人名言的出处“不能坐实”（第21课）。不确定的，宁可不用。
  • 确凿：《接受帮助，报以帮助》的点评指出“用例的‘确凿性’有待提高”。

子专题四：逻辑完善

跳步 → 补中间环节

第16课讲过：说理不能一步到位，链条上的每一环都要接得上。修改时，就是把链条写出来，找缺的一环：

（教学示例）

原：手机让人分心，所以应该禁止学生带手机。

链：手机让人分心 → （缺）→ 应该禁止

补：手机让人分心，影响听课效率；但分心的原因是不受约束的使用，而不是手机本身；所以更合理的做法是限制使用的时间和场合，而不是一概禁止。

补过渡

站内点评指出的一个常见问题是缺乏过渡衔接（《以青春芳华，谱写时代乐章》，2018年）。这篇文章的结构是：第二段写“世纪宝宝”的际遇，第三段寄语2035年，第四段写“使命和挑战”，第五段又寄语2035年。虚实交错，但衔接有断。

修改办法（本课建议，点评没有给出具体改法）：在段与段之间，加一句“承上启下”的话，说明为什么现在从这一层转到那一层。比如第四段开头，可以用一句话说明：“正因为一代人有一代人的使命，所以你们的使命是什么，值得我们此刻想一想。”

对照《接受帮助，报以帮助》：第三段的尾句，就是第四、五段的总起（第18课）。

一组段落对照：《既要温饱，更要环保》（导与练）

导与练选择性必修中册“议论文逻辑链”活动6，把一篇现场作文的两段和升格稿并排，标出五处修改：

现场稿的问题 升格稿怎么改 在哪一层
引桃乐丝·卡耐基谈家庭幸福的话，和“环保”无关 换成爱因斯坦谈人们追逐物质的话 论证：引文与中心脱节
“充裕的物质享受就像一副沉重的枷锁……必定是一个胸无大志的人” 改成“充裕的物质改善了民生，但美好生活，离不开宜居的自然环境” 论证：说过了头，全盘否定物质发展
前面分析问题，后面直接谈做法 加一句“那么，怎样做到‘经济发展与生态保护协同共进’？” 结构：缺过渡
一边写人类“疯狂索取、贪婪享受”，一边又“诗意地栖居” 改成“统筹合理开发与生态养护”，再谈“诗意地栖居” 论证：前后自相矛盾
用一大句写陶渊明的人格和历史评价 改成“与自然和谐共生的梦想，自古及今未曾改变”，再落到今天 论证：事例跑偏

五处修改，四处在论证，一处在结构，没有一处是单纯换个漂亮词。这也说明，教材把“增删材料”放在“推敲语言”前面，是有道理的。

子专题五：语言锤炼

第12课已经讲了准确、严密、形象、简洁。这里只做修改应用：

修改语言的顺序（在前面的步骤都完成以后）：

  1. 删：假、大、空的话，去掉以后论证还在的，就是多余的。
  2. 改：不准确的词。例：《给外国友人的一封信》的点评，建议把“象征”改为“见证”，更准确。
  3. 顺：生硬、不通顺的句子。例：点评多处指出“个别语句不够通畅”。
  4. 省：升格再评：首段删掉“迟子建”等人名，“让句子显得干净流畅些”。

这几项都不需要“写得更漂亮”。语言的修改，是让意思更准，不是让辞藻更多。

子专题六：架构调整

例：“蹄疾步稳”，段落怎样重排

《新材料作文》第8讲的考场作文与升格作文，可以对照着看它们的段落功能：

考场作文（45分） 升格作文（56分）
开头：写《八骏图》，说蹄疾步稳方能行远 开头：孟郊与颜斶的对比，提出“怎样才能做到蹄疾步稳”
王安石变法的事例 说明为什么要兼得（蹄疾而步不稳、步稳而不快，各有后果）
爱迪生、清朝的事例 如何求：两大要素——主观心理、客观方法
王选、布鲁诺的事例 小步快走：步幅与步频
结尾：良马与劣马，蹄疾步稳 心态与急迫感；疫情防控的例子；总结

为什么升格后更合理（本课分析）：

  • 考场稿是事例并排：每段一个人物，换了顺序也不影响意思；
  • 升格稿是问题—原因—办法：先提出“兼得是矛盾”，再讲“为什么要兼得”，再讲“如何求”，每一段回答前一段留下的问题，换了顺序就读不通了。

《新材料作文》对升格的评价：“想要‘蹄疾’就容易‘步不稳’，而追求‘步稳’又容易‘跑得慢’，面对这一问题，升格作者指出‘小步快走’这一解决之道……通过对两个分论点的拆分，避免了作文无序的素材堆砌，又指出了矛盾的根本解决之法。”

另一个方向：删

《给外国友人的一封信》的点评说，文章对第三个关键词“高铁”的阐释相对简略，“如只选择前两个关键词行文，全文内容将更为集中深入”。架构调整不一定是加，有时是删掉一个写不透的部分。（第18课：结构越复杂，每一部分越写不透。）

三个调整的问题

  1. 这一段删掉，后面接得上吗？
  2. 两段交换位置，读得通吗？
  3. 每一段是回答上一段留下的问题吗？

子专题七：分点成文

流程

立意 → 分点 → 段落 → 全文

步骤 做什么 资料
立意 用一句话写出中心论点 《新材料作文》第8讲：审题升格
分点 把中心论点分成二到三个分论点 《新材料作文》第2讲：拟写分论点的三个角度——阐述内涵（是什么）、问一个“为什么”（分析原因）、提出策略（怎么样）
段落 每个分论点写成一段：观点句、材料、分析、小结 第4、11课
全文 开头亮出问题，段与段之间有过渡，结尾回扣 第5、18课

《新材料作文》的分论点例

中心论点：舍弃一些东西，人生会更加美好。

  • 分论点①：舍弃，是寄情山水、不与世俗同流合污的飘逸之风；
  • 分论点②：舍弃，是悠然心会、自得其乐的和谐之风；
  • 分论点③：舍弃，是重振旗鼓的豪迈之风。

（各配以李白、陶渊明、勾践的事例。）句式：“中心论点中的关键词语+是（就是）……”。

分点的三个要求

《新材料作文》第8讲的对策：

  1. 分点前删掉不必要的冗余素材，让文章瘦身；
  2. 分点要贴合情境，在分的过程中应厘清元之间的关系；
  3. 切分之后的小观点要有一点设计感，可利用成语或基本对仗的句式。

提醒

  • 不要为了“设计感”凑对仗：内容不清楚，形式再整齐也没有用。
  • 分点是为了让事例被使用，不是为了显得有条理。

方法步骤（合起来）

  1. 诊断：填三栏修改单，找到问题在哪一层。
  2. 审题：核心对不对？任务完成了吗？
  3. 论点：能用一句话说清吗？有没有条件？分论点有推进吗？
  4. 论证：材料恰当、典型吗？删冗余，补分析，补中间环节。
  5. 结构：先写哪些、后写哪些？段落有功能吗？补过渡。
  6. 语言：删空话，改不准的词，顺不通的句。
  7. 通读：最后从头读一遍，确认没有因为改动，引出新的断裂。

典型例题

例1　诊断

一篇作文：开头引了一段名人名言，主体五段各写一个人物，每段末尾是“这告诉我们要坚持”。请诊断问题，并给出修改顺序。

参考答案（示例）

问题：没有分论点（论点）；每个人物后面的分析相同（论证）；可能没有紧扣材料（审题，需要核对）。 顺序：先核对审题；再确定中心论点，设计二到三个分论点；把五个人物合并、删减；每段写不同的分析；最后处理语言。

例2　改论点

“读书很重要”作中心论点，有什么问题？请改。

参考答案（示例）

问题：谁都同意，没有针对性，也没有条件。 修改：与其把读书的重要性说得更多，不如说清楚它在什么条件下重要——比如“在信息碎片化的时代，整本书的阅读，是训练持续思考的少数方式之一”。

例3　分点

中心论点：坚持要有方向。请分成两到三个分论点，用“是什么、为什么、怎么办”。

参考答案（示例）

①方向是坚持的前提：没有方向的坚持，只是原地打转（是什么）。 ②方向错了，越坚持越远（为什么）。 ③经常回头看，及时校准（怎么办）。

常见错误

  1. 一上来改句子，不查审题。
  2. 改了很多，问题还在：没有先诊断。
  3. 立意越改越多，不是越改越聚焦。
  4. 分点只是把材料重新分了组，没有分论点。
  5. 加分析时重复材料，没有新意。
  6. 补过渡补成套话（“接下来，我们再来看……”）。
  7. 修改后没有通读，产生新的断裂。

课堂小练

小练1　填三栏修改单

读下面两个问题，填“在哪一层”：（a）“整篇文章有六个例子，没有分论点。”（b）“‘象征’一词用得不准。”

参考答案

（a）结构；（b）语言。

小练2　改论点

“网络让人变得肤浅。”请改写，使其有条件，并有针对性。

参考答案（示例）

网络本身不决定人是否肤浅；决定的是使用方式——当阅读只剩下碎片化的浏览，思考才会变浅。

小练3　删

读《给外国友人的一封信》，说一说，如果按点评的建议只保留两个关键词，哪一段可以删？

参考答案（示例）

第五段（讲“高铁”和创新）。保留“长城”“一带一路”两个关键词，主题“谋求合作与发展”更集中；结尾再简略呼应创新即可。

课后训练

  1. 选你最近的一篇作文，填一张三栏修改单，至少写五项。
  2. 按修改顺序改这篇作文，写出改前改后各一份“立意 + 分论点”的提纲。
  3. 找一个你写过的论据，做“只有材料 → 加分析 → 更有效”三步改写。
  4. 读《新材料作文》第8讲的两个升格例，各写出一句话总结：升格靠的是什么。
  5. 对比：把改前和改后各读一遍，看“中心论点更清楚了吗”“任务完成得更好了吗”。
