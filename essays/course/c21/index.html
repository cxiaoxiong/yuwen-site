第四阶段 · 高考综合 · 第21课

阅卷标准与自评

表达与修改

第19课教你怎样应题，第20课教你怎样适应任务。这一课站到另一边：阅卷老师读你的文章，看什么？你交卷之前，怎样替他先看一遍？

学习目标

  • 说清阅卷老师主要在看哪几个方面。
  • 会把一句教师点评，对应到某个维度。
  • 会用检查表，在交卷前检查自己的文章。
  • 知道资料里最常见的失分原因，各对应哪一课。

这一课讲什么

  1. 阅卷在看什么从资料里的阅卷说法和教师点评，归纳出学生能操作的几个维度。
  2. 点评对应维度用站内点评和考场作文评价，看每一句点评指向哪个维度。
  3. 交卷前检查表一张不打分的检查表：审题、论点、结构、论证、表达。
  4. 常见失分原因资料里反复出现的问题，以及它们分别属于哪一课。

先说明资料的边界

三套资料里，没有高考作文的官方评分细则和分数等级表。能依据的有三类：

  1. 《新材料作文》第8讲“从高考阅卷谈作文提升之道”，是一位教师对阅卷情况和提分的总结；同一讲里还有考场作文和升格作文的对照，附有评价和分数（40分、45分、53分、56分、58分）。
  2. 站内历年优秀作文的教师点评。
  3. 导与练、一轮复习里零散的阅卷提醒。

所以这一课不列分数表，不算分。它做的是：从这些说法里，归纳出学生能对照检查的几个维度。文中出现的分数，只是《新材料作文》一本书里的赋分示例，不是官方标准。

核心认识

  • 阅卷先看整体，再看细节。 一轮复习说：“阅卷老师看作文的第一眼就是判断这篇文章的体裁与结构思路，然后是评判考生在这种体裁下的写作技巧与能力。”
  • 切题是底线，不是高分。 《新材料作文》第8讲：2023年高考作文“审题难度有所降低”，所以“作文不写跑题简单，但得高分比较难”。
  • 基本评价标准是三句话。 同一讲：“高考作文的基本评价标准就是文风端正、文脉清晰、文气顺畅。”
  • “论点+论据”不够。 《新材料作文》第2讲：只有观点加一个又一个例子，“结果形成了‘论点+论据’的格局，这样的文章，高考时最高只能评三类作文”。
  • 假、大、空是普遍问题。 第8讲：“考场作文‘假、大、空’现象严重，即有太多的学生在作文中说假话、说大话、说空话，不说实话，不说真话，更谈不上高质量地‘提出问题’‘分析问题’‘解决问题’。”

子专题一：阅卷在看什么

六个维度

把站内教师点评和《新材料作文》的说法放在一起，可以看到，评价总是围绕下面几个方面。这是本课的归纳：

维度 在看什么 对应的课
切题与任务 是否回应材料核心；是否完成了任务（身份、对象、文体、要求） 第1、6、19、20课
中心与观点 有没有明确的中心论点；是否鲜明、有价值 第2、7课
结构与推进 层次是否清楚；段与段之间是否有推进、过渡 第3、9、18课
论证与分析 材料是否有效；是否有分析，而不是只有例子；论证是否严密 第4、10、11、16、17课
思辨与深度 有没有多角度、有条件的判断；思考是否深入 第13、14、15课
表达 语言是否清楚准确；有没有病句、空话、生硬；是否有文采 第5、12课

三个不同的点评，同一个骨架

《劳则生欢，劳则生慧》（2019年）的点评，分四段：

  • 思路清晰——第二至五段紧密结合材料里的错误认识，各段分别提出中心论点、分论点，并驳斥；
  • 完成任务好——“既有立论，亦有驳论”，演讲稿格式完整规范；
  • 思想内容好——“内容充实，逻辑合理，思考深入”，中心明确；
  • 表达形式好——总分总，语言有表现力、感召力。

《以青春芳华，谱写时代乐章》（2018年）的点评，总结为一句：“文章好在能切合题意、任务落实到位；中心突出，论据充实；结构清晰，论证严密；语言表达流畅，富有文采。”

《以鲍叔为模，修青年品德》（2020年）的点评，三点：“切入立意有高度”“论证说理有深度”“结构严谨，口语色彩浓”。

对应下表：

维度 《劳则生欢》 《以青春芳华》 《以鲍叔为模》
切题与任务 完成任务好 切合题意、任务落实到位 符合发言稿的要求
中心与观点 思想内容好：中心明确 中心突出 切入立意有高度
结构与推进 思路清晰；总分总 结构清晰 结构严谨，段与段之间过渡巧妙
论证与分析 逻辑合理，思考深入 论据充实，论证严密 论证说理有深度，分析层层递进
表达 表达形式好 语言流畅，富有文采 口语色彩浓（另有个别语句不够通畅）

三个点评，用词不同，看的方面大致相同。

子专题二：点评里的“不足”

站内的点评，全部是对优秀或较好作文的评价，没有对低分作文的点评。但每一篇都指出了不足。把这些不足收集起来，就是“较好和更好”之间的差别：

作文 点评指出的不足 属于哪个维度
《以青春芳华，谱写时代乐章》（2018年） 缺乏一定过渡衔接，流畅感稍有不足 结构与推进
《献给2035年的你》（2018年） 想象和思考不够丰富和深刻；有些表达不够严谨；引述的话确定不出出处 思辨与深度；表达；论据
《给十八岁的你们的一封信》（2018年） 思考不够深刻；名人名言是谁说的不能坐实 思辨与深度；论据
《接受帮助，报以帮助》（2013年） 用例的“确凿性”有待提高 论证与分析
《一屋不扫，何扫天下》（2019年） 思想深度挖掘不够，“希望和建议”部分稍显薄弱 思辨与深度；任务
《给外国友人的一封信》（2017年） 对第三个关键词“高铁”阐释简略，只写前两个会更集中；“象征”改为“见证”更准确 结构与推进；表达
《让心中燃起劳动之火》（2019年） 个别概括不够准确，个别表述略显生硬 表达

其中有一个反复出现的问题：引述的话、名人名言，出处不能坐实。（2018年两篇）——引用要可查证。

子专题三：阅卷案例（考场作文的评价）

站内没有低分作文的点评，所以下面用《新材料作文》第8讲的考场作文评价补充。作者对每篇的评价和赋分，是一位教师的判断。

案例一：40分左右（审题聚焦不够）

作文《安于无声听惊雷》（材料：叶夫图申科“世界上不存在没有意思的人”）。评价：

“文章相对饱满，但未做到完全围绕核心立意（元）展开。虽旁征博引，文意丰沛，但论证相对散乱，核心‘元’在每段都有冲突挤兑之感，论述过程中往往言不尽意。未把道理讲清楚，未把辩证讲清晰，综合得分40分左右。”

对应维度：切题与任务（立意聚焦）、论证与分析（散乱）、思辨与深度（辩证没讲清）。

案例二：45分（有事例，没有分论点）

作文《蹄疾步稳，方能行远》（超过千字，一连用了王安石、爱迪生、清朝、王选、布鲁诺等事例）。评价：

“丰富的事例是此篇优点，也毫无疑问地成为本篇败笔。……标题之下再无分论点，导致文章徒有血肉缺少骨架，似乎是一个个‘缺少支撑’的故事随意组合，‘群龙无首’的组织形式必然将所有有效事例都变成了‘乌合之众’，使事例变得低效甚至无效，综合赋分45。”

对应维度：结构与推进（没有分论点）、论证与分析（事例没有被使用）。

《新材料作文》还说，“据说45分是高考作文阅卷分数的基准线，得45分意味着作文中规中矩、毫无亮点”。

案例三：一类文（58分）

作文《讲好中国故事 谱写青春华章》（材料：“好的故事……故事是有力量的”）。总评：

“这篇作文紧扣‘好故事’‘故事是有力量的’写作。开篇简引材料，摆出观点。第②段在阐述什么是‘中国故事’的同时，……统领第③至⑥段的内容，第⑦段总结第③至⑥段两部分内容，结构十分严谨。最后一段概括提升，发出呼吁，简洁有力。”

对应维度：切题、中心、结构与推进。

子专题四：交卷前检查表

下面是本课整理的检查表。不打分，每一项只回答“是”或“否”，“否”的，回到对应的课去改（怎样改，见第22课）。

审题

  • [ ] 我的立意回应了材料的核心，而不是背景？（第19课）
  • [ ] 我读出了任务：身份、对象、文体、重点？（第1、20课）
  • [ ] 材料里的几种说法或几个要求，都有着落？（第17、18课）

论点

  • [ ] 中心论点能用一句话说出，而且在开头和结尾都看得见？（第2课）
  • [ ] 各分论点之间不重复、不交叉、有推进？（第8课）

结构

  • [ ] 每一段能用一个动词说出它做什么？（第18课）
  • [ ] 段与段之间有过渡，或者有内在的推进？（第18课）
  • [ ] 结构是为论证服务的，而不是为了显得复杂？（第18课）

论证

  • [ ] 每个论据后面都有分析，不是只有例子？（第4、11课）
  • [ ] 论据真实，能说出出处，引用没有错？（第10课）
  • [ ] 分析没有跳步，结论没有说过头？（第16课）
  • [ ] 需要回应的质疑，回应了吗？（第17课）

表达

  • [ ] 有没有“假、大、空”的话，去掉之后论证还在？（第12课）
  • [ ] 有没有明显的病句、错别字、含糊的指代？（第12课）
  • [ ] 标题简单、贴合核心，不在核心概念之外化用？（第5课）
  • [ ] 字数达到要求，没有泄露个人信息、没有套作？

如果时间只够查一处：先查第一部分——审题。 审题错了，后面的检查都没有意义（第22课也从审题改起）。

方法步骤（合起来）

  1. 先读整体：这篇文章的中心是什么？结构是什么？（阅卷的“第一眼”）
  2. 对照检查表，每部分快速过一遍。
  3. 标出“否”，按维度归类。
  4. 优先处理最靠前的“否”：审题的问题先于论点，论点先于结构，结构先于论证，论证先于语言。

典型例题

例1　把点评归入维度

点评：“文章的第二至五段紧密结合同学中存在的对劳动的偏见和误解，表达了自己对劳动的认识和思考。”这句话在评价哪个维度？

参考答案（示例）

切题与任务（紧扣材料里的“偏见和误解”），也涉及结构与推进（第二至五段的安排）。一句点评可以同时对应两个维度。

例2　读出问题

点评：“文章内容充实，但论证相对散乱，核心‘元’在每段都有冲突挤兑之感。”问题在哪里？该回到哪一课？

参考答案（示例）

问题：核心概念太多，每段各写各的。属于审题聚焦和结构两个维度。回到第19课（抓核心，删繁就简）和第18课（主线）。

例3　用检查表看一段

“网络让人变得肤浅，所以要禁止。”这一句，在检查表里，哪几项是“否”？

参考答案（示例）

“分析没有跳步，结论没有说过头？”——否：从“肤浅”推到“禁止”，跳了几步（第16课）。 “需要回应的质疑，回应了吗？”——否：没有回应“网络也有用”这一质疑（第17课）。

常见错误

  1. 只看语言，不看审题和结构。
  2. 把点评当作分数，不看它指向哪一个具体问题。
  3. 自评只写“比较好”，说不出具体哪里。
  4. 有很多事例，没有分论点，自以为“丰富”。
  5. 引用来路不明，或者出处错了。
  6. 检查时从语言开始，越改越碎，大问题留在最后。

课堂小练

小练1　分类

把下面的点评归入六个维度：（a）“想象和思考还不够丰富和深刻。”（b）“缺乏一定过渡衔接。”（c）“用例的‘确凿性’有待提高。”

参考答案

（a）思辨与深度；（b）结构与推进；（c）论证与分析（论据）。

小练2　用检查表

对照检查表，检查你最近一篇作文的“审题”部分，写出一个“否”，并说明。

小练3　用检查表看45分案例

读《新材料作文》第8讲的45分案例，说出它在检查表里，至少两项是“否”。

参考答案（示例）

“各分论点之间不重复、有推进”：否——没有分论点。 “每一段能用一个动词说出它做什么”：否——事例一个接一个，段与段之间只是堆叠。 “每个论据后面都有分析”：视具体段落，多数只有叙述，没有分析。

课后训练

  1. 读**《以青春芳华，谱写时代乐章》和《献给2035年的你》**的点评，各画一张“维度对照表”，比较两篇的差别。
  2. 选一篇站内优秀作文，先不看点评，用检查表给它挑毛病，再看点评，看你有没有看出同样的不足。
  3. 在你自己的作文里，找出一个你自己读不出出处的引用，核实它，或删掉它。
  4. 用“是或否”做一次限时检查（十分钟内），记录哪一部分最容易漏。
