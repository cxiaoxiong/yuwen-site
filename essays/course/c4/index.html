第一阶段 · 基础写作 · 第4课

规范议论段

段落与论证

写好一个主体段，是写好全文的基本功。这一课只讲怎么把一个分论点写成一个规范的段落。

学习目标

  • 知道一个规范的主体段包含哪五种句子，并能在自己的段落里指出来。
  • 会用事例论证：选事例、概括事例、分析事例、回扣观点。
  • 会用引用论证，并在引用后写出解释，说明它与观点的关系。
  • 能检查自己的段落缺了哪一层。

这一课讲什么

  1. 五层结构观点句、阐释句、材料句、分析句、结论句，写出一个完整的主体段。
  2. 事例论证举什么、怎么概括、怎么分析、怎么扣回观点。
  3. 引用论证引用不是装饰，引用之后必须解释它与观点的关系。

核心认识

教材怎么说

必修下册第八单元“如何论证”：“论据再多再好，也不能‘自动’证明论点。以罗列论据代替论证，是刚开始写作议论文时常常出现的问题”；“所谓论证，其实就是对论据进行解说与分析，建立论据和论点之间的联系。”同册教师教学用书指出学生的两个常见问题：一是“缺乏阐释”，提出观点后要“对观点进行一些阐释，包括界定概念、明确论题”；二是“罗列论据”，提出论据之后要“作一些分析，阐释这一论据如何能够支撑”观点。（教材原文见必修下册第八单元 · 单元学习任务）

本课的五层结构，就是把这几句话落实成一个段落：阐释句对应“阐释”，分析句对应“解说与分析”。

  • 主体段又叫论证段，全文一般有 2–3 个，每段长短适中，一般 200–300 字。它是议论文的核心，也是决定能否得高分的关键。
  • 一个规范主体段，依次有五种功能的句子：观点句、阐释句、材料句、分析句、结论句（导与练、《新材料作文》的叫法）。
  • 论据只是材料，不会自己说话。材料和观点之间，必须由你写出的分析连起来。

子专题一：五层结构

层 作用 怎么写 例
观点句 本段要证明什么，就是第2课的分论点 简洁的陈述句，鲜明准确，开门见山 读书可治迷茫。
阐释句 对观点展开、阐发 讲清意思，紧扣观点，不跑题；可用引用或对偶 特别是年轻的时候，经验阅历少，选择诱惑多，难免会感到迷惘和彷徨。
材料句 提供论据 举典型事例，只交代基本状况、行动、结果 据说一位学者在回信中对迷茫的青年说：“你的问题主要在于读书不多而想得太多。”
分析句 在材料与观点之间搭桥 说明这个材料为什么能证明观点 这真是一句简单而精辟的概括……阅读能帮人明黑白，辨是非，透现象，看本质。
结论句 小结，照应观点句 重申本段观点，也可引用一句名言 前人书中的经验，对我们走好人生之路颇有启迪。经验每多一分，迷茫便减一分。

（例子：导与练“读书可治迷茫”完整段。）

写的时候先判断本段要证明什么，再依次写五层，最后检查：每一层是不是都在说同一个观点。

观点句和阐释句可以合成一句，结论句和分析句有时也合在一起。它们是一个整体，不是五个孤立的小格子。

《新材料作文》第4讲说得更直接：“观点句+材料句+分析句”是例证段的基本式，“凡议论文例证段，一般都具备这三个要素”，阐释句和结论句“可以根据具体情况自由添加”。所以检查时先看三样：有没有观点，有没有材料，有没有分析；缺了分析，就是教材说的“以罗列论据代替论证”。

站内范文里的一段

范文《学好本手，下出妙手，避免俗手》的第二段，是“学好本手”，可以这样对应：

  • 观点句：学好本手。
  • 阐释句：本手是妙手的基础，正如建房须打牢地基……基础不牢，地动山摇。
  • 材料句：毛泽东学透马克思主义理论方法……叶嘉莹深入研究中国古典诗词……单霁翔透彻了解中国古文物……
  • 分析句与结论句：这都告诉我们，本手是妙手的基础，只有脚踏实地，打好基础，才能使前进的步伐更加扎实、更加稳当。

阐释句怎么写

基础阶段用一种就够了：用一句名言（名言印证）或一个道理来解释观点。名言的用法见下面的“引用论证”。

子专题二：事例论证

不是把故事讲一遍，而是完成四件事：举什么 → 怎么概括 → 怎么分析 → 怎么扣回观点。

  1. 举什么：选典型事例，古今中外、正反都可以，但要紧扣本段的观点，不要偏。
  2. 怎么概括：只交代人物的基本情况、行动、结果，不必细讲。单个事例可以稍详，多个事例每个用两三句。
  3. 怎么分析：说明这个事例里哪一点能证明观点。
  4. 怎么扣回观点：最后一句回到观点句，不再讲故事。

三种用法

用法 怎么用 例（导与练）
典例单用 一个典型事例，稍微讲细 相声大师侯宝林只上过三个月小学（状况），但勤奋好学，做事“不达目的不罢休”（行动），终成一代宗师（结果）。
事例对举 一正一反，两个事例对照 楚怀王闭目塞听，客死他乡；唐太宗虚心纳谏，成就“贞观之治”。（观点：从谏如流势在必行）
略例排比 两个以上，每例一句 匡衡出身贫寒，高尔基流浪街头，保尔做过童工……（观点：贫困有时也是一种财富）

分析句：这里先学最基本的

  • 归纳分析：列举几个事例 → 找出共同点 → 揭示观点。常用“可见”“由此看来”“这都证明”。
  • 因果分析：事例发生 → 找原因 → 说规律。常用“正是因为……所以”“之所以……是因为”。

假设、对比、类比等更深的分析方法，留到第11课。

容易犯的错

  • 只有事例，没有分析：讲完故事就换段。
  • 事例太长：占了整段，分析只有一句。
  • 事例与观点不对应：故事不错，但证明的不是本段观点。导与练评《既要温饱，更要环保》这一篇的问题之一就是“事例论证跑偏”：写陶渊明的人格和评价太多，偏离了论证的核心。
  • 事例总是同一批，缺少变化，那是第10课的内容。

子专题三：引用论证

引用不是装饰。引用名言、诗句、数据，为的是支持本段的观点，所以引完之后，必须解释：这句话是什么意思，和我的观点有什么关系。

怎么做

  1. 选：引用的内容要与本段观点一致，不宜过长。
  2. 引：交代出处或说话人，引文准确。
  3. 解释：用自己的话说清引文的意思。
  4. 联结：说明它与本段观点的关系，回扣观点。

一轮复习对“引用式开头”的提醒，也适合用在主体段里：引用内容不宜过长；引用之后要有简短的概括点评，并点明核心话题；引用与点评之间要有合理的逻辑，不能生拉硬扯。

例

观点句（导与练）：今天，继续发扬五四精神，正需要青年有迎难而上、挺身而出的担当精神。

阐释里的引用：“世之奇伟、瑰怪、非常之观，常在于险远”，唯有不断探索尝试，勇于走在前列，才能领略最美丽的风景、成就最壮丽的人生。

拆开看这一步做了什么：

  • 引：“世之奇伟、瑰怪、非常之观，常在于险远。”
  • 解释：最壮美的景象，总在险峻遥远之处。
  • 与观点的关系：要看到最美的风景，就得敢于探索、不怕负重前行，正是“迎难而上、挺身而出”。

如果只引第一句，后面不写解释和联结，这句名言就只是装饰。

一个完整的引用段

下面这段以名言为材料（《新材料作文》第7讲例段）。它没有单独的阐释句，名言直接当材料；分析句分成了正、反两步：

  • 观点句：开端决定终端，入手决定出手。
  • 材料句：《道德经》有云：“合抱之木，生于毫末；九层之台，起于累土；千里之行，始于足下。”
  • 分析句（正面）：“合抱之木”，不可谓不“大”；“九层之台”，不可谓不“高”；“千里之行”，不可谓不“远”。然而，这“大”“高”“远”，都是从“毫末”“累土”“足下”开始的。
  • 分析句（反面）：不自“毫末”，何来“合抱”？不起“累土”，哪来“九层”？不始“足下”，何以“千里”？
  • 结论句：可见，“始”之重要，一切贵在“始”。

同一句名言，同一讲的另一个例段把分析的落点改成“积累”，论点就成了“积累是生命的年轮”。可见材料本身不决定论点，分析把材料引向哪里，材料才证明什么（选材见第10课）。

也要看到这段的不足：名言证明的是“大成就都从小处开始”，论点却说“开端决定终端”，说得比材料重。把论点改成“成大事，须从开端做起”，材料和论点才对得上（结论不能大于前提，见第16课）。

容易犯的错

  • 引完就走，不解释，读者不知道你为什么引。
  • 引用脱节：导与练评现场作文《既要温饱，更要环保》，指出引用桃乐丝·卡耐基关于家庭幸福的名言，与“环保”论点无关，“引文与中心脱节”。
  • 引用太长，占了大半个段。
  • 一个段里堆几句名言，没有一句被解释。

典型例题

例1　补全一个段

观点句：读书可治迷茫。请补写阐释句、材料句、分析句、结论句。

参考答案

阐释：特别是年轻的时候，经验阅历少，选择诱惑多，难免迷惘彷徨。怎样借得慧眼、穿越迷雾呢？读书，大概是最好的办法。 材料：据说一位学者在给迷茫青年的回信中说：“你的问题主要在于读书不多而想得太多。” 分析：这句话简单而精辟。“不畏浮云遮望眼，自缘身在最高层”，阅读能帮人明黑白、辨是非、透现象、看本质，认知到了一定高度，自然拨云见日。 结论：前人书中的经验，对我们走好人生之路颇有启迪。经验每多一分，迷茫便减一分。

例2　典例单用

观点句：国家荣誉感能激发一个人的战斗力。

参考答案（示例）

阐释：只关注自我的人不会有持久的战斗力，当一个人将自身命运与国家命运相连，就会产生强烈的责任感和使命感。材料：抗日战争时期，无数中华儿女在国家危亡之际，怀着民族荣誉感和爱国热情前赴后继，经过十四年殊死战斗，最终打败了侵略者。（观点句与材料句之间，还可以补一句分析，说明是什么激发了战斗力。）

常见错误

  1. 没有观点句，一上来就讲故事。
  2. 观点句太长或一段里有两个观点，段意不集中。
  3. 事例讲得太长，分析只有一两句。
  4. 只有“这说明了……”，没有真正的分析。
  5. 引用之后不解释，或者引文与观点脱节。
  6. 结论句照抄观点句，没有概括本段。

课堂小练

小练1　找出五层

读站内范文《学好本手，下出妙手，避免俗手》第三段“下出妙手”，标出五种句子，看看它缺哪一层，或哪两层合在了一起。

参考答案（本站整理，依据范文原文）
  • 观点句：下出妙手。
  • 阐释句：妙手是本手的创造。在这个日新月异的时代……然而若无出人意料的妙手，我们又将如何推动中国的跨越式发展呢？所以，在学好本手的基础上，我们要敢于创新，下出妙手……
  • 材料句：张艺谋……华为……中国航天……（略例排比，每例一句）
  • 分析与结论：故以本手为基础，不固步自封，而是勇于开拓，进取创新。一朝下妙手，赢得天下惊。

严格按本课“五层议论段”模型看，这一段的分析层没有独立展开。张艺谋、华为、中国航天三个材料都带有“在原有基础上创新”的简短分析，因此部分分析实际融进了材料句；最后“故以本手为基础……”一句承担归纳和收束作用。也就是说，这个段落不是机械地把五层各写一句，而是“材料＋简析”融合，再用结论句收束。

小练2　补分析

材料：相声大师侯宝林只上过三个月小学，但由于勤奋好学，做事从来都是“不达目的不罢休”，最后终于成为一代相声艺术宗师。观点句：勤奋能弥补起点的不足。请补一句分析，说明这个事例为什么能证明观点。

参考答案（示例）

侯宝林的起点并不高，只上过三个月小学，之所以能成为一代宗师，正是因为他勤奋好学、不达目的不罢休。由此可见，勤奋可以弥补起点的不足。（用了因果分析：结果→原因→观点。）

小练3　解释引用

观点：善于借助外物，才能更快成长。引文：“君子生非异也，善假于物也。”请写两三句，先说引文的意思，再说它与观点的关系。

参考答案（示例）

这句话的意思是：君子的资质与常人并没有不同，只是善于借助外物。它正好说明，成长不只靠自己的力量，善于借助工具和条件，才能走得更快更远。

课后训练

  1. 用第2课得到的分论点，写一个 200–300 字的主体段，写完标出五层，检查缺哪层。
  2. **站内范文《故事的力量》**第二段（杜甫与《石壕吏》）：说说材料句是什么，分析句在哪里，它是怎样把事例和观点连起来的。
  3. 站内范文《学好本手，下出妙手，避免俗手》：找一段，说说事例是“典例单用”“事例对举”还是“略例排比”。
