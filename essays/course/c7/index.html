第二阶段 · 专项突破 · 第7课

核心概念阐释

读题定题立论

很多材料的立意，落在一个抽象的词上：好的故事、追求、创新、感知。这个词不解释，观点就悬着；解释成空话，文章就空转。这一课只做一件事：把核心概念找准，用一小段话说清，并且让它为论证服务。

学习目标

  • 说清核心概念在立意里起什么作用，能从材料和题目里找出它。
  • 分辨“真核心”和“抄词”。
  • 用几种基础方法，写一段不超过100字的概念阐释。
  • 检查阐释有没有和中心论点、分论点接上，避免“概念空转”。

这一课讲什么

  1. 确定核心概念从材料和题目里找出真正需要解释的词，不是照抄最显眼的那个。
  2. 阐发核心概念用几种基础方法把概念说清、限定范围，并接到中心论点上。

核心认识

教材怎么说

选择性必修上册第二单元“审题与立意”：审题要“重点思考题目中的核心概念是什么，应该如何界定，可以从哪些方面立意”。必修下册教师教学用书指出，学生议论文的一个常见问题是“缺乏阐释”：“确定了一个论点之后，不进行任何阐释，不界定相关概念，就匆忙展开论证，这就容易留下漏洞”；所以“在提出观点后，往往需要对观点进行一些阐释，包括界定概念、明确论题等”。（教材原文见选择性必修上册第二单元 · 单元研习任务）

下面几条来自导与练，是把“界定核心概念”落实成具体做法：

  • 核心概念是立意的引发点和着力点。（导与练）
  • 概念的内涵错了，观点就会出错；概念的范围错了，论据就会出错。（导与练）
  • 核心词语大多很概括，所以写作时要作出自己的解释。解释就是：选择角度，缩小范围，明确内涵，阐述剖析。（导与练）
  • 阐释不是词典抄录，而是一座桥：一头接材料里的词，一头接你的中心论点和后面的论证方向。

本课的边界

本课只做基础的“找出来、说清楚、接上去”。给概念划定成立条件和边界、把相近的概念辨析清楚，属于第15课，这里只在末尾提示一次。

子专题一：确定核心概念

核心概念从哪里来

来源 特点 例
材料里的评议对象和关键词 反复出现，被评价、被强调 2023年新课标Ⅰ卷：“好的故事”
材料里的二元关系 两个概念互相对照 “共享与独创”；“实用与审美”“有用与无用”
题目里直接给出的词 材料已经给了解释，要先读懂 2022年新高考Ⅰ卷：本手、妙手、俗手
需要先概括本质的词 材料是知识性的，要提炼特点再选话题 2024年九省联考：“交错带”，特点是“敏感”“最先改变”“局部影响整体”

材料是具体的事，核心概念要从具体上升到抽象。导与练的例子：勒内·托姆说，远古人保存火种，是因为夜里火光灿烂，最美。材料说的是火，核心概念是“实用与审美”“物质与精神”“有用与无用”。

什么是“真核心”

判断一个词能不能做核心概念，问三句：

  1. 没有它，我的观点还成立吗？不成立，才是核心。
  2. 不解释它，读者会有不同的理解吗？会，就需要解释。
  3. 它是材料在说的东西，还是背景？背景词不是核心。

核心概念不是抄题目

三种常见的“假核心”：

  • 抄最显眼的大词。2023年材料只写“故事”，但材料评议的对象是“好的故事”。一轮复习特别指出，这道题用“极其概括的单概念‘好的故事’”取代了近两年流行的关系型作文形式。核心概念是“好的故事”，不是“故事”。
  • 只抓一半。材料是“共享与独创”，只解释“独创”，“共享”就丢了，材料的对照也没有了。
  • 贪多。一篇文章只留一个核心概念，或一组二元关系。（第1课已说：概念不集中，就不聚焦。）

材料已经给了解释怎么办

2022年材料对“本手、妙手、俗手”已经作了界定。写作时先用材料的解释，不要另造一个。站内范文《以本手为基，避俗手之劣，创妙手之举》的点评说，开头“引述原材料，解释围棋‘三手’，阐述三者关系，表明中心观点”，先接住材料，再往前走。

子专题二：阐发核心概念

四种基础方法

导与练归纳了五种阐释方法。基础的是前四种：

方法 做法 例
含义阐释法 先说它是什么，再说它有什么用 “追求”：用积极的行动来争取达到某种目的，是对美好人生的向往，是不断成长的动力
字词拆分法 拆开字词，一字一字地解释 “英雄”：“英”是才能智慧出众，“雄”是有气魄
事例阐释法 用一两个典型例子说明 “简练”：陆游“小楼一夜听春雨，深巷明朝卖杏花”，十四个字含了多少情和景
比喻阐释法 用比喻使概念形象 “追求”是一支飞向靶心的箭

第五种“比较分析法”（如“授之以渔”与“授之以鱼”），是把两个概念放在一起比较，做深了就是概念辨析，见第15课。本课不展开。

站内例（字词拆分）：2015年范文《仰观宇宙，俯察万物》写道：“何谓‘感知’？‘感’即感受，‘知’为相知。”

站内例（列举场景）：2019年范文《让心中燃起劳动之火》：“劳动究竟是什么？也许你我都难以精准概括。但请大家环视四周：那堆砌整齐的一砖一瓦，是工人们的劳动；那干净整洁的一道一路，是清洁工的劳动；那骄傲成长的一草一木，是园丁们的劳动……”

常用句式和篇幅

导与练提供了一些带理性色彩的句式：

  • 何谓……　什么是……（聚焦概念，引发思考）
  • 请循其本，……（回到原点）
  • ……，……之谓也（判断句，简洁，肯定）
  • 顾名思义，……（简洁，有提示作用）
  • 名不正则言不顺，……（名句，典雅）

篇幅：界定概念不要太长，控制在100字以内。阐释是为论证打基础，不是写一篇小论文。

怎么限定范围

概念太大，什么都能装，就等于没说。限定的办法是用材料给概念画一个圈：

  1. 加限定语：“好的故事”，不是所有故事；
  2. 落到材料的情境：材料里谈的是哪一类人、哪一件事；
  3. 抓住材料给的特征：“交错带”的特征是“敏感”“最先改变”“推动整体变化”，只有满足这些特征的，才算交错带。

站内例：2023年范文《讲好新时代故事，点亮新征程明灯》第二段这样界定：“何为好的故事？传播正能量、弘扬民族精神的时代强音。”后面举了“年度感动中国人物故事”“人民日报、央视新闻记录的先进人物、群众事迹”作为范围。这样，“好的故事”就被限定在一个具体的圈里。

阐释要接到论点上

阐释完不能就放下。三个动作，把它和后面接起来：

  1. 释义落到关键词：阐释的最后一句，回到中心论点里的词。
  2. 释义拆出来的要素，变成分论点或论证方向。导与练的例子：“乐于共享的独创者”，前提是乐于共享，核心是独创，两半各是一层要论证的意思。
  3. 释义决定哪些论据能用。

站内例：范文《仰观宇宙，俯察万物》先拆“感知”：“感”是感受，“知”是相知。然后写：“明白了这一点，便可知为何科技手段无法让我们真正地亲近自然，感知自然。”接着写电视、网络“这顶多可算作对与自然相关的科学知识的学习与认知”，而无法让人“感受自然之美”，然后以孩子对红花绿叶、画家对湖光山色说明“感”。整段论证，都是从“感”和“知”两个字里生长出来的。

避免概念空转

“空转”指阐释和论证没有关系：定义写得漂亮，后面照旧写别的。三个自查问题：

  1. 删掉这段阐释，后文读得通吗？读得通，说明没有用上。
  2. 后文的分论点、论据，用到阐释里的词了吗？
  3. 阐释比原词多说了什么？如果只是“追求就是追求的过程”，等于没说。

站内范文《讲好新时代故事，点亮新征程明灯》，点评一方面肯定它先界定“好的故事”，另一方面指出“第二段和第五段稍显空洞，削弱了论证的力量”。可以这样读：第二段界定了“好的故事”应当“向上向善”，但后面两段论证的是“好的故事有什么作用”，例子没有回过头来检验“向上向善”这条界定。界定给了方向，论证却没有用它。

方法步骤

  1. 找：圈材料的关键词，判断哪个是核心（三问）。
  2. 定：写下一个核心概念，或一组二元关系。
  3. 释：选一种方法，在100字以内写出内涵，用材料限定范围。
  4. 接：阐释最后一句落回中心论点；想想它引出哪几个分论点。
  5. 查：空转三问。

典型例题

例1　确定核心概念：2023年

  • 先判断：材料一句列举“好的故事”的作用，再总结“故事是有力量的”。
  • 再做：评议对象是“好的故事”，不是“故事”。核心概念是“好的故事”，后面接“力量”。
  • 最后检查：如果观点是“好的故事有力量”，就要说明“好”指什么。示例：好的故事，就是能让人得到启迪、产生力量的故事，即能表达沟通、触动心灵、启迪智慧的故事。（依据材料四个“可以”）

例2　阐发核心概念：“追求”（导与练）

材料：成功人士晚年说，留在记忆里的不是成功的喜悦，而是曾经苦苦的追求；登山者说，登山是因为想看到山顶的雪，每个人有自己选定的路径。

  • 含义阐释法：何谓追求？其含义是“用积极的行动来争取达到某种目的”，是对美好人生的向往，是在困厄中仍能让人努力向上的精神支柱。
  • 字词拆分法：“追”即追赶，“求”即谋求，两者合一，是身与心的全力拼搏。

接到论点：可以提出“追求的过程，比抵达更长久”，分论点从“追”与“求”两层展开。

例3　用材料的限定：“交错带”（2024年九省联考）

  • 材料特征：敏感，最先发生改变，进而推动整体变化。
  • 概念：交错带，是局部先变、并带动整体变化的地方。写作时，需要先概括本质特性，再选一个话题，在概念的范围内展开。
  • 提醒：如果选的话题里，找不到“最先变”“推动整体变”，就不是交错带。

常见错误

  1. 抄题目最大的词：解释“故事”，没有解释“好的故事”。
  2. 只解释一半：二元关系只写一半。
  3. 词典式：照抄词典释义，没有限定范围，没有和材料联系。
  4. 太长：阐释写成大段，压掉了论证。
  5. 空转：写了阐释，后面用不上。
  6. 同一句话换说法：“追求就是不懈地追求”。
  7. 释义与立意矛盾：阐释里说“追求是过程”，立意却写“结果最重要”。
  8. 一段里解释太多概念：一段一个，一篇一个核心。

课堂小练

小练1　找核心概念

①点击链接就能读美文，扫码就能买时装，科学发展使成果共享更便捷；但写作者的思考、设计师的匠心仍属独创者。对国家而言，可以共享科学成果，却很难共享关键核心技术。新时代呼唤更多的独创者、独有者。

②数学家托姆与两位古人类学家讨论远古人为什么保存火种：一位说取暖，一位说烧肉，托姆说，因为夜里火光灿烂，最美。

参考答案（导与练）

①共享与独创。②实用与审美；物质与精神；有用与无用。

小练2　辨认方法

下面三段，各用了什么阐释方法？

① 何谓“英雄”？“英”是指才能或智慧出众的人，“雄”是指有气魄的人。

② 什么叫简练呢？简练就是陆游在小楼上听雨，彻夜未眠，写下“小楼一夜听春雨，深巷明朝卖杏花”，只不过十四个字，可是包含了多少情和景！

③ 追求是小船航行的发动机，是一支飞向靶心的箭。

参考答案

① 字词拆分法；② 事例阐释法；③ 比喻阐释法。（例句来自导与练）

小练3　写一段阐释

材料：一位登山者说：“我登山是因为想看到山顶的雪。”山顶的雪，牵引着每一个上山的人，只是每个人选定的路径和方式不同。用两种不同的方法，各写一句阐释“追求”，每句不超过60字。

参考答案（导与练）

含义阐释：何谓追求？其含义是“用积极的行动来争取达到某种目的”，它是一种对美好人生的向往，是激励自己不断成长的动力。 事例阐释：追求，是一种对信仰的坚守，对梦想的向往。辛弃疾“赢得生前身后名”是对建功立业的追求；屠呦呦潜心研究青蒿素，是对守护健康、敬畏生命的追求。

小练4　找空转

下面一段是某篇文章的第二段，请指出问题，并说出怎样改。

“什么是坚持？坚持就是一直坚持下去，是一种美好的品质。”（第二段）后文三段分别写：爱迪生发明电灯的故事，越王勾践卧薪尝胆的故事，某同学每天早起背单词的故事。

参考答案（教学示例）

问题：阐释是同义反复（坚持就是坚持下去），没有比原词多说什么；后面三段的例子，也没有一个用到这段阐释。改法：把“坚持”限定，例如“坚持，是在看不到成效时仍然继续”，这样三个事例都可以回头检验：爱迪生、勾践、同学，是不是在“看不到成效时”继续？

小练5　从字词到论证

“何谓‘感知’？‘感’即感受，‘知’为相知。”请根据这个拆分，说一说“科技手段能不能让人感知自然”，并写出一个论证方向。

参考答案

“知”可以靠电视、网络来获得，“感”需要亲身接触。所以科技手段提供“知”，却给不了“感”。论证方向：区分“知道自然”和“感受自然”，用亲身接触自然的例子（如画家、诗人）说明“感”的价值。范文《仰观宇宙，俯察万物》就是这样写的。

课后训练

下面的资料都可以在“相关资源”里进入：

  1. 2023年高考作文题：核心概念定为“好的故事”，用含义阐释法写一段不超过80字的阐释，并写出它引出的两个分论点；再读范文《讲好新时代故事，点亮新征程明灯》第二段，说说它的界定有没有被后文用上。
  2. 2015年高考作文题：写出你认为的核心概念（可以是一个词，也可以是“近与远”一组），用一种方法阐释；读范文《仰观宇宙，俯察万物》，找出阐释后面第一个论证句。
