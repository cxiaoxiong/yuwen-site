第三阶段 · 思辨进阶 · 第18课

高级谋篇

谋篇

第3课教了总分、并列、递进，第9课教了对照、引议联结、起承转合。这一课不再学新的结构名称。它要回答的是：面对一则具体的材料，怎么决定整篇文章的排法，怎么检查自己的排法站不站得住。

链条上的位置：

基础结构 → 结构变化 → 立与驳 → 谋篇

本课是较克制的一课

谋篇是本站作文课程里资料最少的一块。导与练、《新材料作文》和一轮复习，讲结构名称和模板的多，讲“怎样根据题目决定结构”的少。所以这一课比其他课短：只讲资料里真正有依据的做法，找不到依据的，放在最后的“资料充分度”里，说明缺什么，不自造。

不做的事：不重讲第3、9课的骨架；不进入第19课的高考题型迁移；不做第22课的修改升格。

学习目标

  • 能从材料和题目里，读出对结构的提示。
  • 能用一句话说出一篇文章的主线，并检查每一段是否在推进它。
  • 能为一篇范文画出“结构地图”：每段做什么，为什么放在这里。
  • 知道“结构复杂”不等于“结构好”。

这一课讲什么

  1. 从任务看结构材料里的说法、题目里的词、要回答的问题，往往已经在提示每一段做什么。
  2. 主线一句话说出：这篇文章从头到尾，推进了什么。
  3. 段落功能每一段负责什么，为什么放在这里，换个位置行不行。
  4. 结构地图用范文和点评，把整篇文章画成一张“每段做什么”的图。
  5. 结构服务论证好的结构，标准是清楚、有效、有推进，不是花样。

核心认识

  • 结构由论证任务决定。 第9课已经说过。这一课往前走一步：任务从哪里看出来？——从材料、题目和要求里。
  • 每一段都有它的功能。 定义、提出问题、分析原因、回应反方、提出办法、收束，功能不同，位置也不同。
  • 有主线，才谈得上结构。 主线就是这篇文章一路在证明的那件事。
  • 高级谋篇的标准是：清楚、有效、有推进。 读者读到任何一段，知道它为什么在这里。

子专题一：从任务看结构

三个来源

来源 看什么 在结构上的提示
材料里的说法 材料是否已经给出几种态度、几种质疑 每种说法，可以对应一处回应，也可以对应一个分论点
题目里的词 题目或要求是否有两个动作、两个概念 两个词可以各占一段，再合起来
要求里的任务 文体、对象、要“提出希望与建议”等 决定要有哪一部分，以及放在哪里

例：2019年，材料里的三个说法

2019年广东卷的材料，写了三种不愿意劳动的说法：“我们学习这么忙，劳动太占时间了！”“科技进步这么快，劳动的事，以后可以交给人工智能啊！”“劳动这么苦，这么累，干吗非得自己干？花点钱让别人去做好了！”另有一句：身边也有不尊重劳动的现象。要求是：写演讲稿，倡议“热爱劳动，从我做起”，体现认识与思考，并提出希望与建议。

这些已经提示了几件事：要回应这几种说法（第17课）；要有一个“倡议”；要有“希望与建议”。同一个任务，站内有三种排法，见下面的结构地图。

例：2013年，题目里的两个词

范文《接受帮助，报以帮助》，题目里有两个动作：接受帮助，报以帮助。点评这样描述它的结构：

“次段从逻辑思辨维度扣‘接受帮助’，第三段从逻辑思辨维度扣‘报以帮助’，第四段第五段分别从个人、公司视角写‘接受帮助，报以帮助’，第六段总绾全文点题。……第三自然段的尾句就是第四、第五自然段的总起，过渡自然、针线绵密。”

也就是说：先分别讲清题目里两个动作是什么、为什么，再用两个事例把它们合起来讲，最后收束。题目里的词，被拆成了结构。

例：一轮复习，三个追问撑起全文

一轮复习在“聚焦思辨”里，讲了“是什么、为什么、怎么办”三个追问（见第16课）。其中范文《认同传统向未来》，整篇用“三探”行文：探寻“认同什么”，探明“为什么要认同”，探索“怎么来认同”。点评：“先后用了多个问号和疑问词，不断地追问，一步步地将对……的思辨推向了深入。”

这是把三个追问，直接作为全文的三个部分。用《六国论》作说明：“是什么”亮出观点（“弊在赂秦”），“为什么”分析（赂者和不赂者两条链），“怎么办”提出办法（三个对策）。

（提醒：导与练的“提出问题—分析问题—解决问题”，和三个追问几乎一致。第3课已经讲过，这里不重复。）

子专题二：主线

一句话检验

读完一篇文章，或者写完自己的初稿，试着回答：

这篇文章从第一段到最后一段，究竟推进了什么？

如果答案是一句话，比如“先说劳动为什么值得，再回应几种不愿意的想法，最后提出怎么做”，主线就是清楚的。如果答案是“写了很多方面”，多半是并列堆叠，没有主线。

资料里的提示

  • 《融汇“本妙”，不落“俗套”》的点评说：第二、三、四段分别论证“本手”与“妙手”、“妙手”与“本手”“俗手”之间的关系，三个概念围绕一条主线（第13课）。
  • 《进步与退步》（2016年）三个“承”，第9课已指出其实是并列，整体是总分总。看主线：三段在回答同一个问题，没有一段比前一段走得更远。

主线不清的三种表现

  1. 原地转圈：每段换一个例子，说的是同一句话。
  2. 各说各的：每段一个话题，之间没有关系。
  3. 中途换靶：前面在论 A，后面突然论 B，读者不知道中心是哪一个。

子专题三：段落功能

一段一个动词

点评在描述范文时，常常用一个动词概括每一段，比如“提出中心论点”“提出分论点一”“反驳……”“联系现实”“提出希望和建议”。自己检查时，也可以这样做：给每一段写一个动词，写不出的段，多半没有功能。

站内几篇范文里，出现过的功能有：

功能 例
交代问题 “但揆诸当下，‘劳动无用论’却甚嚣尘上。”（《让心中燃起劳动之火》）
界定、阐释 “劳动究竟是什么？”（同上，用身边场景阐释）
分论点 “劳则生欢……”“劳则生慧……”（《劳则生欢，劳则生慧》）
回应反方 “诚然……但是……”（《以劳动书写人生风采》）
转折 “然而，时代的脚步却总不会留恋畴昔。”（《透过那泛黄的老照片》）
提出建议 “首先……其次……最后……”（《以劳动书写人生风采》）
收束 首尾呼应，“助”字首段4次、尾段3次（《接受帮助，报以帮助》）

三问检查每一段

  1. 这一段负责什么？（一个动词）
  2. 删掉它，后面还接得上吗？ 接得上，说明它可能是多余的；接不上，说明它是链条上的一环。
  3. 换到别的位置，行吗？ 行，说明它可能与前后没有推进关系；不行，说明它的位置有理由。

这三问是本课整理的教学工具。

段与段之间

导与练“议论文逻辑链”一课里，一篇现场作文被指出“行文缺少过渡，前文分析问题、后文谈做法，层次跳转生硬”（见第16课）。反过来看，《接受帮助，报以帮助》第三段的尾句，就是第四、五段的总起，前后接得上。

子专题四：结构地图

用三篇站内范文的点评，画出“每段做什么，为什么放在这里”。第三列是本课的分析，供参考，不是唯一标准答案。

地图一：《劳则生欢，劳则生慧》（2019年）

材料里有几种说法，这篇文章把回应做成了分论点。

段 做什么 为什么放在这里
第一段 引“民生在勤，勤则不匮”，亮出主题，发出倡议 演讲稿需要先交代主题和对象
第二段 从传统立中心论点：应当理解、愿意、热爱劳动 先立总的立场，后面才有东西可分
第三段 分论点一：劳则生欢，回应“劳动太占时间” 点评：反驳材料中的第一个错误认识
第四段 分论点二：劳则生慧，回应“交给人工智能” 点评：反驳材料中的第二个错误认识
第五段 针对不尊重劳动的现象提问 材料最后一句的现象，也要有着落
第六段 提出希望和建议，呼告同学 任务要求“希望与建议”

一个观察：材料里的第三种说法“花点钱让别人去做”，这篇文章没有单独回应。任务里的每个靶，要不要有着落，是谋篇时要有意识决定的。（此为本课的观察，点评只指出“不足之处为‘希望与建议’部分相对较弱”。）

地图二：《以劳动书写人生风采》（2019年）

段 做什么 为什么放在这里
第一段 点题：因为劳动是财富的源泉，也是幸福的源泉，希望大家热爱劳动 开门见山，符合演讲稿
第二段 从传统与“幸福是奋斗出来的”讲劳动为什么值得 先讲为什么，再讲遇到什么问题
第三段 “然而”：现实中有不理解、不愿意、不尊重劳动的人；概括回应 转折之处，把材料里的说法合起来写
第四段 “诚然……但是……”：承认机器可以代工，指出精神与意志的锤炼不能少 回应放在“怎么办”之前，先把疑问解决
第五段 “因此”：三条建议——理想信念、方式方法、从自身做起 建立在前面的论证上，所以用“因此”
第六、七段 呼吁，收束 演讲稿的结尾

点评说这篇“有驳论也有立论”。走的顺序是：为什么 → 遇到的疑问 → 回应 → 怎么办。

地图三：《让心中燃起劳动之火》（2019年）

段 做什么 为什么放在这里
第一段 交代问题：“劳动无用论”甚嚣尘上；说明这次演讲的目的 先有问题，后有回答
第二段 劳动究竟是什么：用身边的场景阐释 先说清对象是什么
第三段 劳动为什么：为个人和国家的福祉；顺手回应“何不交给人工智能” 阐释之后，才谈价值；回应放在价值里
第四段 怎么办：清扫、整理、布置，路遇环卫工人…… 建议具体到同学的日常
第五段 “诚然”：劳动不是无头苍蝇式的庸碌，要通向目标 在建议之后加一个边界

点评：“文章思路明晰，暗合是什么—为什么—怎么样的思考轨迹，但却不露痕迹。”

同一个任务，三种排法

篇 回应反方的方式 全文顺序
《劳则生欢，劳则生慧》 做成分论点，一个反方一段 立 → 分论点（回应） → 现象 → 建议
《以劳动书写人生风采》 集中在一两段里回应 为什么 → 疑问 → 回应 → 怎么办
《让心中燃起劳动之火》 放在“为什么”里顺带回应 问题 → 是什么 → 为什么 → 怎么办

三种都能成立，各有各的道理。选哪种，要看自己的论点和材料：反方多、各不相同，可以一个一段；反方相近，可以合并；反方只有一个而且不是重点，可以顺带。

子专题五：结构服务论证

三个标准

  1. 清楚：读者知道每一段在做什么。
  2. 有效：每一段都在证明主线，没有多余的段。
  3. 有推进：后一段比前一段多走了一步——多了一个层面，多回答了一个疑问，或多推进了一层。

常见的“假高级”

  • 结构名称很多，推进很少。 三个“承”，其实是并列。（第9课的《进步与退步》）
  • 为“转”而转。 转到别的话题，回不来。（第9课）
  • 回应反方过多。 整篇都在驳，自己的观点只剩一句。（第17课）
  • 一个段里放太多功能。 既下定义，又举例，又转折，又回应，读者不知道它要做什么。
  • 段落太细。 站内这几篇优秀作文，正文都是五到七个自然段。字数有限，结构越复杂，每一部分越写不透。

和第3、9课的关系

第3课和第9课是给你几个“拿来就能用”的骨架。这一课教的是：**不用骨架的名字，也能说清一篇文章的排法。**这时候再回头，第3、9课的名称就是概括它的方便说法，不是先于文章存在的模板。

方法步骤

  1. 读任务：材料里有几种说法？题目里有几个词？要求要哪几部分？
  2. 写主线：用一句话写出这篇文章要一路证明的事。
  3. 排段落：给每段写一个动词，定顺序。
  4. 查着落：任务里的每个靶，有没有着落？没有的，是有意舍弃，还是漏了？
  5. 三问检查：每一段负责什么？删了行不行？换位置行不行？

典型例题

例1　从材料看结构

材料（教学示例）：有人说“读书不如实践”，有人说“实践不如读书”。请写一篇文章。

参考答案（示例）

任务提示：材料里已经有两种相反的说法，需要写出自己的判断。 主线：读书和实践各有作用，判断的关键是它们分别在什么条件下起作用。 排法一：先立自己的判断，再分别回应两种说法，最后写怎么结合。 排法二：先承认两种说法各有道理，再指出各自的局限，最后立起自己的判断。 （涉及辩证，见第14课；回应对方，见第17课。）

例2　写一句主线

《以劳动书写人生风采》的主线，用一句话怎么写？

参考答案（示例）

先说劳动为什么值得，再回应对劳动的几种疑问，最后提出同学们可以怎么做。

常见错误

  1. 只写结构名称，说不出每段做什么。
  2. 材料里的说法，一个也没有回应。
  3. 主线不明：读完说不出这篇文章推进了什么。
  4. 段落太多，每段只有几句，写不透。
  5. 为了显得高级，硬用起承转合。
  6. 回应反方喧宾夺主。

课堂小练

小练1　一段一个动词

给《让心中燃起劳动之火》的每一段写一个动词。

参考答案（示例）

第一段：交代问题；第二段：阐释；第三段：论述价值；第四段：提建议；第五段：设边界。

小练2　三问检查

《劳则生欢，劳则生慧》的第五段（针对不尊重劳动的现象提问），删掉行不行？为什么？

参考答案（示例）

删掉后，前面的论证仍然完整，但材料里“不尊重劳动的现象”就没有着落，也少了“提出问题启发同学”的一步。所以在这个任务里，它是有用的；在别的题目里，这样的段就要看是否被材料要求。

小练3　同一个任务另一种排法

用《以劳动书写人生风采》的材料，设计一种“分论点式”的排法（像《劳则生欢》那样），写出每段的功能。

参考答案（示例）

第一段：点题，发出倡议。第二段：立中心论点。第三段：分论点一，回应“占时间”。第四段：分论点二，回应“交给机器”。第五段：分论点三，回应“花钱代劳”。第六段：建议。第七段：收束。

课后训练

  1. 选一篇你写过的作文，先写出“一句话主线”，再给每段写一个动词。
  2. 读范文《接受帮助，报以帮助》，画出你自己的结构地图，与点评对照。
  3. 读范文《透过那泛黄的老照片》，第9课已按起承转合标注过，这次用“一段一个动词”重新标注，比较两种方法的区别。
  4. 选 2019 年的材料，写一个与站内三篇都不同的排法，说明理由。
