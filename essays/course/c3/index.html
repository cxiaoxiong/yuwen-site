第一阶段 · 基础写作 · 第3课

全文结构

谋篇

有了中心论点和分论点，这一课让你把它们排成一篇完整的文章。

学习目标

  • 能画出议论文“引论、本论、结论”的全文骨架。
  • 分清并列式和递进式，会按论点选择合适的一种。
  • 动笔前能列出一份简明提纲，并说清各部分之间的逻辑关系。
  • 能看出一篇范文用了哪种结构。

这一课讲什么

  1. 总分式开头提出中心论点，中间分说，结尾总结，是最常用的全文骨架。
  2. 并列式本论几个分论点互相平行，没有先后主次。
  3. 递进式本论几个分论点由浅入深，顺序不能调换。

核心认识

教材怎么说

必修下册第一单元“如何阐述自己的观点”：“阐述的结构多种多样，常见的有并列式和层进式。并列式阐述指阐述内容之间的关系是并列的，有时甚至是相对独立的，但这些内容并非互不相关，而是体现了观点的不同方面。层进式阐述则先提出观点，然后分层进行解释，从一个层次递进到下一个层次。文章选用哪种结构来阐述，要由写作的意图和观点本身的特点来决定。”动笔前，“可以先打腹稿或列出提纲，把观点的若干方面梳理一下，看看先说哪些，后说哪些”。（原文见必修下册第一单元 · 单元学习任务）

本课沿用导与练的“递进式”这个叫法，它就是教材和《新材料作文》说的“层进式”。

  • 议论文的整体思路是：提出问题（引论）→ 分析问题（本论）→ 解决问题（结论）。
  • 总分式说的是整篇的“总说—分说”关系；并列式、递进式说的是本论里几个分论点之间的关系。三者不是三选一，而是先用总分式搭骨架，再决定本论用并列还是递进。
  • 结构不是套模板。教材说，选哪种结构“要由写作的意图和观点本身的特点来决定”；落到分论点上，能不能调换顺序，是判断并列还是递进的关键。

子专题一：总分式

什么时候用

任何有中心论点和分论点的议论文，都可以用总分式。它是基础骨架。

《新材料作文》把总分式分成三种：先总后分、先分后总、先总后分再总。高考作文最常用的是最后一种：开头亮出中心论点，中间分说，结尾总结回扣。

怎么做

引论：引材料一句，提出中心论点
本论：分论点一 → 观点句 + 论据 + 分析
      分论点二 → 观点句 + 论据 + 分析
      分论点三 → 观点句 + 论据 + 分析
结论：总结全文，回扣中心论点

写完检查三点：

  • 分论点的排序合乎一般思维习惯。
  • 分论点各自独立，又都围绕中心论点。
  • 分论点内容是平行的，不交叉，不互相包含。

例

站内范文《学好本手，下出妙手，避免俗手》：开头引围棋三手，亮出中心论点；中间三段依次是“学好本手”“下出妙手”“避免俗手”；结尾回到“新时代青年”的号召。教师点评称它“采用总-分-总的结构”，并说“思路清晰”。

容易犯的错

  • 开头长、结尾长，中间的分论点只有几句话。
  • “总”“分”不一致：开头亮出的观点，中间没有分论点撑住。
  • 中间几段各说各的，读不出它们和中心论点的关系。

子专题二：并列式

什么时候用

中心论点包含几个互相平行的方面，几个层次之间没有先后主次，从几个侧面共同证明中心论点。好处是论证全面，有条理，阅卷者一目了然。

怎么做

先判断能不能调换分论点的顺序：能换，多半是并列；一换意思就走不通，就要考虑递进。再用第2课学过的三问法，从同一个问题拆出分论点。

中心论点
├ 分论点一（同一问题的一个回答）
├ 分论点二
└ 分论点三

例一（《新材料作文》）：中心论点“人生路上要点亮理智的灯”，从“为什么”分类阐述：

① 成功时，理智是进击的征帆；② 失败时，理智是振奋的号角；③ 逆境中，理智是希望的曙光。

例二（一轮复习范文）：中心论点“成熟即想开”：想开功名负累；想开挫折坎坷；想开烦恼仇恨。三个方面平行，各一段，每段有观点、有名人事例。

容易犯的错

  • 分论点交叉重叠，如“成功时”和“顺境中”。
  • 排序随意，没有逻辑。可以按“人—集体—国家”“成功—失败—逆境”等顺序排。
  • 明明有先后关系，却硬写成并列，如“怎么做”放在“是什么”前面。

子专题三：递进式

什么时候用

分论点之间有内在联系：后一个建立在前一个之上，由浅入深、由现象到本质、由原因到结果。层次不能随意调换。它更能体现思维的严密，把问题谈深。

怎么做

导与练总结了三种常用模式：

模式 怎么排
层层深入 分论点一浅，分论点二较深，分论点三更深
逐层分析 是什么 → 为什么 → 怎么办
步步剖析 摆现象 → 析危害 → 挖根源 → 指办法

例一（《新材料作文》）：话题“珍惜时间”，中心论点里分三层：

① 珍惜时间是珍惜生命的表现（是什么）；② 珍惜时间能帮助人走向成功（为什么）；③ 珍惜时间应落实到行动中去（怎么做）。

例二（导与练，原示例为问句，这里改写成判断句）：论点“礼赞英雄，助力时代发展”：真正的英雄，源自把平凡工作做好的普通人；崇尚英雄，才能凝聚推动时代发展的力量；学习英雄，就要在自己的岗位上把每一件平凡的事做好。

用递进式，要注意两点：

  • 层次之间有内在的逻辑关系，写前就要安排好先后。
  • 递进不容易一眼看出，所以每段的开头句要写好，既扣住论点，又能看出“往前走了一步”。

容易犯的错

  • 三个分论点其实是并列，却当作递进写，段与段之间没有“更进一步”。
  • 第三层只是第二层的重复。
  • 段首句没有体现递进，读者看不出层次。

怎么选

先判断它们的关系，再选结构，最后检查每段首句。

问自己 答案 选
分论点能调换顺序吗？ 能 并列式
后一个必须建立在前一个之上吗？ 是 递进式

基础阶段，无论选哪一种，全文一般都用总分式的头尾：开头亮论点，结尾回扣。

站内范文《操故事巨椽，谱时代华章》的分论点由人与人的沟通，到个人心灵，到命运，到民族，再到今天，点评称它“显示出逐层推进的逻辑力量”。

本课先不追求

对照式、引议联结式、起承转合，留到第9课。这里只把总分、并列、递进三种基础结构用熟。

典型例题

例1　给材料列提纲

2022年新高考Ⅰ卷材料：本手是基础，妙手是创造，对本手理解深刻，才可能出现妙手；否则难免下出俗手。

  • 中心论点：在生活中，我们应学好本手，下出妙手，避免俗手。
  • 结构：总分式，先总后分再总。
  • 本论：三个分论点，学好本手（基础）→ 下出妙手（创造）→ 避免俗手（回避错误）。
  • 关系：三个分论点有一定的先后关系，也可以看成从三个方面共同证明中心论点，读范文时想想哪种更合理。

站内范文与点评见相关资源。

例2　把分论点排成递进

论点：礼赞英雄，助力时代发展。写出分论点的排序，并说明为什么不宜调换。

参考答案

① 真正的英雄，源自把平凡工作做好的普通人（是什么）② 崇尚英雄，才能凝聚推动时代发展的力量（为什么）③ 学习英雄，就要在自己的岗位上把每一件平凡的事做好（怎么做）。这里不宜调换：先回答“什么是英雄”，明确讨论对象；再回答“为什么崇尚英雄”，说明价值；最后回答“怎样学习英雄”，落实到行动，思路由认识逐步走向实践。

例3　改一份提纲：2021年全国乙卷

材料：汉代扬雄以射箭为喻：“修身以为弓，矫思以为矢，立义以为的，奠而后发，发必中矣。”题目说，古人常以比喻说明对理想的追求，“涉及基础、方法、路径、目标及其关系等”，要求结合对自身发展的思考写一篇文章。（题目见高考真题）

一位同学的提纲：

  • 中心论点：青年要追求理想。
  • 分论点一：理想很重要。
  • 分论点二：扬雄的话很有道理。
  • 分论点三：我们要努力奋斗。

请指出问题，再改成一份提纲。

参考答案（本站整理）

问题：① 中心论点太宽，没有用上材料里的弓、矢、的、发；② 三个分论点不回答同一个问题：一是“为什么”，二是在评价材料，三是“怎么做”；③ 分论点二只是复述材料，不是观点。

一种改法（并列式）：

  • 中心论点：追求理想，先修身、正思、立义，再付诸行动。
  • 分论点一：修身为弓：理想要靠修养打底（基础）。
  • 分论点二：矫思为矢：思想端正，努力才有准头（方法）。
  • 分论点三：立义为的：目标正当，行动才有方向（目标）。
  • 结尾：“奠而后发”：准备停当，再把理想变成行动。

三个分论点是射箭前的三项准备，回答的是同一个问题“追求理想要准备什么”，调换顺序意思不变，所以是并列；结尾用“奠而后发”把三者收到行动上。材料没有规定三项谁先谁后，所以并列最稳。如果想写成递进，就要说出每一层为什么建立在上一层之上，比如“修身才能正思，正思才能立义”，并且找得到依据，否则只是把并列排了个顺序。

常见错误

  1. 没有提纲，边想边写，写到哪算哪。
  2. 全文只有论点和论据，中间没有分论点。
  3. 用了并列式，几个分论点互相交叉或包含。
  4. 用了递进式，几个分论点顺序可以随意调换。
  5. 开头和结尾占了大半篇，本论过薄。一个规范的主体段一般 200–300 字，全文有 2–3 个主体段。
  6. 段与段之间没有段首观点句，读不出逻辑。

课堂小练

小练1　判断关系

判断下面两组分论点是并列还是递进，并说出理由。

甲：成功时，理智是进击的征帆；失败时，理智是振奋的号角；逆境中，理智是希望的曙光。 乙：珍惜时间是珍惜生命的表现；珍惜时间能帮助人走向成功；珍惜时间应落实到行动中去。

参考答案

甲：并列。三个场合平行，互相不依赖，可以调换顺序。乙：递进。按“是什么—为什么—怎么做”排列，前一个是后一个的基础，不宜调换。

小练2　列并列式提纲

中心论点：关注你身边的人。请用并列式，按“不同身份的人”拆出三个分论点。

参考答案（示例，来自《新材料作文》）

① 关注平凡的人：看他们淡泊宁静的处世态度，陶冶我们年轻的心；② 关注贫穷的人：看他们为维护尊严而坚挺的傲骨，我们会变得更坚强；③ 关注成功的人：看他们为理想拼搏洒下的汗水，让我们更有斗志。三个对象平行，可以调换顺序。

小练3　读范文，画骨架

读站内范文《学好本手，下出妙手，避免俗手》，画出它的骨架：引、分论点各是什么，结尾怎样回扣。

参考答案（本站整理，依据范文原文与教师点评）
  • 引（第一段）：由围棋“三手”引出启示，亮出中心论点：在生活中，我们应学好“本手”，下出“妙手”，避免“俗手”，方能走向成功。
  • 分论点一（第二段）：学好本手。本手是妙手的基础。
  • 分论点二（第三段）：下出妙手。妙手是本手的创造。
  • 分论点三（第四段）：避免俗手。不能本末倒置，要先固基础，再求创新。
  • 结尾（第五段）：回扣“三手”的智慧，落到“担当民族复兴大任的新时代青年”，呼吁打好基础、敢于创新。

骨架是总—分—总。点评说，中间三段“每段均侧重在一个方面，但是均注意阐明三手之间的逻辑关系”。

课后训练

  1. 站内范文《学好本手，下出妙手，避免俗手》：把每一段的段首句抄下来，画出骨架，并判断本论更接近并列还是递进。
  2. 站内范文《操故事巨椽，谱时代华章》：读教师点评，说说为什么点评认为它有“逐层推进”的力量，又为什么认为分论点偏多。
  3. 2019年高考作文题（面向同学的演讲稿）：材料写了一些同学不愿劳动的现象。请用递进式列一份提纲（可参考“摆现象—析原因—提建议”），写出每一段的段首句。
