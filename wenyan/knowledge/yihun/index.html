古代文化常识

高频易混总表

汇总各专题「易混辨析」：先看 ✗ 的说法错在哪，再看 ✓ 的正确说法。尚未整理的专题：。

姓名字号与年龄称谓

  • ✗ 称对方的名，是对对方的尊敬。→ ✓ 称名一般不表示尊敬。自称、作传、尊者对卑者、对憎恶轻视的人才直称名。
  • ✗ 字用于上对下、长对少的称呼。→ ✓ 字用于平辈相称，下对上、卑对尊也称字；长辈对晚辈多直称名。
  • ✗ 女子有名无字。→ ✓ 女子十五岁行笄礼（许嫁）时取字，如谢道韫字令姜。
  • ✗ 「忠毅」「文正」是号。→ ✓ 是谥号：死后由朝廷评定；号是自己取的。
  • ✗ 「庖丁」的「丁」是姓。→ ✓ 庖是职业，丁是名字。
  • ✗ 「临川」是王安石的字。→ ✓ 临川是王安石的籍贯，他字介甫，号半山。
  • ✗ 《杜工部集》的「工部」是杜甫的号。→ ✓ 是官职（杜甫官至工部员外郎）。
  • ✗ 《聊斋志异》的「聊斋」是作者的号。→ ✓ 聊斋是蒲松龄的书室名。
  • ✗ 束发、结发都指男子十五岁。→ ✓ 束发指男孩成童（约十五岁）；「结发」在《孔雀东南飞》里指成婚，不是年龄。
  • ✗ 及笄指男子二十岁。→ ✓ 及笄是女子十五岁；男子二十岁是弱冠。
  • ✗ 豆蔻年华指女子十五岁。→ ✓ 豆蔻指十三四岁；十五岁是及笄。
  • ✗ 花甲和耳顺是两个不同的年龄。→ ✓ 都指六十岁。
  • ✗ 垂髫指老人。→ ✓ 垂髫指儿童（「黄发垂髫」里黄发才是老人）。
  • ✗ 苏洵号东坡居士，苏轼号老泉。→ ✓ 苏洵号老泉，苏轼号东坡居士，苏辙号颍滨遗老。

回到专题

谦称敬称

  • ✗ 「足下」是同辈之间的称呼，不能用于下对上。→ ✓ 下称上、同辈相称都可用（「再拜献大王足下」）。另注意《孔雀东南飞》「足下蹑丝履」的「足下」是脚下，不是称呼。
  • ✗ 所有人对君主都可自称「臣」，包括百姓。→ ✓ 「臣」是臣子（官员）对君主的自称，平民不称臣。
  • ✗ 寡人是君主在失德之后的自称。→ ✓ 寡人是「寡德之人」的谦称，是君主、诸侯平时的谦称。
  • ✗ 「丈人」就是岳父。→ ✓ 《苏武传》里的「丈人」是对长辈的尊称。
  • ✗ 「卿」一律是对人的尊称。→ ✓ 多义：高级官名；对人的敬称；君对臣、上对下的称呼；夫妻间的爱称。
  • ✗ 家父、家慈、家严都称父亲。→ ✓ 家父、家严、家君称父亲；家母、家慈称母亲。
  • ✗ 「陛下」「执事」直接指对方本人。→ ✓ 本义分别是台阶下的侍者、办事的人，借以称对方，是不敢直呼的委婉说法。
  • ✗ 「先」只用于已故的父母。→ ✓ 已故的尊长都可加「先」：先帝、先大母、先考、先妣。

回到专题

谥号·庙号·年号

  • ✗ 元丰是宋神宗的庙号，「元丰七年」是庙号纪年。→ ✓ 元丰是年号，神宗是庙号，「元丰七年」是年号纪年。「元和」与「宪宗」、「乾隆」与「高宗」也这样对应。
  • ✗ 谥号是生前得到的。→ ✓ 谥号是死后评定的；年号是在位时用的；尊号、徽号多在生前加。
  • ✗ 谥号都是褒扬的称号。→ ✓ 有美谥、平谥、恶谥三类，如「怀」是平谥，「厉」「炀」是恶谥。
  • ✗ 秦昭王和楚怀王都是美谥。→ ✓ 「昭」是美谥，「怀」是平谥。
  • ✗ 「忠毅」「文正」是号。→ ✓ 是谥号。号是自己取的。
  • ✗ 一个皇帝只有一个年号，新君即位必须改年号。→ ✓ 明代以前一帝可以多次改元（汉武帝用过十一个年号）；明清一般一帝一个年号。
  • ✗ 年号始于秦始皇。→ ✓ 年号始于汉武帝（建元）。
  • ✗ 庙号就是谥号。→ ✓ 庙号是太庙奉祀用的名号（祖、宗）；谥号是评价性的称号。

回到专题

中央官制与三省六部

  • ✗ 三公就是丞相、太尉、御史大夫，历代不变。→ ✓ 周为太师、太傅、太保；秦、西汉为丞相、太尉、御史大夫；东汉为太尉、司徒、司空。
  • ✗ 尚书省负责决策，中书省负责执行。→ ✓ 中书决策、门下审议、尚书执行。
  • ✗ 礼部掌管土地、户籍。→ ✓ 土地户口赋税归户部；礼部管典礼、祭祀、科举、学校。
  • ✗ 科举考试由吏部主持。→ ✓ 科举归礼部；吏部管官吏的任免考核。
  • ✗ 御史台负责选拔、纠察、弹劾官员。→ ✓ 御史台是监察机构，职责是纠察、弹劾，不包括选拔。
  • ✗ 诏书从周代起就是皇帝布告臣民的专用文书。→ ✓ 周代君臣上下都可用「诏」；秦始皇改「令」为「诏」后才成为皇帝专用。
  • ✗ 「有司」就是今天说的「有关部门」。→ ✓ 有司指主管某事的官吏，泛指官吏。
  • ✗ 「郎中」是医生，「博士」是学位。→ ✓ 在文言文里多是官名：郎中是尚书省属官，博士是学官。
  • ✗ 楚国令尹之下的左尹、右尹，右尹地位略高。→ ✓ 左尹地位略高。
  • ✗ 侍中一定是正式的实职。→ ✓ 汉代侍中是本官之外的加官（教材注）。
  • ✗ 丞相一职历代都有。→ ✓ 秦以后时废时设，明太祖废丞相后不再恢复，由内阁大学士行其职权。

回到专题

地方官制与行政区划

  • ✗ 州、郡、县是一回事，只是叫法不同。→ ✓ 郡、州、府是县之上的政区，层级和辖区随朝代变化；县是基层政区。
  • ✗ 春秋战国时期都是郡比县大。→ ✓ 春秋以前县大于郡；战国以后郡才大于县，县隶属于郡。
  • ✗ 「郡县」和「郡县制」没有区别。→ ✓ 「郡县」是政区名称；「郡县制」是继分封制之后出现的两级地方管理制度。
  • ✗ 汉代刺史就是一州的行政长官。→ ✓ 汉代刺史是巡视州部的监察官；东汉末以后才掌握一州军政；隋唐才是州的长官。
  • ✗ 刺史、太守、知州都是一个级别。→ ✓ 太守管郡；刺史管州（汉为监察官）；知州、知府是宋以后的称呼，不能拿来直接对号。
  • ✗ 大县的长官称「长」，小县的长官称「令」。→ ✓ 大县称「令」，小县称「长」。
  • ✗ 「从事」都是指汉代刺史的属吏。→ ✓ 「从事」汉代确指刺史属官，但后世也泛指一般属官，要看语境。
  • ✗ 唐代的司马是一州的实权长官。→ ✓ 唐代州司马是刺史之佐，实为闲职。
  • ✗ 节度使是宋代设立的地方民政长官。→ ✓ 节度使是唐代在军事重镇设立的军政长官，兼管军政财政。
  • ✗ 明清的抚军是掌管一府的官。→ ✓ 抚军是巡抚的别称，管一省。

回到专题

官职任免升降

  • ✗ 「迁」就是升官。→ ✓ 迁泛指调动官职，多指升迁；「左迁」是降职；《屈原列传》「迁之」是放逐。
  • ✗ 「左迁」是向左边调动、平级调任。→ ✓ 古代以右为尊、以左为卑，左迁、左除、左降都是降职。
  • ✗ 「拜」「除」只能表示升官。→ ✓ 都是授予官职，看后面跟的官名才知道升降（教材注：拜，授官；除，授官）。
  • ✗ 「黜」是升职。→ ✓ 黜（绌）是罢免、贬退；「陟」才是升职（「黜陟」＝降免与升迁）。
  • ✗ 「致仕」是开始做官。→ ✓ 致仕是交还官职、退休；「出仕」「仕进」才是做官。
  • ✗ 「乞骸骨」是请求赐死。→ ✓ 是请求退职，意思是让骸骨得以归葬故乡。
  • ✗ 「徙」一定是迁居。→ ✓ 在官职语境里，徙是调动官职（「徙齐王信为楚王」）。
  • ✗ 「守」「摄」「权」表示正式任职。→ ✓ 都是暂时代理；「守」多指以较低官阶代理较高职务。
  • ✗ 「出」是出使。→ ✓ 在任免语境里，「出」多指京官外放地方（「出官」）。
  • ✗ 「视事」是看事情，「下车」是下车子。→ ✓ 视事是到职工作；下车是官吏刚到任。
  • ✗ 「谪」只是流放，与官职无关。→ ✓ 谪是因罪降职或流放，「谪守巴陵郡」仍是做官，只是被贬。
  • ✗ 「起」就是起义、起兵。→ ✓ 在任免语境里是重新起用（「起为太医院都事」）。

回到专题

选官、科举与学校

  • ✗ 征辟和察举都是地方长官推荐人才。→ ✓ 征辟是上级（皇帝、府主）直接征召、聘用；察举是地方长官考察后向朝廷推荐。
  • ✗ 孝廉是「学业优异」的人。→ ✓ 孝廉指孝顺亲长、廉能正直；察举科目，重在品行。
  • ✗ 察举是自上而下选拔人才的制度。→ ✓ 按题库答案的口径，察举是地方长官向朝廷推举（自下而上），征辟是上级直接征聘（自上而下）；这是本站常用的解题说法，不是对察举的无条件定义。
  • ✗ 「秀才」在任何时代都指县学生员。→ ✓ 汉代是察举科目（东汉改称茂才）；明清才指府、州、县学生员。
  • ✗ 乡试中了叫贡士，会试中了叫举人。→ ✓ 乡试中举人，会试中贡士，殿试中进士。
  • ✗ 贡士就是贡生。→ ✓ 贡士是会试中式者；贡生是被选送国子监的生员。
  • ✗ 殿试第一名是解元。→ ✓ 解元是乡试第一名，会元是会试第一名，状元是殿试第一名。
  • ✗ 会试由皇帝主持。→ ✓ 会试由礼部主持；殿试才由皇帝主持。
  • ✗ 童生就是秀才。→ ✓ 童生是尚未考取生员的读书人；院试录取后才是生员（秀才）。
  • ✗ 「太学」和「国子监」在任何朝代都是同一个机构。→ ✓ 汉代有太学；唐宋国子监是中央教育管理机构，太学等学校隶属其下，具体关系各时期有变化；明清常以「太学」泛称国子监。掌管其教育的官员称祭酒。
  • ✗ 「六艺」永远是《诗》《书》《礼》《乐》《易》《春秋》。→ ✓ 六艺有两个义项：礼乐射御书数六种技能，也指六部经书，要看语境。

回到专题

宗法、亲属与丧服

  • ✗ 嫡子、嫡长子、庶子可以随便称呼。→ ✓ 嫡子是正妻所生的儿子，嫡长子是正妻的长子；庶子是妾所生的儿子。
  • ✗ 宗子就是长子。→ ✓ 宗子是嫡长子，继承大宗，是一宗之主；并非所有长子都是宗子。
  • ✗ 宗室和外戚是一回事。→ ✓ 宗室是与君主同一宗族的人（皇族）；外戚是皇后、太后一方的亲族。
  • ✗ 大功指五个月，小功指九个月。→ ✓ 大功九个月，小功五个月。
  • ✗ 期功之亲指关系疏远的亲戚。→ ✓ 期功之亲是需要为其服一年至五个月丧服的较近亲属，「外无期功强近之亲」是说没有近亲。
  • ✗ 家父、家慈、家严、家君都指父亲。→ ✓ 家父、家严、家君、家尊指父亲，家慈、家母指母亲。
  • ✗ 「先」都是对去世的人的敬称，可以随便用。→ ✓ 「先」用于已故的尊长：先考、先父（父）、先妣、先母（母）、先大母（祖母）；不能用于生者。
  • ✗ 「季」是排行第三。→ ✓ 「季」是兄弟排行里最小的，季父指最小的叔父（教材注为叔父）。
  • ✗ 「伯」和「孟」完全一样。→ ✓ 都表示排行最大；嫡长子称伯，庶长子称孟。
  • ✗ 舅一定是母亲的兄弟。→ ✓ 「舅」可指母之兄弟，也可指丈夫的父亲（舅姑），还可指妻之兄弟，要看语境。
  • ✗ 从兄弟就是亲兄弟。→ ✓ 从兄弟即堂兄弟，是同祖父的兄弟。

回到专题

祭祀与丧葬

  • ✗ 「封」是祭地，「禅」是祭天。→ ✓ 封是在泰山顶上祭天，禅是在泰山脚下梁父山上祭地。
  • ✗ 太牢用羊、猪各一头，少牢用牛、猪各一头。→ ✓ 太牢是牛、羊、猪各一头；少牢是羊、猪各一头。
  • ✗ 衅鼓是敲鼓助威。→ ✓ 衅鼓是杀牲（或杀人）取血涂在鼓上举行祭祀。
  • ✗ 庙社就是庙里的神社。→ ✓ 庙指宗庙，社指社稷，庙社借指国家朝廷。
  • ✗ 天子、诸侯、大夫、士、庶人都可设宗庙。→ ✓ 按古制，天子七庙、诸侯五庙、大夫三庙、士一庙，庶人不设庙。
  • ✗ 七庙是七座寺庙。→ ✓ 七庙是天子供奉七代祖先的宗庙，借指王朝、国家。
  • ✗ 「崩」「薨」「卒」是同一个意思，可以互换。→ ✓ 天子崩，诸侯薨，大夫卒，士不禄，庶人死，按身份区分。
  • ✗ 「舞」是求雨的祭祀仪式。→ ✓ 「雩」才是求雨的祭祀；因为伴以乐舞，所以叫「舞雩」。
  • ✗ 血食指吃血制的食品。→ ✓ 血食指享受祭祀，因古代杀牲取血以祭得名；「不血食」指没有后人祭祀。
  • ✗ 「席薪枕块」是贫穷时的睡法。→ ✓ 是居丧时的礼俗，睡柴草、枕土块，表示悲哀。

回到专题

礼仪、座次与避讳

  • ✗ 坐、跪、跽是同一个姿势。→ ✓ 坐是臀部压在脚后跟上；跪是臀部抬起；跽（长跪）是跪而挺腰耸身。
  • ✗ 稽首和顿首都是「头叩地即起」。→ ✓ 稽首是头至地并停留较久，最重；顿首是头叩地即起。
  • ✗ 再拜就是拜一次。→ ✓ 再拜是拜两次，是较重的礼节。
  • ✗ 古代的「揖」就是现在的握手。→ ✓ 揖是推手礼，分土揖、时揖、天揖；执手才类似握手。
  • ✗ 室内座次以南向为尊，堂上以东向为尊。→ ✓ 堂上以南向为尊；室内以东向为尊（《鸿门宴》）。
  • ✗ 「南面」是称臣，「北面」是称王。→ ✓ 南面称王称帝，北面称臣。
  • ✗ 古人不论什么场合，都是以右为尊。→ ✓ 官位、居住多尚右，车乘、吉礼常尚左，要看语境。
  • ✗ 「左迁」是升官。→ ✓ 左迁是降职、贬官。
  • ✗ 女子出嫁叫「归宁」。→ ✓ 出嫁叫「归」，「归宁」是出嫁的女子回娘家省亲。
  • ✗ 避讳只是不说皇帝的名字。→ ✓ 避讳有国讳、家讳、圣人讳，方法有改字、空字、缺笔、改音。
  • ✗ 「彻侯」「通侯」是两种不同的爵位。→ ✓ 同一爵位，因避汉武帝刘彻讳改称通侯。
  • ✗ 三驱是田猎时设网一面，留三面不设。→ ✓ 三驱是设网三面，留一面不设，表示田猎有度、有好生之德（教材《谏太宗十思疏》「三驱以为度」）。

回到专题

纪年·纪月·纪日·纪时

  • ✗ 「壬戌之秋」的「壬戌」是年号。→ ✓ 是干支纪年；同篇背景「元丰五年」才是年号纪年。
  • ✗ 干支只能用来纪年。→ ✓ 干支可以纪年、纪月、纪日（「戊申晦」「六月丁丑」都是纪日）。
  • ✗ 「戊申晦」的「戊申」是干支纪月。→ ✓ 是干支纪日：戊申日，恰是月底。
  • ✗ 「闰某月」指加在某月之前的那个月。→ ✓ 加在某月之后的那个月叫「闰某月」。
  • ✗ 农历每月十五叫「弦」。→ ✓ 十五（大月十六）叫望；初七八是上弦，二十二三是下弦。
  • ✗ 既望是十五，望是十六。→ ✓ 望通常是十五，既望是望后一天，通常是十六。
  • ✗ 晦是每月初一。→ ✓ 晦是最后一天，朔才是初一。
  • ✗ 一夜分为三更，每更一个时辰。→ ✓ 一夜分为五更（戌、亥、子、丑、寅），每更约一个时辰。
  • ✗ 暮春指春天过后的四月。→ ✓ 暮春即季春，农历三月。
  • ✗ 「三五之夜」是初三、初五的夜晚。→ ✓ 三乘五，是十五的夜晚。
  • ✗ 《孔雀东南飞》「六合正相应」与《过秦论》「制六合」的「六合」意思相同。→ ✓ 前者指月建与日辰相合的吉日，后者指天地四方。
  • ✗ 年号纪年始于秦始皇。→ ✓ 始于汉武帝（第一个年号「建元」）。
  • ✗ 古人以岁星纪年，把周天分为七个星次。→ ✓ 分为十二个星次，岁星每年行经一个星次。

节日节气与天文星宿

  • ✗ 中元节是农历八月十五。→ ✓ 中元节是农历七月十五，追怀先人的传统节日。
  • ✗ 上巳节是三月初一。→ ✓ 上巳原为三月上旬的巳日，三国魏以后固定为三月初三。
  • ✗ 修禊是饮酒赋诗的宴会。→ ✓ 修禊是到水边嬉戏、祓除不祥的民俗；饮酒赋诗是曲水流觞的雅集。
  • ✗ 寒食节就是清明节。→ ✓ 寒食在冬至后一百零五日，清明前一二日；清明本是节气，后与寒食习俗相融。
  • ✗ 「白露横江」中的「白露」是二十四节气之一。→ ✓ 教材注为白茫茫的水汽。
  • ✗ 「至日」一定是夏至。→ ✓ 教材《扬州慢》注为冬至，要看语境。
  • ✗ 二十八宿是指二十八颗星。→ ✓ 二十八宿是二十八个星区（星座群）。
  • ✗ 斗牛是「斗」和「牛」两个动物。→ ✓ 斗牛是斗宿和牛宿两个星宿，玄武七宿中的前两宿。
  • ✗ 岁星就是北斗星。→ ✓ 岁星是木星；北斗是北斗七星。
  • ✗ 岁星纪年是把一周天分为七个星次。→ ✓ 一周天分十二个星次，岁星每行经一个星次为一年。
  • ✗ 星宿、分野是纯粹的迷信，与文化常识无关。→ ✓ 分野是古代星象与地域相配的说法，用于解释诗文中的星象地理用语，只需作知识识记，不必当作科学结论。

地理称谓与古今地名

  • ✗ 「山东」就是今天的山东省。→ ✓ 教材注为崤山以东，泛指东方六国之地。
  • ✗ 「山东」在战国秦汉时指泰山以东。→ ✓ 指崤山（函谷关）以东；战国时除秦外，六国都在崤山以东，故称「山东之国」。
  • ✗ 「河北」「河南」就是今天的河北省、河南省。→ ✓ 多指黄河以北、黄河以南。
  • ✗ 「河内」是黄河以南。→ ✓ 河内泛指黄河以北地区。
  • ✗ 「江东」「江左」「江表」范围完全相同。→ ✓ 江表泛指长江以南，江东（江左）多指长江下游南岸，常互相通用。
  • ✗ 「阳」指山的北面或水的南面。→ ✓ 「阳」指山的南面或水的北面，「阴」相反。
  • ✗ 「水南为阳」。→ ✓ 水北为阳，水南为阴。
  • ✗ 「北海」在任何文章里都指贝加尔湖。→ ✓ 《苏武传》指贝加尔湖；《齐桓晋文之事》指渤海。
  • ✗ 城墙里边的一道是「郭」，外边的一道是「城」。→ ✓ 里边一道叫「城」，外边一道叫「郭」。
  • ✗ 「和亲」专指汉族封建王朝与少数民族首领的联姻。→ ✓ 也指少数民族首领之间有政治目的的联姻。
  • ✗ 「九州」中有「郑州」。→ ✓ 九州是冀、兖、青、徐、扬、荆、豫、梁、雍，没有「郑州」。
  • ✗ 「五服」都指丧服。→ ✓ 也可指王畿以外的甸服、侯服、绥服、要服、荒服。

军事与兵制

  • ✗ 「乘」就是骑马。→ ✓ 「乘（shèng）」是量词，一车四马为一乘；「千乘」「万乘」表示兵车数量。
  • ✗ 「百乘」指一百个骑兵。→ ✓ 「百乘」指一百辆兵车，常用来代指兵力。
  • ✗ 「万乘」只指天子。→ ✓ 万乘既可指兵车万辆、军事力量强大，也可以指天子、大国。
  • ✗ 「部曲」在任何时候都是部队的编制单位。→ ✓ 部曲有编制单位和私家军队两义，「逖将其部曲百余家」是私家军队。
  • ✗ 「金」是刁斗发出的声音。→ ✓ 「金」指锣、钲，击金收兵；刁斗是军中用具，白天煮饭、夜间敲击巡逻。
  • ✗ 「衔枚」是嘴里含着食物。→ ✓ 衔枚是口中横衔一根形如筷子的枚，防止喧哗。
  • ✗ 「檄」是私人书信。→ ✓ 檄是官府用来征召、晓谕、声讨的文书。
  • ✗ 「校尉」永远是具体的官名，不是泛称。→ ✓ 汉代校尉是将军的属官，教材《燕歌行》中的「校尉」泛指统帅。
  • ✗ 「胄」只指头盔。→ ✓ 胄一指头盔（甲胄），二指子孙后代（贵胄），要看语境。
  • ✗ 「差强人意」是勉强不能让人满意。→ ✓ 原义为尚能振奋人的意志；后来引申为大体还能让人满意。
  • ✗ 「车驾」是普通的车。→ ✓ 车驾是帝王所乘的车马，常代指帝王。
  • ✗ 「戍」就是打仗。→ ✓ 戍是守边、驻守；谪戍是因罪被征调去守边。

刑罚与司法

  • ✗ 五刑只有一套：笞杖徒流死。→ ✓ 有先秦和隋唐以后两套：先秦（通行说法）为墨（黥）、劓、刖（剕）、宫、大辟；隋唐以后为笞、杖、徒、流、死。
  • ✗ 大辟是流放。→ ✓ 大辟是砍头，古代死刑的通称。
  • ✗ 「抵极刑」是死刑外加暴尸示众。→ ✓ 极刑即死刑，「抵」是达到；尸体示众叫弃市。
  • ✗ 弃市是流放边地。→ ✓ 弃市是在闹市处死并陈尸示众。
  • ✗ 黥、墨刑和宫刑是同一种刑罚。→ ✓ 黥（墨）是刺面涂墨；宫是破坏生殖机能。
  • ✗ 刖和膑是割鼻。→ ✓ 割鼻是劓；刖是砍脚，膑是剔去膝盖骨。
  • ✗ 笞和杖完全相同。→ ✓ 都是用棍板责打，笞用荆条竹板，较轻；杖用大板，较重。
  • ✗ 「族」只是一个姓氏。→ ✓ 在刑罚中「族」指灭族，一人犯死罪牵连全家被杀。
  • ✗ 连坐和族是一回事。→ ✓ 连坐（相坐）是与犯罪者有关系的人连带受刑，不一定处死；族是株连全家处死。
  • ✗ 廷尉和大理寺是两个完全不同的机构。→ ✓ 廷尉是秦汉掌刑狱之官，汉后改称大理；北齐以后称大理寺。
  • ✗ 御史台负责审判案件。→ ✓ 御史台是监察机构，负责纠察、弹劾；审判由廷尉、大理寺、刑部承担。
  • ✗ 三法司是历代不变的一组机构。→ ✓ 「三法司」固定指明清的刑部、大理寺、都察院；唐代是「三司会审」，成员和名称不同。

经史子集与诸子百家

  • ✗ 《老子》属于经部。→ ✓ 《老子》是道家著作，属子部。
  • ✗ 「四书」是《大学》《荀子》《论语》《孟子》。→ ✓ 四书是《大学》《中庸》《论语》《孟子》，没有《荀子》。
  • ✗ 「五经」包括《乐》。→ ✓ 《乐》已亡佚，五经是《诗》《书》《礼》《易》《春秋》。
  • ✗ 《师说》中的「六艺」是礼乐射御书数。→ ✓ 《师说》中的「六艺」指六部经书；礼乐射御书数是另一义。
  • ✗ 「传」就是人物传记，「六艺经传」的「传」指《史记》《汉书》的传。→ ✓ 「传」在这里指解释经书的著作。
  • ✗ 《左传》是国别体。→ ✓ 《左传》是编年体，按年月顺序记事；国别体是《国语》《战国策》。
  • ✗ 《左传》原名《春秋》。→ ✓ 《左传》原名《左氏春秋》，汉代改称《春秋左氏传》；《春秋》是另一部书。
  • ✗ 《礼记》是秦汉以来的礼仪论著。→ ✓ 秦汉以前；相传为西汉戴圣编撰。
  • ✗ 《史记》是断代史。→ ✓ 《史记》是通史，《汉书》才是我国第一部纪传体断代史。
  • ✗ 「三玄」是《老子》《孟子》《庄子》。→ ✓ 三玄是《老子》《庄子》《周易》。
  • ✗ 《庄子》是春秋中期庄子一人所著。→ ✓ 庄子是战国中期思想家；《庄子》是庄子及其后学所著。
  • ✗ 「圣人」在任何诸子文章里都指孔子。→ ✓ 「圣人」有多种含义，如《墨子》中指德高望重、有大智的人。
  • ✗ 诸子散文是两汉散文。→ ✓ 诸子散文是先秦各学派的著作。

回到专题

古代文体

  • ✗ 「表」是下级向上级陈述的一般文体。→ ✓ 表特指臣下向帝王陈情言事的文体。
  • ✗ 疏和表完全相同。→ ✓ 疏是分条陈述意见，表是陈述某种意见或事情，都属奏议，侧重不同。
  • ✗ 战国时臣下上书称「表」。→ ✓ 战国时统称为「书」，汉代才分章、奏、表、议。
  • ✗ 「书」只指书信。→ ✓ 「书」还可指上书（《谏逐客书》）。
  • ✗ 序都是为别人的书作的前言。→ ✓ 序有书序（前言）和赠序（送别题赠）；《兰亭集序》是为诗集所作的序，不是朋友之间唱和的赠言。
  • ✗ 「传」就是人物传记。→ ✓ 「传」也指解释经书的著作（「六艺经传」）。
  • ✗ 「记」和「志」毫无关系。→ ✓ 「志」有「记」的意思，《项脊轩志》属记叙类。
  • ✗ 「论」和「说」都是议论，没有区别。→ ✓ 论多议论政治得失、史事；说重在阐发道理，如《师说》。
  • ✗ 「赋」和「辞」完全等同。→ ✓ 辞重言情，赋重铺陈，汉代合称辞赋。
  • ✗ 《阿房宫赋》是骈赋，不是文赋。→ ✓ 教材清单题指出杜牧《阿房宫赋》是文赋的代表。
  • ✗ 《离骚》是政治叙事诗。→ ✓ 《离骚》是政治抒情诗。
  • ✗ 「吟」「行」「歌」是同一个诗体的不同写法，没有区别。→ ✓ 都是古体诗的体式，形式活泼、不拘一格，相似但不完全等同。
  • ✗ 「留别」是抒发惜别之情。→ ✓ 「留别」是临行前留下诗文向朋友话别；《梦游天姥吟留别》主要写梦游与态度，并未表达惜别之感（《导与练》该题解析）。

衣食住行与器物音乐

  • ✗ 「冠」是所有人都戴的帽子。→ ✓ 冠是一般贵族男子所戴；先秦时小孩、罪犯、异族人、平民一般不戴冠，后世的头饰另当别论。
  • ✗ 「冠」「冕」没有区别。→ ✓ 冕是祭祀时所戴的极尊贵的礼冠，冠顶有延，前垂旒。
  • ✗ 「襦」是长袄，「袍」是短袄。→ ✓ 襦是短袄，袍是长袄。
  • ✗ 「环」「玦」是同一种佩玉。→ ✓ 环是圆形中空；玦是环边有缺口。
  • ✗ 「笏」是一种兵器。→ ✓ 笏是君臣朝见时手中所执的板子，用于指画、记事。
  • ✗ 「鼎」是盛酒器。→ ✓ 鼎是煮肉盛肉的器具；樽、卮、觞才是酒器。
  • ✗ 「俎」「刀俎」是砍人的刑具。→ ✓ 俎是砧板，刀俎是刀和砧板，比喻任人宰割。
  • ✗ 「东宫」只指太子。→ ✓ 东宫是太子所居之宫，也借指太子；汉代长乐宫也称东宫，借指太后。
  • ✗ 「便殿」是正殿。→ ✓ 便殿是正殿以外的别殿。
  • ✗ 「妃嫔媵嫱」是同一类身份，「媵」也是宫中女子的名位。→ ✓ 妃地位次于皇后，嫔、嫱有一定等级，具体名位因时代而异；媵是陪嫁的人。
  • ✗ 「步」是跨出一脚。→ ✓ 跨出一脚是「跬」，跨出两脚是「步」。
  • ✗ 「十驾」是十辆马车。→ ✓ 十驾是劣马拉车走十天的行程。
  • ✗ 「金」在秦汉一样：一金＝一斤。→ ✓ 秦代二十两黄金为一金，汉代一斤黄金为一金。
  • ✗ 「乐师」「伶官」都是普通歌女。→ ✓ 乐师是以演奏音乐为职业的人；伶官是宫廷乐官和授有官职的演戏艺人。
