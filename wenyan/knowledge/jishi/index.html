1　知识梳理

四个层级，各有几种方法：

  • 纪年： 王公即位年次（「赵惠文王十六年」）、年号（「元和十年」）、干支（「壬戌之秋」）、年号＋干支兼用（「淳熙丙申」「永和九年，岁在癸丑」）。
  • 纪月： 序数（正月、二月……）；孟、仲、季（每季第一、二、三个月）；地支建月（建寅为正月……建子为十一月）；闰月。
  • 纪日： 干支纪日（「戊申晦」「是月丁未」）；序数纪日；月相纪日——朔（初一）、望（十五，大月十六）、既望（望后一天）、晦（最后一天）。
  • 纪时： 十二时辰（地支和天色名两套名称）；夜间分五更（五鼓）；漏刻计时。

干支是一套通用的序号： 十天干（甲乙丙丁戊己庚辛壬癸）与十二地支（子丑寅卯辰巳午未申酉戌亥）依次相配，六十个一循环，所以叫「六十甲子」「花甲」。它既能纪年，也能纪月、纪日。判断是哪一种，看它在句子里的位置：「壬戌之秋」是年，「戊申晦」「六月丁丑」是日。

闰月： 农历比回归年短，大约三年加一个闰月。加在某月之后的那个月叫「闰某月」（2021 年全国甲卷就考了这一点）。

数字相乘表数： 「三五之夜」是十五夜，「二八」是十六岁。

4　易混辨析

  • ✗ 「壬戌之秋」的「壬戌」是年号。→ ✓ 是干支纪年；同篇背景「元丰五年」才是年号纪年。
  • ✗ 干支只能用来纪年。→ ✓ 干支可以纪年、纪月、纪日（「戊申晦」「六月丁丑」都是纪日）。
  • ✗ 「戊申晦」的「戊申」是干支纪月。→ ✓ 是干支纪日：戊申日，恰是月底。
  • ✗ 「闰某月」指加在某月之前的那个月。→ ✓ 加在某月之后的那个月叫「闰某月」。
  • ✗ 农历每月十五叫「弦」。→ ✓ 十五（大月十六）叫望；初七八是上弦，二十二三是下弦。
  • ✗ 既望是十五，望是十六。→ ✓ 望通常是十五，既望是望后一天，通常是十六。
  • ✗ 晦是每月初一。→ ✓ 晦是最后一天，朔才是初一。
  • ✗ 一夜分为三更，每更一个时辰。→ ✓ 一夜分为五更（戌、亥、子、丑、寅），每更约一个时辰。
  • ✗ 暮春指春天过后的四月。→ ✓ 暮春即季春，农历三月。
  • ✗ 「三五之夜」是初三、初五的夜晚。→ ✓ 三乘五，是十五的夜晚。
  • ✗ 《孔雀东南飞》「六合正相应」与《过秦论》「制六合」的「六合」意思相同。→ ✓ 前者指月建与日辰相合的吉日，后者指天地四方。
  • ✗ 年号纪年始于秦始皇。→ ✓ 始于汉武帝（第一个年号「建元」）。
  • ✗ 古人以岁星纪年，把周天分为七个星次。→ ✓ 分为十二个星次，岁星每年行经一个星次。

设错方式 本专题的典型错项 出处
位置颠倒 「闰某月指加在某月之前的那个月」 2021 年全国甲卷（真题）
纪法混淆 「『戊申』是干支纪月」 2024 仿真卷 2
纪法混淆 「『壬戌』为年号纪年」 《导与练》《赤壁赋》
名称错配 「每月……十五叫弦」 2025 一轮讲义 · 教材小练
数字错误 「一夜分为三更」；「一周天分为七个星次」 教材清单《与妻书》《兰亭集序》
同词异义 「六合……与《孔雀东南飞》中『六合正相应』意义相同」 2025 一轮讲义 · 即时训练

真题： 2021 年新高考Ⅰ卷 A 项「甲子……干支相配以纪年月日，文中是纪日」是正确项；2021 年全国甲卷 C 项「闰月」是错误项。

解题抓手： 先看干支后面跟的是「之秋」「岁」（年）还是「晦」「朔」、紧跟在月份后（日）；月相记「初一朔、十五望、十六既望、月底晦」。

仿真 · 教辅练习 2024 年高考仿真卷 2 · 文言文阅读第 11 题（教辅仿真，非真题）

阅读材料

材料一： 夫得言不可以不察，数传而白为黑，黑为白。故狗似玃，玃似母猴，母猴似人，人之与狗则远矣。此愚者之所以大过也。 闻而审，则为福矣；闻而不审，不若无闻矣。齐桓公闻管子于鲍叔，楚庄闻孙叔敖于沈尹筮，审之也，故国霸诸侯也。吴王闻越王勾践于太宰嚭，智伯闻赵襄子于张武，不审也，故国亡身死也。 凡闻言必熟论，其于人必验之以理。鲁哀公问于孔子曰：“乐正夔一足，信乎？”孔子曰：“昔者舜欲以乐传教于天下乃令重黎举夔于草莽之中而进之舜以为乐正。夔于是正六律，和五声，以通八风，而天下大服。重黎又欲益求人，舜曰：‘夫乐，天地之精也，得失之节也。故唯圣人为能和。和，乐之本也。夔能和之，以平天下，若夔者一而足矣。’故曰‘夔一足’，非‘一足’也。”宋之丁氏，家无井，而出溉汲，常一人居外。及其家穿井，告人曰：“吾穿井得一人。”有闻而传之者曰：“丁氏穿井得一人。”国人道之，闻之于宋君。宋君令人问之于丁氏，丁氏对曰：“得一人之使，非得一人于井中也。”求闻之若此，不若无闻也。子夏之晋，过卫，有读史记者曰：“晋师三豕涉河。”子夏曰：“非也，是己亥也。夫己与三相近，豕与亥相似。”至于晋而问之，则曰，晋师己亥涉河也。 辞多类非而是，多类是而非，是非之经，不可不分，此圣人之所慎也。然则何以慎？缘物之情及人之情，以为所闻，则得之矣。 (节选自《吕氏春秋·察传》) 材料二： 庞葱【注】与太子质于邯郸，谓魏王曰：“今一人言市有虎，王信之乎？”王曰：“否。”“二人言市有虎，王信之乎？”王曰：“寡人疑之矣。”“三人言市有虎，王信之乎？”王曰：“寡人信之矣。”庞葱曰：“夫市之无虎，明矣，然而三人言而成虎。今邯郸去大梁也远于市，而议臣者过于三人矣，愿王察之矣。”王曰：“寡人自为知。”于是辞行。而谗言先至。后太子罢质，果不得见。 (节选自《战国策·魏策二》) 【注】　庞葱：一作庞恭，魏国大臣。

3.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  1. A.“若”在文中的意思是“像、如”，与《诗经·卫风·氓》中“其叶沃若”的“若”字意思不同。
  2. B.“己亥”在文中是干支纪日，而《登泰山记》中所言“戊申晦，五鼓”中的“戊申”是干支纪月。
  3. C.“质”在文中的意思是“做人质”，与《论语》中的“文质彬彬”的“质”意思不相同。
  4. D.“罢”在文中的意思是“结束”，与《廉颇蔺相如列传》中的“既罢归国”的“罢”意思相同。
查看答案与解析

答案

B

解析

A项，“其叶沃若”的“若”是形容词词尾，可译为“的样子”。B项，“‘戊申’是干支纪月”错误。两者都是干支纪日。“戊申晦”指的是“戊申日月底这一天”。C项，“文质彬彬”中的“质”是“质朴、朴实”的意思。D项，“罢”在两句中的意思均为“结束”。

5.下列对词语相关内容的解说，不正确的一项是

  1. A.百越，古代越族居住在桂、浙、闽、粤等地，每个部落都有名称，统称“百越”。(选择性必修中册《过秦论》)
