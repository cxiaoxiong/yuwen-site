1　知识梳理

本专题分两块： 一是节日与节气（时间与习俗），二是天文星宿（星宿、星次、分野）。纪年、纪月、纪日、纪时的方法见「纪年·纪月·纪日·纪时」。

传统节日（按农历）：

节日 日期 主要习俗与提醒
元日（今称春节） 正月初一 一年之始；燃爆竹、饮屠苏酒
上元（元宵） 正月十五 观灯
上巳 三月上旬巳日（三国魏以后固定为三月初三） 修禊：到水边嬉戏、祓除不祥（教材《兰亭集序》）
寒食 冬至后一百零五日，清明前一二日 禁火、吃冷食；相传纪念介子推
清明 节气，在公历四月五日前后 踏青、扫墓；《临安春雨初霁》「犹及清明可到家」
端午 五月初五 龙舟、粽子；相传纪念屈原
七夕 七月初七 乞巧；牛郎织女（《鹊桥仙》）
中元 七月十五 追怀先人；民间习俗与佛教的盂兰盆节相融合，但两者来源不同
中秋 八月十五 赏月，团圆（《念奴娇·过洞庭》「近中秋」）
重阳 九月初九 登高、插茱萸、赏菊（《登高》）
腊日（腊八） 先秦、汉代腊祭日期不固定；后世以十二月初八为腊八 腊祭；喝腊八粥
除夕 十二月最后一天 除旧迎新，守岁

二十四节气： 依太阳在黄道上的位置划分，用来安排农事。四季各六个：

  • 春： 立春、雨水、惊蛰、春分、清明、谷雨
  • 夏： 立夏、小满、芒种、夏至、小暑、大暑
  • 秋： 立秋、处暑、白露、秋分、寒露、霜降
  • 冬： 立冬、小雪、大雪、冬至、小寒、大寒

歌诀： 春雨惊春清谷天，夏满芒夏暑相连；秋处露秋寒霜降，冬雪雪冬小大寒。

  • 四立： 立春、立夏、立秋、立冬，标志四季开始。
  • 二分： 春分、秋分，昼夜等长。
  • 二至： 夏至（白昼最长）、冬至（白昼最短）；「至日」常指冬至（教材《扬州慢》「淳熙丙申至日」注：冬至）。
  • 提醒： 《赤壁赋》「白露横江」的「白露」教材注为「白茫茫的水汽」，不是节气；不能因为出现「白露」就判断是白露节气。

二十八宿与四象： 古人为观测日、月、五星的运行，沿黄道、赤道划分了二十八个星区，称二十八宿，分属四大区域：

四象 方位 七宿
青龙（苍龙） 东 角、亢、氐、房、心、尾、箕
玄武 北 斗、牛、女、虚、危、室、壁
白虎 西 奎、娄、胃、昴、毕、觜、参
朱雀 南 井、鬼、柳、星、张、翼、轸
  • 斗牛： 斗宿和牛宿，都是星宿名（教材《赤壁赋》注：「月出于东山之上，徘徊于斗牛之间」）。这里的「斗」是南斗（斗宿），不是北斗七星。
  • 参商： 参宿（西方）和商宿（心宿，东方）此出彼没，永不相见，比喻亲友隔绝。

十二星次与分野：

  • 十二星次： 古人把黄道带分成十二个区域，称十二星次。
  • 分野： 把天上的星宿（星次）与地上的州国区域相对应，称为分野；星象变化被认为预示着相应地域的吉凶。
  • 岁星纪年： 岁星即木星，古人把一周天分为十二个星次，以岁星每行经一个星次为一年来纪年（这是大致的说法，岁星实际运行周期略短于十二年）。
  • 太岁纪年： 后来人们假设了一个与岁星运行方向相反的「太岁」，用「摄提格」「单阏」等十二个岁名纪年，与地支相配。教材《离骚》「摄提贞于孟陬」的「摄提」即「摄提格」，是寅年的岁名，属于这一系统，不要写成岁星纪年。

其他天文名词（了解）： 五星——金星（太白）、木星（岁星）、水星（辰星）、火星（荧惑）、土星（填星）；银汉、天河、银河同指银河；北斗七星，斗柄的指向可以定季节。

3　教材例子

词 出处 说明
修禊 《兰亭集序》 「暮春之初，会于会稽山阴之兰亭，修禊事也」：教材注修禊是古代民俗，农历三月上旬巳日（三国魏以后固定为三月初三）到水边嬉戏，祓除不祥，所以写的是上巳节
斗牛 《赤壁赋》 「徘徊于斗牛之间」：教材注斗宿和牛宿，都是星宿名，说明月出东山、夜已渐深；「白露横江」的「白露」是水汽，不是节气
七夕、银汉 《鹊桥仙》 「银汉迢迢暗度」：教材注传说每年农历七月七日夜，织女、牛郎借鹊桥越过天河相会，银汉即银河
初七及下九 《孔雀东南飞并序》 「初七及下九」：教材注指七月七日和每月的十九日；初七是旧时妇女晚上祭织女乞巧的日子，下九（十九日）妇女置酒欢聚
近中秋 《念奴娇·过洞庭》 「洞庭青草，近中秋」：说明词写于八月十五前后，「素月分辉」有节日背景
至日 《扬州慢》 「淳熙丙申至日」：教材注至日指冬至，「至日」在此处点明时节
清明 《临安春雨初霁》 「犹及清明可到家」：教材注意思是事毕后返回，还来得及在清明节到家
重阳登高 《登高》 教材题解：「登高，古人重阳节有登高的习俗」
摄提、孟陬 《离骚（节选）》 「摄提贞于孟陬兮，惟庚寅吾以降」：教材注摄提即摄提格，寅年的别称（太岁纪年的岁名）；孟陬是孟春正月，说明屈原生于寅年寅月寅日
北斗 《念奴娇·过洞庭》 「细斟北斗」：用北斗七星组成的勺子斟酒，写星宿的意象
教材外的常见例子
  • 《滕王阁序》：「星分翼轸，地接衡庐」——翼、轸二宿的分野属楚地（南昌一带），是分野的常见例句。
  • 杜甫《赠卫八处士》：「人生不相见，动如参与商」——参商喻永不相见。
  • 《史记·天官书》中的「荧惑」「太白」等五星名，用于星占。

4　易混辨析

  • ✗ 中元节是农历八月十五。→ ✓ 中元节是农历七月十五，追怀先人的传统节日。
  • ✗ 上巳节是三月初一。→ ✓ 上巳原为三月上旬的巳日，三国魏以后固定为三月初三。
  • ✗ 修禊是饮酒赋诗的宴会。→ ✓ 修禊是到水边嬉戏、祓除不祥的民俗；饮酒赋诗是曲水流觞的雅集。
  • ✗ 寒食节就是清明节。→ ✓ 寒食在冬至后一百零五日，清明前一二日；清明本是节气，后与寒食习俗相融。
  • ✗ 「白露横江」中的「白露」是二十四节气之一。→ ✓ 教材注为白茫茫的水汽。
  • ✗ 「至日」一定是夏至。→ ✓ 教材《扬州慢》注为冬至，要看语境。
  • ✗ 二十八宿是指二十八颗星。→ ✓ 二十八宿是二十八个星区（星座群）。
  • ✗ 斗牛是「斗」和「牛」两个动物。→ ✓ 斗牛是斗宿和牛宿两个星宿，玄武七宿中的前两宿。
  • ✗ 岁星就是北斗星。→ ✓ 岁星是木星；北斗是北斗七星。
  • ✗ 岁星纪年是把一周天分为七个星次。→ ✓ 一周天分十二个星次，岁星每行经一个星次为一年。
  • ✗ 星宿、分野是纯粹的迷信，与文化常识无关。→ ✓ 分野是古代星象与地域相配的说法，用于解释诗文中的星象地理用语，只需作知识识记，不必当作科学结论。

5　高考常见设错

设错方式 本专题的典型错项 出处
数字错位 「岁星……一周天分为七个星次」（应为十二个星次） 教材清单《兰亭集序》
日期偷换 把中元（七月十五）说成八月十五、把上巳说成三月初一 常见误判（本站归纳）
名称混淆 把「斗牛」说成「北斗星和牵牛星」 常见误判（本站归纳）
古今混同 把「白露」当作节气，把「至日」固定为夏至 常见误判（本站归纳）
干支与纪年混淆 「壬戌之秋」的「壬戌」说成年号纪年（应为干支纪年） 《导与练》《赤壁赋》课时作业
习俗错配 把重阳「登高」写成中秋习俗，把端午写成纪念介子推 常见误判（本站归纳）

解题抓手： ① 节日先记「月日」，再记「习俗」；② 星宿名词先分「星宿」「星次」「分野」三个层次；③ 遇到「岁在某某」，先看是干支；遇到「摄提」，是太岁纪年的岁名。

6　真题 / 典型题

仿真 · 教辅练习 2025 版一轮复习 · 高考主题衍生仿真卷 主题 11（教辅仿真，非真题）

阅读材料

杜子春者，盖周隋间人，少落拓，不事家产，然以志气闲旷，纵酒闲游。资产荡尽，投于亲故，皆以不事事见弃。 方冬，衣破腹空，徒行长安中，日晚未食，彷徨不知所往。于东市西门，饥寒之色可掬，仰天长吁。有一老人策杖于前，问曰：“君子何叹？”春言其心，且愤其亲戚之疏薄也，感激之气，发于颜色。老人曰：“几缗①则丰用？”子春曰：“三五万则可以活矣。”老人曰：“未也。”更言之：“十万。”曰：“未也。”乃言：“百万。”亦曰：“未也。”曰：“三百万。”乃曰：“可矣。”于是袖出一缗曰：“给子今夕明日午时候子于西市波斯邸慎无后期！”及时子春往，老人果与钱三百万，不告姓名而去。 子春既富，荡心复炽，自以为终身不复羁旅也。乘肥衣轻，会酒徒，征丝管，歌舞于倡楼，不复以治生为意。一二年间，稍稍而尽，衣服车马，易贵从贱，去马而驴，去驴而徒，倏忽如初。既而复无计，自叹于市门。发声而老人到，握其手曰：“君复如此，奇哉！吾将复济子，几缗方可？”子春惭不应。老人因逼之，子春愧谢而已。老人曰：“明日午时，来前期处。”子春忍愧而往，得钱一千万。 未受之初，愤发，以为从此谋身治生。钱既入手，心又翻然，纵适之情，又却如故。不一二年间，贫过旧日。复遇老人于故处，子春不胜其愧，掩面而走。老人牵裾止之，又曰：“嗟乎拙谋也。”因与三千万，曰：“此而不痊，则子贫在膏肓矣。”子春曰：“吾落拓邪游，生涯罄尽，亲戚豪族无相顾者，独此叟三给我，我何以当之？”因谓老人曰：“吾得此，人间之事可以立，孤孀可以衣食，于名教复圆矣。感叟深惠，立事之后，唯叟所使。”老人曰：“吾心也！子治生毕，来岁中元，见我于老君双桧下。” 子春以孤孀多寓淮南，遂转资扬州，买良田百顷，郭中起甲第，要路置邸百余间，悉召孤孀，分居第中。婚嫁甥侄，迁袝旅榇②；恩者煦之，仇者复③之。既毕事，及期而往。 (节选自《太平广记》卷十六) 【注】　①缗：串钱的绳子。一千文为一缗，也称一吊或一贯。②迁袝旅榇：指安葬客死他乡的人。③复：恢复，修好。

1.下列对文中加点的词语及相关内容的解说，不正确的一项是

  1. A.“三五万则可以活矣”与《鸿门宴》中的“项伯杀人，臣活之”的“活”意思相同。
  2. B.“乘肥衣轻”与《齐桓晋文之事》中的“五十者可以衣帛矣”的“衣”意思相同。
  3. C.“因与三千万”与《六国论》中的“与嬴而不助五国也”的“与”意思相同。
  4. D.中元，即“中元节”，是追怀先人的传统节日，时间在每年农历七月十五。
查看答案与解析

答案

C

解析

A项，都是“活命”的意思。句意：我若有三五万钱就可以活命了。/项伯杀了人，我使他活了下来。B项，都是“穿”的意思。句意：乘肥马穿轻裘。/五十岁的人就可以穿丝织的衣服。C项，“意思相同”错误，两个“与”意思不同，原文“因与三千万”中的“与”是“赠与，给予”的意思；《六国论》中“与嬴而不助五国也”的“与”是“亲附、亲近”的意思。句意：然后又给了他三千万。/这是因为它跟秦国交好而不帮助五国啊。D项，正确。

9　速记清单

  • 节日：元日（正月初一）、上元（正月十五）、上巳（三月初三，修禊）、寒食（清明前一二日）、清明、端午（五月初五）、七夕（七月初七）、中元（七月十五，追怀先人）、中秋（八月十五）、重阳（九月初九，登高）、腊八（十二月初八）、除夕。
  • 二十四节气：春雨惊春清谷天，夏满芒夏暑相连，秋处露秋寒霜降，冬雪雪冬小大寒。
  • 四立（立春立夏立秋立冬）、二分（春分秋分）、二至（夏至冬至）；至日常指冬至。
  • 二十八宿分四象：东青龙（角亢氐房心尾箕）、北玄武（斗牛女虚危室壁）、西白虎（奎娄胃昴毕觜参）、南朱雀（井鬼柳星张翼轸）。
  • 斗牛＝斗宿＋牛宿；参商＝参宿＋心宿，此出彼没；银汉＝银河。
  • 分野：星宿（星次）对应地上州国；岁星＝木星，以行经十二星次纪年；太岁纪年的岁名「摄提格」＝寅年，不属岁星纪年。
  • 「白露横江」的白露是水汽，不是节气。
  • 口诀：正月元宵三月巳，五月端午七月七；七月十五中元节，八月中秋九重阳。
