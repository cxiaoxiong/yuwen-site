1　知识梳理

一句话： 礼仪的题目大多考三类：动作（拜、跪、揖）、位置（座次、左右）、忌讳（避讳、讳言）。

冠礼与婚礼（嘉礼）：

  • 冠礼： 男子二十岁行加冠之礼，表示成年，所以「弱冠」指二十岁；教材《子路、曾皙、冉有、公西华侍坐》「冠者五六人」的「冠者」即成年人。女子十五岁行笄礼（插簪），表示成年可嫁。
  • 婚礼： 婚姻成立的手续称六礼——纳采、问名、纳吉、纳征、请期、亲迎；也有「六礼」指冠、婚、丧、祭、乡饮酒和乡射、相见六种礼的说法，要看语境。
  • 合卺（jǐn）： 结婚时新夫妇各持半个瓠瓢饮酒（饮交杯酒），后来「合卺」指成婚。
  • 结发： 教材注为成婚，古代婚礼成婚之夕男女共髻束发，也指原配夫妻。
  • 「归」： 古代称女子出嫁为「归」；「归宁」是出嫁的女子回娘家省亲（教材《项脊轩志》「吾妻来归」「吾妻归宁」）。

拜跪揖趋：

  1. 坐、跪、跽： 古人席地而坐，两膝着地、臀部压在脚后跟上叫坐；臀部抬起、上身挺直叫跪；跪而挺腰耸身叫跽（也叫长跪），是一种警备或郑重的姿势。
  2. 拜： 表示礼节的通称。再拜是拜两次，是较重的礼节（教材《鸿门宴》注）。
    • 稽首： 拜跪于地，头至地并停留较久，是最重的拜礼。
    • 顿首： 拜跪于地，头叩地即抬起。
    • 空首： 拱手至地，头不着地。
  3. 揖： 古代作揖是推手礼，随对象不同有高低：土揖（对无亲属关系者，手略向下）、时揖（对异姓，平推）、天揖（对同姓，稍举高）。
  4. 趋： 小步快走，臣见君时表示恭敬。
  5. 寿： 向人敬酒或送物祝福（《鸿门宴》「奉卮酒为寿」）。
  6. 箕踞： 两腿伸直分开而坐，形似簸箕，表示傲视对方。
  7. 九宾： 外交上最隆重的礼节，由九名傧相依次传呼接引宾客上殿。

座次：

  • 堂上： 古建筑前堂后室，堂上以南向为尊；君主坐北朝南，所以称王称帝叫南面，称臣叫北面。
  • 室内： 室内东西长、南北窄，最尊的座次是东向（西面东坐），其次是南向，再次是北向，最卑是西向。《鸿门宴》：项王、项伯东向坐（最尊）；亚父（范增）南向坐；沛公北向坐；张良西向侍（最卑）。
  • 注意区分「朝向」与「所处位置」： 「东向」「南向」指人面朝的方向，不是座位所在的位置。《鸿门宴》里项王「东向坐」，是面朝东、座位在西侧。判断尊卑先看朝向。

左右尊卑：

  • 官位、居住： 战国秦汉时官位多以右为尊，所以有「位在廉颇之右」，贬官叫左迁，平民居住的地方叫闾左，权贵叫右族、豪右。
  • 车乘： 车上以左为尊，空着左边的位置迎接贵客叫「虚左」。
  • 吉凶： 古礼中常说「吉事尚左，凶事尚右」（先秦文献里的说法，各国、各场合并不完全一致）。
  • 各朝的习惯不同：先秦各国有别，战国秦汉官位多尚右，后世常见尚左（如明清）。所以不能背成一条：「古人一律尚右」。

避讳与忌讳：

  • 避讳： 遇到与君主、尊长的名字相同的字，要设法回避。分国讳（避皇帝和皇室的名讳）、家讳（避自己父祖名讳）、圣人讳（避孔子等圣贤名讳）。
  • 避讳的方法： ① 改字：如汉武帝名刘彻，「彻侯」改称「通侯」（教材《苏武传》注）；② 空字：空而不写，或写「某」「□」；③ 缺笔：少写一两笔；④ 改音：读书遇到讳字，改变读音。
  • 讳言： 古人不直说不吉利、不雅的词：「死」有等级，见「祭祀与丧葬」；如厕常委婉地说「更衣」「出恭」「解手」等。

4　易混辨析

  • ✗ 坐、跪、跽是同一个姿势。→ ✓ 坐是臀部压在脚后跟上；跪是臀部抬起；跽（长跪）是跪而挺腰耸身。
  • ✗ 稽首和顿首都是「头叩地即起」。→ ✓ 稽首是头至地并停留较久，最重；顿首是头叩地即起。
  • ✗ 再拜就是拜一次。→ ✓ 再拜是拜两次，是较重的礼节。
  • ✗ 古代的「揖」就是现在的握手。→ ✓ 揖是推手礼，分土揖、时揖、天揖；执手才类似握手。
  • ✗ 室内座次以南向为尊，堂上以东向为尊。→ ✓ 堂上以南向为尊；室内以东向为尊（《鸿门宴》）。
  • ✗ 「南面」是称臣，「北面」是称王。→ ✓ 南面称王称帝，北面称臣。
  • ✗ 古人不论什么场合，都是以右为尊。→ ✓ 官位、居住多尚右，车乘、吉礼常尚左，要看语境。
  • ✗ 「左迁」是升官。→ ✓ 左迁是降职、贬官。
  • ✗ 女子出嫁叫「归宁」。→ ✓ 出嫁叫「归」，「归宁」是出嫁的女子回娘家省亲。
  • ✗ 避讳只是不说皇帝的名字。→ ✓ 避讳有国讳、家讳、圣人讳，方法有改字、空字、缺笔、改音。
  • ✗ 「彻侯」「通侯」是两种不同的爵位。→ ✓ 同一爵位，因避汉武帝刘彻讳改称通侯。
  • ✗ 三驱是田猎时设网一面，留三面不设。→ ✓ 三驱是设网三面，留一面不设，表示田猎有度、有好生之德（教材《谏太宗十思疏》「三驱以为度」）。

5　高考常见设错

设错方式 本专题的典型错项 出处
数字或方位颠倒 「三驱，田猎时设网一面，留三面不设」（应为设网三面，留一面不设） 教材清单《谏太宗十思疏》
词义偷换 「吾妻归宁」的「归」也解为「出嫁」（应为「返回」） 教材清单《项脊轩志》
对象错位 「舞，古代求雨的一种祭祀仪式」（应为「雩」） 一轮讲义即时训练（宗法礼俗）
语境错位 把「跽」「箕踞」的姿势含义互换 常见误判（本站归纳）
尊卑颠倒 「东向」最卑，「西向」最尊 常见误判（本站归纳）
概念混同 把「避讳」只理解为改用皇帝名字的同音字 常见误判（本站归纳）

解题抓手： ① 动作类：先分「方式」（稽首、顿首、空首）与「次数」（再拜是拜两次），两者不在同一个维度；② 方位类：先分「堂上」还是「室内」；③ 避讳类：找到「谁的名字」「改成什么字」。

真题 2021 年全国乙卷 · 文言文阅读第 11 题

1.下列对文中加点词语的相关内容的解说，不正确的一项是

  1. A.犯颜，指敢于冒犯君王或尊长的威严，常常用于表示直言敢谏的执着态度。
  2. B.抵极刑，抵刑即处刑，抵极刑指犯人受到死刑外加上尸体示众的极端刑罚。
  3. C.减膳，古代帝王遇到天灾等让自己感到内疚的情况时，常食素或减少肴馔。
  4. D.大理丞，大理丞是大理寺的重要官员，大理寺是我国古代掌管刑狱的官署。

答案

B

解析

B项，抵极刑，“极刑”即“死刑”，“抵”意为“达到”，意即达到判处死刑的地步，并不只包括“尸体示众之意”。尸体示众，叫“弃市”。

9　速记清单

  • 五礼：吉（祭）、凶（丧）、军、宾、嘉（冠婚）。
  • 男二十冠（弱冠）；女十五笄；「冠者」＝成年人。
  • 六礼：纳采、问名、纳吉、纳征、请期、亲迎；合卺＝成婚；结发＝成婚；出嫁为「归」，归宁＝回娘家省亲。
  • 坐（臀压脚后跟）、跪（臀离脚跟）、跽（跪而挺腰）、箕踞（伸腿傲视）。
  • 拜礼：稽首（头至地停留，最重）、顿首（头叩地即起）、空首（头不着地）；再拜＝拜两次。
  • 堂上南向尊；室内东向尊，其次南、北，西最卑；南面称王，北面称臣。
  • 官位尚右（左迁＝降职）；车上尊位在左（虚左）；吉事尚左，凶事尚右。
  • 避讳：国讳、家讳、圣人讳；改字、空字、缺笔、改音；彻侯→通侯。
  • 讳言：更衣、出恭、解手（大小便）；崩薨卒（死）。
  • 口诀：稽首最重顿首轻，跪坐跽踞各不同；堂上南向室东向，左右尊卑看场合。

教师备注 · 待裁定点（3）

L01　左右尊卑：旧资料 A 写「古人尚右」（官位以右为尊，贬官称左迁）；但古人也有「吉事尚左，凶事尚右」「车上以左为尊」的说法，不同时代、场合不同。本页把「官位、居住」和「车乘、吉凶礼」分开写，不写成一条绝对规则。

L02　座次：旧资料 A 写「堂上以南向为尊；室内以东向为尊」，与《鸿门宴》课文座次一致，本页只按「朝向」写。题库教材清单题（e-lz-2）另有「东西坐席一般以东为主，以西为客」的说法，题目答案为 √；这句话若按座位所在的一侧理解，与《鸿门宴》中主人项王面朝东、座位在西侧表面上不一致，本页不并列写入正文，也不用「东家」「东道主」作证（「东道主」的解释见「地理称谓与古今地名」）。该说法如何表述，请教师裁定。

L03　避讳例：旧资料 A 的「改字法、空字法、缺笔法、改音法」是常见分类；教材《苏武传》注明「彻侯」因避汉武帝刘彻讳改「通侯」，本页以此为主要教材例证。本页只写题库教材清单题有依据的「民」改「人」（唐人避太宗名讳）；教材《种树郭橐驼传》只注「人，民」，没有说明避讳，页内已标为题库说法。「治」改「理」（避高宗名讳）在现有资料中没有依据，本页不写。
