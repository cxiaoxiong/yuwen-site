1　知识梳理

一条时间线记住一个人的称呼： 出生取名 → 成年（男子二十行冠礼，女子十五行笄礼）取字 → 自己取号、斋名 → 死后由朝廷评定谥号（见「谥号·庙号·年号」）。年龄称谓就挂在这条线上：垂髫、总角、束发、弱冠、及笄……

读到一个称呼，先问三件事：

  1. 谁对谁说？ 自称用名，称别人用字或号；作者叙述时直称名是客观介绍。
  2. 是活着时的，还是死后的？ 名、字、号是生前的；谥号是死后的。
  3. 有没有敬意？ 称名一般不表示尊敬；称字、号、谥号、斋名、官职、籍贯都有礼貌或尊敬的意思。

直称名只在这几种场合合适： 自称（表谦）；为人作传、客观介绍；尊者对卑者、长辈对晚辈；对所憎恶、轻视的人。

名与字常有联系： 义同或义近（屈原名平字原）、义反（韩愈字退之）、意义相关（白居易字乐天）、以排行入字（伯、仲、叔、季）。

文集常以称谓命名： 懂了作者的号、籍贯、官职、书室名，就能读懂教材每篇「选自《…》」里的集名。

4　易混辨析

  • ✗ 称对方的名，是对对方的尊敬。→ ✓ 称名一般不表示尊敬。自称、作传、尊者对卑者、对憎恶轻视的人才直称名。
  • ✗ 字用于上对下、长对少的称呼。→ ✓ 字用于平辈相称，下对上、卑对尊也称字；长辈对晚辈多直称名。
  • ✗ 女子有名无字。→ ✓ 女子十五岁行笄礼（许嫁）时取字，如谢道韫字令姜。
  • ✗ 「忠毅」「文正」是号。→ ✓ 是谥号：死后由朝廷评定；号是自己取的。
  • ✗ 「庖丁」的「丁」是姓。→ ✓ 庖是职业，丁是名字。
  • ✗ 「临川」是王安石的字。→ ✓ 临川是王安石的籍贯，他字介甫，号半山。
  • ✗ 《杜工部集》的「工部」是杜甫的号。→ ✓ 是官职（杜甫官至工部员外郎）。
  • ✗ 《聊斋志异》的「聊斋」是作者的号。→ ✓ 聊斋是蒲松龄的书室名。
  • ✗ 束发、结发都指男子十五岁。→ ✓ 束发指男孩成童（约十五岁）；「结发」在《孔雀东南飞》里指成婚，不是年龄。
  • ✗ 及笄指男子二十岁。→ ✓ 及笄是女子十五岁；男子二十岁是弱冠。
  • ✗ 豆蔻年华指女子十五岁。→ ✓ 豆蔻指十三四岁；十五岁是及笄。
  • ✗ 花甲和耳顺是两个不同的年龄。→ ✓ 都指六十岁。
  • ✗ 垂髫指老人。→ ✓ 垂髫指儿童（「黄发垂髫」里黄发才是老人）。
  • ✗ 苏洵号东坡居士，苏轼号老泉。→ ✓ 苏洵号老泉，苏轼号东坡居士，苏辙号颍滨遗老。

展开全部答案（10 题）
  1. 1. × 错误　“称对方的名、字、号或君、足下、阁下等以示尊敬”错误，古代称对方的名不表示尊敬。自称、作传、长辈对晚辈、对蔑视的人等可以称名。
  2. 2. D　D项，“女子有名无字”错误，古人“女子十五笄而字”。古代女子在十五岁行笄礼(许嫁)时取字，像谢道韫(字令姜)、鱼玄机(字蕙兰)等都有字。
  3. 3. × 错误　“字用于上对下、长对少的称呼”错。字用于平辈之间相称，在下对上、卑对尊写信或呼唤时，也可以称字。

  6. 6. × 错误　“临川”为王安石的籍贯，王安石的字为“介甫”。
  7. 7. × 错误　苏洵，号老泉；苏辙，号颍滨遗老。

9　速记清单

  • 名幼取，字冠笄（男二十、女十五），号自取，谥死后。
  • 称名：自称、作传、尊对卑、憎恶——一般不表敬。
  • 称字、号、斋名、官职、籍贯：都表尊重（本站不比较谁更敬）。
  • 名与字：义同（屈平字原）、义反（韩愈字退之）、义连（白居易字乐天）。
  • 年龄口诀：襁褓孩提垂髫小，总角豆蔻及笄娇；弱冠而立不惑壮，知命花甲古稀老，耄耋期颐长寿考。
  • 男十五束发、二十弱冠；女十三四豆蔻、十五及笄。
  • 集名看来历：临川、昌黎、河东是地名；聊斋是书室；工部是官职；东坡是号。

教师备注 · 待裁定点（3）

C07　号与字孰更敬：B、F 有「称号（乃至官职、籍贯）比称字更敬」的说法；D 称「号一般用于自称，对人称号亦为敬称」；A 只并列不比较。教材注释与真题、教辅答案均无此比较。本页按「字、号、谥号、斋名都是敬称、不分高低」写；教师可复核后调整。

C05　耄、耋：A「耄耋，八九十岁」；C「耄耋 80—90 岁」；D「耄耋八九十岁」，并引《礼记》「八十、九十曰耄」与毛传「八十曰耋」；F 则写「耋，七十至八十岁；耄，八十至九十岁」。教材无该词，真题、教辅题库也未见单字考法。本页只写合称「八九十岁，泛指高寿」，并注明单字说法不一、不作单字考点；教师可复核后调整。

C04　冠礼年龄：A、B、C、D 均写二十岁，F 写「二十岁和十九岁两种说法」。本页正文写二十岁，注明另有十九岁的说法。
