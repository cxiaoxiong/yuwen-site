1　知识梳理

三个名号，三个时间： 年号在皇帝在位时用来纪年；谥号、庙号都是死后才有的。

  • 谥号是评价：根据一生事迹评定，有褒有贬。帝王、诸侯、大臣、名士都可以有谥号（如范仲淹谥文正）。
  • 庙号是祭祀用的名号：皇帝死后在太庙立室奉祀时所起，开国之君多称「祖」，后继者多称「宗」。只有帝王有庙号。
  • 年号是纪年的名号：始于汉武帝（第一个年号「建元」）。新君即位一般要改元，同一皇帝在位时也可以再改元；明清一般一帝一个年号。

最常见的设错： 把年号说成庙号（「元丰是宋神宗的庙号」）、把平谥说成美谥（「楚怀王是美谥」）、说谥号都是褒扬。

称呼帝王的习惯（据 F，仅供参考）： 汉代多称谥号（如汉武帝）；唐宋多称庙号（如唐太宗、宋太祖）；明清多称年号（如乾隆皇帝）。

4　易混辨析

  • ✗ 元丰是宋神宗的庙号，「元丰七年」是庙号纪年。→ ✓ 元丰是年号，神宗是庙号，「元丰七年」是年号纪年。「元和」与「宪宗」、「乾隆」与「高宗」也这样对应。
  • ✗ 谥号是生前得到的。→ ✓ 谥号是死后评定的；年号是在位时用的；尊号、徽号多在生前加。
  • ✗ 谥号都是褒扬的称号。→ ✓ 有美谥、平谥、恶谥三类，如「怀」是平谥，「厉」「炀」是恶谥。
  • ✗ 秦昭王和楚怀王都是美谥。→ ✓ 「昭」是美谥，「怀」是平谥。
  • ✗ 「忠毅」「文正」是号。→ ✓ 是谥号。号是自己取的。
  • ✗ 一个皇帝只有一个年号，新君即位必须改年号。→ ✓ 明代以前一帝可以多次改元（汉武帝用过十一个年号）；明清一般一帝一个年号。
  • ✗ 年号始于秦始皇。→ ✓ 年号始于汉武帝（建元）。
  • ✗ 庙号就是谥号。→ ✓ 庙号是太庙奉祀用的名号（祖、宗）；谥号是评价性的称号。

  9. 9. C　A项,年号开始于汉武帝时期。B项,可用于纪日。D项,“朋友之间互相唱和的赠言”错误,此为书序。

9　速记清单

  • 年号在位用，谥号、庙号死后加。
  • 庙号只帝王有：开国称祖，后继称宗。
  • 谥号有褒贬：美（文武昭穆）、平（怀哀愍）、恶（灵厉炀幽）。
  • 年号始于汉武帝「建元」；明以前可多次改元，明清一帝一号。
  • 「元丰七年」「元和十年」「乾隆三十九年」都是年号纪年。
  • 称帝习惯（据 F）：汉称谥、唐宋称庙号、明清称年号。
