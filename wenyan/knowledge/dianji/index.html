1　知识梳理

先看方法： 遇到「某书是什么类、属于哪个体例、代表哪个学派」，先按 经、史、子、集 分类，再看 史书体例，最后看 学派。

一、四部分类（经史子集）：

部 收入 教材里的例子
经 儒家经典及其解释；「六经」「五经」「四书」 《诗经》《周易》《礼记》《论语》《孟子》《左传》
史 史书、地理、政书 《史记》《汉书》《新五代史》《晋书》《水经注》
子 诸子百家的著作 《老子》《庄子》《墨子》《荀子》《韩非子》
集 个人诗文集（别集）、诗文总集 《陶渊明集》《苏轼文集》《文选》《楚辞》

二、经：

  • 六经（六艺）： 《诗》《书》《礼》《乐》《易》《春秋》六部儒家经典；《乐》已亡佚，所以常说五经。注意：「六艺」还有另一义（礼、乐、射、御、书、数六种技能）；教材《师说》「六艺经传皆通习之」的「六艺」指前者。
  • 四书： 南宋朱熹把《礼记》中的《大学》《中庸》抽出来，与《论语》《孟子》合编，称为「四书」；不含《荀子》。
  • 五经： 《诗》《书》《礼》《易》《春秋》。
  • 传： 古代解释经书的著作（如《左传》是解释《春秋》的），不是人物传记；注是解释字句，疏是对注的进一步解释。
  • 常见经书： 《诗经》（《诗三百》）是我国第一部诗歌总集，分风、雅、颂；《尚书》是上古典章文献的汇编；《周易》讲卦爻；《礼记》是秦汉以前各种礼仪论著的选集，相传为西汉戴圣编撰；《春秋》是鲁国编年体史书，记载鲁隐公元年到鲁哀公十四年的史实；《左传》《公羊传》《穀梁传》合称「春秋三传」。

三、史与史书体例：

体例 特点 代表
编年体 按年月顺序记事 《春秋》《左传》《资治通鉴》
纪传体 以人物传记为中心，分本纪、世家、列传、表、书 《史记》《汉书》
国别体 按国家分记 《国语》《战国策》
  • 《史记》： 西汉司马迁著，我国第一部纪传体通史；司马迁被称「史迁」「太史公」。《汉书》：东汉班固著，我国第一部纪传体断代史，记载西汉一代；班固与司马迁并称「班马」。
  • 二十四史： 历代纪传体正史的总称，《新五代史》《晋书》《汉书》《史记》都在其中。
  • 《水经注》： 北魏郦道元作，在《水经》基础上补充发展而成，《水经》是我国第一部记述水系的专著。
  • 《楚辞》： 西汉刘向整理，收录屈原、宋玉的作品及汉代人的仿作，是我国文学史上第一部浪漫主义诗歌总集。

四、子——诸子百家（先秦到战国）：

学派 代表人物 主张 代表作
儒家 孔子、孟子、荀子 仁、义、礼、智、信，忠恕、孝悌；孟子主张仁政、民贵君轻、性善 《论语》《孟子》《荀子》
道家 老子、庄子 无为而治、清静自然、天人合一 《老子》（《道德经》）、《庄子》（《南华经》）
墨家 墨子 兼爱、非攻，兼相爱、交相利 《墨子》
法家 韩非（集大成者） 依法治国，以法为教 《韩非子》
兵家 孙武、孙膑 研究行军用兵之道 《孙子兵法》
  • 儒家： 《论语》记录孔子及其弟子的言行，集中体现孔子的政治主张、伦理思想、道德观念和教育理念；孟子被称为「亚圣」，政治上主张施行仁政，保民而王。
  • 道家： 《老子》属于子书，不是经书；魏晋玄学「三玄」是《老子》《庄子》《周易》。《庄子》是庄子及其后学所著，庄子是战国中期思想家。
  • 墨家： 墨子核心思想是「兼爱」，爱无等差；《墨子》原有七十一篇，现存五十三篇，包括墨子及弟子的言行和后期墨家的哲学、逻辑、科学论著。
  • 诸子中影响较大的是儒、法、道、墨四家。 「显学」指儒、墨两家（韩非语）。
  • 诸子散文： 春秋战国各学派的著作，是先秦散文，不是两汉的作品。

五、集：

  • 别集： 个人的诗文集，多以作者姓名、字号、官职、籍贯等命名（如《陶渊明集》《苏轼文集》《柳宗元集》《震川先生集》）。
  • 总集： 多人作品汇编，如《文选》《玉台新咏》《楚辞》。
  • 唐宋八大家： 韩愈、柳宗元、欧阳修、苏洵、苏轼、苏辙、王安石、曾巩；唐代古文运动由韩愈、柳宗元倡导，反对六朝以来的骈俪文。

教材外的常见例子
  • 《史记·太史公自序》：司马迁称自己的书为《太史公书》，后来通称《史记》；「史迁」是司马迁的别称。
  • 《资治通鉴》：北宋司马光主编的编年体通史，是编年体的代表作。
  • 《战国策》：国别体史书，记录战国时期策士的言行。

4　易混辨析

  • ✗ 《老子》属于经部。→ ✓ 《老子》是道家著作，属子部。
  • ✗ 「四书」是《大学》《荀子》《论语》《孟子》。→ ✓ 四书是《大学》《中庸》《论语》《孟子》，没有《荀子》。
  • ✗ 「五经」包括《乐》。→ ✓ 《乐》已亡佚，五经是《诗》《书》《礼》《易》《春秋》。
  • ✗ 《师说》中的「六艺」是礼乐射御书数。→ ✓ 《师说》中的「六艺」指六部经书；礼乐射御书数是另一义。
  • ✗ 「传」就是人物传记，「六艺经传」的「传」指《史记》《汉书》的传。→ ✓ 「传」在这里指解释经书的著作。
  • ✗ 《左传》是国别体。→ ✓ 《左传》是编年体，按年月顺序记事；国别体是《国语》《战国策》。
  • ✗ 《左传》原名《春秋》。→ ✓ 《左传》原名《左氏春秋》，汉代改称《春秋左氏传》；《春秋》是另一部书。
  • ✗ 《礼记》是秦汉以来的礼仪论著。→ ✓ 秦汉以前；相传为西汉戴圣编撰。
  • ✗ 《史记》是断代史。→ ✓ 《史记》是通史，《汉书》才是我国第一部纪传体断代史。
  • ✗ 「三玄」是《老子》《孟子》《庄子》。→ ✓ 三玄是《老子》《庄子》《周易》。
  • ✗ 《庄子》是春秋中期庄子一人所著。→ ✓ 庄子是战国中期思想家；《庄子》是庄子及其后学所著。
  • ✗ 「圣人」在任何诸子文章里都指孔子。→ ✓ 「圣人」有多种含义，如《墨子》中指德高望重、有大智的人。
  • ✗ 诸子散文是两汉散文。→ ✓ 诸子散文是先秦各学派的著作。

5　高考常见设错

设错方式 本专题的典型错项 出处
分类错位 「《老子》……在经、史、子、集中属于『经』」（应为子） 教材清单《〈老子〉四章》
名称偷换 「三玄」写成《老子》《孟子》《庄子》（应为《老子》《庄子》《周易》） 教材清单《〈老子〉四章》
体例错位 「《左传》……是我国第一部叙事详备的国别体著作」（应为编年体） 教材清单《烛之武退秦师》
时间偷换 「《礼记》是秦汉以来各种礼仪论著的选集」（应为秦汉以前） 教材清单《大学之道》
时代与作者 「庄子是春秋中期思想家……《庄子》为庄子一人所著」 教材清单《五石之瓠》
书名混同 「四书」写成《大学》《荀子》《论语》《孟子》（应有《中庸》） 《导与练》选必上册课时作业
概念张冠李戴 「六艺经传」的「传」当作人物传记；「史迁」作者写成《汉书》 《导与练》必修上册、必修下册课时作业
义项错配 「《师说》中的『六艺』指后者」（应指六经） 教材清单《师说》

解题抓手： ① 「书、部类」先想：老子庄子墨子荀子韩非子属子；② 「史书体例」：编年（《春秋》《左传》）、纪传（《史记》《汉书》）、国别（《国语》《战国策》）；③ 「四书」记「大中论孟」，「三玄」记「老庄易」。

材料一： 赵简子围卫之郛郭，犀盾、犀橹，立于矢石之所不及，鼓之而士不起。简子投枹曰：“乌乎！吾之士数弊也。”行人烛过免胄而对曰：“臣闻之：亦有君之不能士耳，士无弊者。昔者吾先君献公①并国十七，服国三十八，战十有二胜，是民之用也。献公没，惠公即位，淫衍暴乱，身好玉女，秦人恣侵，去绛十七里，亦是人之用也。惠公没，文公授之，围卫，取邺，城濮之战，五败荆人，取尊名于天下，亦此人之用也。亦有君不能士耳，士无弊也。”简子乃去盾橹立矢石之所及鼓之而士乘之战大胜。简子曰：“与吾得革车千乘，不如闻烛过之一言也。” 或曰：行人未有以说也，乃道惠公以此人是败，文公以此人是霸，未见所以用人也。简子未可以速去盾、橹也。严亲在围，轻犯矢石，孝子之所爱亲也。孝子爱亲，百数之一也。今以为身处危而人尚可战，是以百族之子于上皆若孝子之爱亲也，是行人之诬②也。好利恶害，夫人之所有也。赏厚而信，人轻敌矣；刑重而必，失人不比矣③。长行徇上④，数百不一人；喜利畏罪，人莫不然。将众者不出乎莫不然之数，而道乎百无一人之行，行人未知众之道也。 (节选自《韩非子·难二》，有删改) 材料二： 孔子适卫，卫将军文子问曰：“吾闻鲁公父氏不能听狱，信乎？”孔子答曰：“不知其不能也。夫公父氏之听狱，有罪者惧，无罪者耻。”文子曰：“有罪者惧，是听之察，刑之当也。无罪者耻，何乎？”孔子曰：“齐之以礼，则民耻矣；刑以止刑，则民惧矣。”文子曰：“今齐之以刑，刑犹弗胜，何礼之齐？”孔子曰：“以礼齐民，譬之于御则辔也，以刑齐民，譬之于御则鞭也。执辔于此而动于彼，御之良也。无辔而用策，则马失道矣。”文子曰：“以御言之，左手执辔，右手运策，不亦速乎？若徒辔无策，马何惧哉？”孔子曰：“吾闻古之善御者，执辔如组，两骖如舞，非策之助也。是以先王盛于礼而薄于刑，故民从命。今也废礼而尚刑，故民弥暴。” (节选自《孔丛子·刑论》) 【注】　①献公：即晋献公。②诬：谎言。③失人不比矣：人们都不敢败逃了。④长行徇上：为了君主而牺牲自己的高尚行为。

1.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  1. A.既，指动作已经完成，与《过秦论》“始皇既没”中的“既”词义相同。
  2. B.涉，徒步渡水，与《归去来兮辞并序》“园日涉以成趣”的“涉”词义相同。
  3. C.重伤，指再次伤害已经受伤的人，与现在所说的“造成重伤”并不一样。
  4. D.《春秋》，是中国春秋时期的编年体史书，记录了鲁隐公元年到鲁哀公十四年鲁国的重要史实。

答案

B

解析

A项，正确。句意：宋国人已摆好阵势。/始皇去世之后。B项，错误。徒步渡水；游玩、游览。句意：请求(让军人)在楚国人渡河过半还没有排好队列时向他们攻击。/每天在园中游玩，成为乐趣。C项，正确。“造成重伤”的“重伤”指严重伤害。句意：不重复伤害伤兵。D项，正确。故选B。

9　速记清单

  • 经史子集：经（儒家经典）、史（史书）、子（诸子）、集（诗文集）。
  • 四书：《大学》《中庸》《论语》《孟子》（朱熹）；五经：《诗》《书》《礼》《易》《春秋》；六经＝五经＋《乐》。
  • 六艺：六经；或礼、乐、射、御、书、数；《师说》的六艺＝六经；传＝解释经书的著作。
  • 《礼记》秦汉以前，相传戴圣编；《大学》《中庸》出自《礼记》。
  • 《春秋》编年，三传：《左传》《公羊传》《穀梁传》；《左传》＝编年体；国别体＝《国语》《战国策》。
  • 《史记》＝第一部纪传体通史（司马迁）；《汉书》＝第一部纪传体断代史（班固）；「班马」＝班固＋司马迁。
  • 诸子：儒（孔孟荀）、道（老庄）、墨（墨子，兼爱非攻）、法（韩非）、兵（孙武、孙膑）。
  • 《老子》属子；三玄＝《老子》《庄子》《周易》；《庄子》＝战国中期，庄子及其后学，又称《南华经》。
  • 《楚辞》：刘向辑，屈原、宋玉作品；《诗经》：第一部诗歌总集。
  • 唐宋八大家：韩、柳、欧阳修、三苏、王安石、曾巩。
  • 口诀：四书大中论孟，五经诗书礼易春；三玄老庄加周易，纪传《史》《汉》编年《左》。

教师备注 · 待裁定点（5）

DJ01　《左传》的归类：按传统四部分类，《春秋》及三传属经部；但《左传》同时是编年体叙事史书。题库教材清单题（《左传》）答案：《左传》是编年体，不是国别体。本页两点分别写：类别按经部，体例按编年体，不写成矛盾。

DJ02　六艺：教材《师说》「六艺经传皆通习之」的六艺指《诗》《书》《礼》《乐》《易》《春秋》六经；另一义是礼、乐、射、御、书、数六种技能（见「选官、科举与学校」）。本页只在经部这里写前者。

DJ03　《礼记》的成书：题库教材清单题答案「《礼记》是秦汉以前（而非「以来」）各种礼仪论著的选集，相传为西汉戴圣编撰」。本页照此写；四书里的《大学》《中庸》原为《礼记》中的两篇。

DJ04　「三玄」：魏晋玄学的三玄是《老子》《庄子》《周易》（教材清单题答案），不是《老子》《孟子》《庄子》。本页照此写。

DJ05　《庄子》的时代与作者：题库答案「庄子是战国中期思想家，《庄子》是庄子及其后学所著，又称《南华经》」。本页照此写，不写「春秋」，也不写成庄子一人所作。
