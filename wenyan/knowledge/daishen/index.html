2027 资料 · 待审校 2027 教考融合精讲 · 练习 07 · 姓名字号与年龄称谓、礼仪、座次与避讳

阅读材料

文段节选自《送东阳马生序》：“余幼时即嗜学。家贫，无从致书以观，每假借于藏书之家，手自笔录，计日以还。……既加冠，益慕圣贤之道。又患无硕师名人与游，尝趋百里外，从乡之先达执经叩问……当余之从师也，负箧曳屣行深山巨谷中。”

1.下列对文中加点词语的相关内容的解说，不正确的一项是

  1. A.“致书”指得到书、买书。“无从致书以观”即没有钱买书。
  2. B.“加冠”指加冠礼。古代男子20岁行冠礼，表示成年，可以正式参与社会活动。
  3. C.“硕师”指学问渊博的老师。“硕”有“大、充实”之意，如“硕果”即大果实。
  4. D.“先达”指地位显赫、有钱有势的人。“从乡之先达执经叩问”即向当地权贵请教。

原文答案

D

解析

A项正确：“致书”中的“致”意为“取得、得到”，教材注释明确。“无从致书以观”即“没有办法得到书来读”，与后文“每假借于藏书之家”相呼应。 B项正确：“加冠”指举行冠礼。古代男子20岁在宗庙中由父亲主持加冠仪式，加冠后表示已经成年，可以娶妻、入仕，参与社会活动。教材《送东阳马生序》注释明确此义。 C项正确：“硕师”之“硕”意为“大”，引申为“学问渊博”。与“硕果”“硕大”等词同义。“硕师”即学识丰富的大师。 D项错误：D项误将“先达”解释为“地位显赫、有钱有势的人”。教材注释明确“先达”指“有德行学问而显达的前辈”，强调的是道德学问，而非权贵身份。“达”在此意为“通晓事理、名声远扬”，而非“显赫有权”。文中宋濂“从乡之先达执经叩问”，是向当地德高望重的学问前辈请教经书疑难，而不是向有钱有势的人求助。这一混淆反映了古今词义的差异，是文化常识题的常见陷阱。

8.下列对文中加点词语的相关内容的解说，不正确的一项是

  1. A.“布衣”指平民百姓。古代平民穿麻布衣服，故以此代指。
  2. B.“先帝”指已故的皇帝。文中的“先帝”即刘备。
  3. C.“卑鄙”指地位低下、见识浅陋，是诸葛亮的自谦之词。
  4. D.“臣”是古代对皇帝的自称，所有官员甚至百姓都自称“臣”。

原文答案

D

解析

A项正确：“布衣”是古代常见的文化常识，教材中多次出现。“布”指麻布、葛布，在古代是平民百姓的衣料，贵族则穿丝织品，故“布衣”借指平民。课文中“臣本布衣”意为“我本来是平民百姓”。 B项正确：“先帝”之“先”表示已故，“帝”指皇帝。刘备此时已去世，故诸葛亮称其为“先帝”。同理，课文后文“先帝不以臣卑鄙”“三顾臣于草庐之中”中的“先帝”皆指刘备。 C项正确：“卑鄙”是古今异义词。古义为“地位低下、见识浅陋”，是自谦之词；今义为“品行恶劣”，是贬义词。本题即考查这一差异。 D项错误：“臣”在古代确实是官吏对皇帝的自称，但并非所有百姓都自称“臣”。平民百姓在皇帝面前通常自称“草民”“小民”或直接称名。D项“所有官员甚至百姓”的表述过于绝对，故错误。

楚汉相争，汉王与郦食其谋桡楚权。食其曰：“今秦失德弃义，侵伐诸侯，灭其社稷，使无立锥之地。陛下诚能复立六国之后，其君臣、百姓必皆戴陛下之德。德义已行，陛下南乡称霸，楚必敛衽而朝。”汉王曰：“善。趣刻印，先生因行佩之矣。”张良从外来谒，汉王具以郦生语告良，良历数其弊，曰：“陛下事去矣！”汉王令趣销印。荀悦论曰：夫立策决胜之术，其要有三：一曰形，二曰势，三曰情。形者，言其大体得失之数也；势者，言其临时之宜、进退之机也；情者，言其心志可否之实也。故策同、事等而功殊者，三术不同也。初，张耳、陈馀说陈涉以复六国，自为树党，郦生亦说汉王。所以说者同而得失异者，陈涉之起，天下皆欲亡秦，而楚。汉之分未有所定，今天下未必欲亡项也。故立六国，于陈涉所谓多己之党而益秦之敌也。且陈涉未能专天下之地也，所谓取非其有以与于人，行虚惠而获实福也。立六国，于汉王所谓割己之有而以资敌，设虚名而受实祸也，此同事而异形者也。及宋义待秦、赵之毙，与昔卞庄刺虎[注]同说者也。施之战国之时，邻国相攻，无临时之急则可也。今楚、赵所起，其与秦势不并立，安危之机，呼吸成变，进则定功，退则受祸，此同事而异势者也。伐赵之役，韩信军于泜水之上，而赵不能败。彭城之难，汉王战于睢水之上，士卒皆赴入睢水，而楚兵大胜。何则？赵兵出国迎战，怀内顾之心，无出死之计。韩信军孤在水上，士卒必死，无有二心，此信之所以胜也。汉王深入敌国，士卒逸豫，战心不固；楚以强大之威而丧其国都，士卒皆有赴亡之急，以决一旦之命，此汉之所以败也。此同事而异情者也。 （节选自《通鉴纪事本末·高帝灭楚》） 【注】卞庄刺虎：卞庄为春秋时鲁国勇士，等两只老虎为争食两败俱伤后才出手刺杀，得到了两老虎。

材料一： 治国之道，所养有二：一曰养德，二曰养力。养德者，养名高之人，以示能敬贤；养力者，养气力之士，以明能用兵。此所谓文武张设，德力具足者也。事或可以德怀，或可以力摧。外以德自立，内以力自备。慕德者不战而服，犯德者畏兵而却。徐偃王①修行仁义，陆地朝者三十二国，强楚闻之，举兵而灭之。此有德守，无力备者也。夫德不可独任以治国，力不可直任以御敌也。韩子②之术不养德，偃王之操不任力，二者偏驳，各有不足。偃王有无力之祸，知韩子必有无德之患。 （选自王充《论衡》，有删改） 材料二： 《司马法》曰：“国虽大，好战必亡；天下虽安，忘战必危。”《易》曰：“君子以除③戎器，戒不虞。”夫兵不可玩，玩则无威；兵不可废，废则召寇。昔吴王夫差好战而亡，徐偃王无武亦灭。故明王之制国也，上不玩兵，下不废武。《易》曰：“存不忘亡，是以身安而国家可保也。”秦昭王中朝而叹曰：“夫楚剑利，倡优拙。夫剑利，则士多悍；倡优拙，则思虑远也。吾恐楚之谋秦也。”此谓当吉念凶，而存不忘亡也，当卒以成霸焉。王孙厉谓楚文王曰：“徐偃王好行仁义之道，汉东诸侯三十二国尽服矣。王若不伐，楚必事徐。”王曰：“若信有道，不可伐也。”对曰：“大之伐小，强之伐弱，犹大鱼之吞小鱼也，若虎之食豚也。恶有其不得理？”文王遂兴师伐徐，残之。徐偃王将死，曰：“吾赖于文德，而不明武备，好行仁义之道，而不知诈人之心，以至于此。”夫古之王者，其有备乎！《春秋》记国家存亡，以察来世。虽有广土众民，坚甲利兵，威猛之将，士卒不亲附，不可以战胜取功。晋侯获于韩④。楚子玉得臣⑤败于城濮，蔡不待敌而众溃。故语曰：“文王不能使不附之民，先轸⑥不能战不教之卒。故强弱成败之要，在乎附士卒，教习之而已。” （选自《说苑·卷十五·指武》，有删改） [注]①徐偃王：周朝时徐国国君。②韩子：韩非子。③除：修治。④公元前645年，秦穆公攻晋，战于韩原，大败晋军，擒晋惠公。⑤子玉得臣：姓成，名得臣，字子玉，楚成王时为令尹。⑥先轸：春秋时晋国卿大夫。
