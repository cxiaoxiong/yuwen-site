1　知识梳理

为什么要专门学军事： 文言阅读的传记里，战争、出使、守边非常常见；高考「文化常识」题里的军事词语（乘、部曲、辎重、衔枚、刁斗、传檄、车驾、将校）出现频率很高，但课本讲得少，需要单独整理。

一、兵车与兵力：乘、千乘、万乘、百乘

  • 乘（shèng）： 古代一车四马为一乘，兵车的单位。
  • 千乘之国： 教材《子路、曾皙、冉有、公西华侍坐》注为「有一千辆兵车的诸侯国，春秋后期是中等国家」。
  • 万乘： 兵车万辆，表示军事力量强大，也称天子或大国。
  • 百乘： 一百辆兵车；「百乘」「千乘」常用来代指兵力。
  • 车驾： 帝王所乘车马，常代指帝王（如「车驾亲征」），与「丝竹」代指音乐的用法相同。

二、编制与军队：

  • 行伍： 古代兵制，五人为伍、二十五人为行，因此用「行伍」代指军队（《过秦论》「蹑足行伍之间」）。
  • 部曲： 两义。原是军队编制单位（大将军营分部，部下有曲）；后来指豪门大族和将领的私人军队。要看语境，不能一概说成「编制单位」。
  • 师、旅、军： 周制五人为伍，二十五人为两，百人为卒，五百人为旅，二千五百人为师，一万二千五百人为军；「师」「旅」也泛指军队。
  • 戍： 守边；谪戍是因有罪被征调去守边（《过秦论》「谪戍之众」）；戍卒指守边的士兵。
  • 兵制的大致演变（了解）： 秦汉主要是征兵；隋唐前期行府兵制，中期以后募兵；宋代募兵，有禁军、厢军；明代卫所制；清代八旗、绿营。

三、武官：

  • 将军： 统兵的高级武官，也泛称统帅。校尉： 汉代将军属官；也泛指军官、统帅（教材《燕歌行》注「武官名，泛指统帅」）；将校是将军与校尉的合称。
  • 都尉： 秦汉重要的中高级武官；司马： 掌军政的官，也指军事主官的僚属（《鸿门宴》「左司马」注：将军下面的属官，参掌军政）；都督： 军事长官；经略使： 唐宋边防军事长官；节度使： 唐代重镇的军政长官。
  • 元戎： 主将（教材《燕歌行》注）。

四、号令与器物：

  • 金鼓： 军中信号。金指钲、锣，击金则收兵（鸣金收兵）；鼓指战鼓，击鼓则进军。
  • 刁斗： 三足长柄的铜锅，白天煮饭，夜间敲击巡逻报警（教材《燕歌行》注）。注意：金不是刁斗的声音。
  • 衔枚： 行军或夜袭时，让士兵口中横衔一根枚（形如筷子），防止喧哗。
  • 节（旄节）： 使者所持的凭证，竹竿上缀牦牛尾（《苏武传》「持节」）。兵符（虎符）：调兵的凭证。
  • 檄： 古代官府用来征召、晓谕、声讨的文书；传檄即传布檄文；羽书（羽檄）是插鸟羽以示紧急的军事文书。
  • 辎重： 行军时随军运载的军械、粮草、被服等军用物资。馈饷： 粮饷，也指运送军粮。
  • 斥候： 侦察兵（《苏武传》注）。烽火： 边防报警的信号。
  • 甲胄： 铠甲和头盔；胄也指后代（贵胄）。免胄是脱去头盔，表示对天子或尊者敬意。

读军事材料的提醒：

  1. 看到「乘」先念 shèng，再想「一车四马」。
  2. 看到「部曲」「将校」先问「哪个朝代、什么语境」。
  3. 「金」是收兵，「鼓」是进军；「刁斗」是夜间巡逻用具。

3　教材例子

词 出处 说明
千乘之国 《子路、曾皙、冉有、公西华侍坐》 「千乘之国，摄乎大国之间」：教材注为有一千辆兵车的诸侯国，春秋后期是中等国家，「乘」是一车四马
万乘、谪戍 《过秦论》 「致万乘之权」：万乘指兵车万辆，表示军事力量强大；「谪戍之众」：教材注「因有罪而被征调去守边」，说明陈涉的队伍是戍卒
行伍 《过秦论》 「蹑足行伍之间」：行伍指军队，写陈涉从最底层的士卒起家
戍卒 《阿房宫赋》 「戍卒叫，函谷举」：教材注指陈涉、吴广起义，写戍卒起义推翻秦朝
左司马、交戟、披帷 《鸿门宴》 「左司马曹无伤」：教材注为将军下面的属官，参掌军政；「交戟之卫士」：用戟交叉守卫营门的兵士，写军营的戒备
节、斥候、中郎将 《苏武传》 苏武以中郎将「使持节」出使，节是使者的凭证；「斥候百余人」：教材注为侦察兵，写出使随员的组成
刁斗、羽书、校尉、元戎 《燕歌行并序》 「寒声一夜传刁斗」：教材注刁斗是军中兼用于炊煮和巡更敲击的铜制用具；「校尉羽书飞瀚海」：羽书是插鸟羽的紧急军事文书，校尉泛指统帅；「元戎」指主将
金戈铁马、烽火 《永遇乐·京口北固亭怀古》 「金戈铁马」：教材注写刘裕两次率军北伐；「烽火扬州路」：扬州一带抗金的烽火
楼船、铁马 《书愤》 教材注：「楼船夜雪瓜洲渡」指陆游任镇江通判时的事，「铁马秋风大散关」指在陕南汉中大散关前线与金兵交战的经历
三矢、告庙 《五代史伶官传序》 「以三矢赐庄宗」：三支箭是晋王的遗恨托付，「还矢先王」：出征前后祭告祖庙，军事与祭祀相连
教材外的常见例子
  • 《史记·信陵君列传》：「窃符救赵」——兵符（虎符）是调兵的凭证，窃符即取得调兵权。
  • 《晋书·祖逖传》：「逖将其部曲百余家渡江」——部曲是祖逖的私家军队（2021 年新高考Ⅱ卷）。
  • 《后汉书·吴汉传》：「吴公差强人意」——差强人意是「尚能振奋人的意志」，不是「较差、不能令人满意」（2022 年新高考Ⅱ卷）。

4　易混辨析

  • ✗ 「乘」就是骑马。→ ✓ 「乘（shèng）」是量词，一车四马为一乘；「千乘」「万乘」表示兵车数量。
  • ✗ 「百乘」指一百个骑兵。→ ✓ 「百乘」指一百辆兵车，常用来代指兵力。
  • ✗ 「万乘」只指天子。→ ✓ 万乘既可指兵车万辆、军事力量强大，也可以指天子、大国。
  • ✗ 「部曲」在任何时候都是部队的编制单位。→ ✓ 部曲有编制单位和私家军队两义，「逖将其部曲百余家」是私家军队。
  • ✗ 「金」是刁斗发出的声音。→ ✓ 「金」指锣、钲，击金收兵；刁斗是军中用具，白天煮饭、夜间敲击巡逻。
  • ✗ 「衔枚」是嘴里含着食物。→ ✓ 衔枚是口中横衔一根形如筷子的枚，防止喧哗。
  • ✗ 「檄」是私人书信。→ ✓ 檄是官府用来征召、晓谕、声讨的文书。
  • ✗ 「校尉」永远是具体的官名，不是泛称。→ ✓ 汉代校尉是将军的属官，教材《燕歌行》中的「校尉」泛指统帅。
  • ✗ 「胄」只指头盔。→ ✓ 胄一指头盔（甲胄），二指子孙后代（贵胄），要看语境。
  • ✗ 「差强人意」是勉强不能让人满意。→ ✓ 原义为尚能振奋人的意志；后来引申为大体还能让人满意。
  • ✗ 「车驾」是普通的车。→ ✓ 车驾是帝王所乘的车马，常代指帝王。
  • ✗ 「戍」就是打仗。→ ✓ 戍是守边、驻守；谪戍是因罪被征调去守边。

5　高考常见设错

设错方式 本专题的典型错项 出处
义项错配 「部曲，……文中是指部队的编制单位」（应为私家军队） 2021 年新高考Ⅱ卷（真题，本项是错项）
器物混淆 「闻金则止，金指敲击刁斗发出的声音」（应为锣、钲） 2023 年新课标Ⅱ卷（真题，本项是错项）
词义误释 「差强人意，文中指表现较差，不能令人满意」（应为尚能振奋人心） 2022 年新高考Ⅱ卷（真题，本项是错项）
古今相混 把「乘」「车驾」「行伍」当今义理解 教辅常见
同题对比 把「千乘」「万乘」的对应国家大小颠倒 教材清单《子路、曾皙……》《过秦论》
官名张冠李戴 「将校，汉代军制，将军属下设校尉，将军与校尉合称将校」（正确项，用来对照） 专项对点练 20（教辅）

真题： 2021 年全国甲卷 D 项「辎重」是正确项，错在 C 项「闰月」；2022 年新高考Ⅰ卷 B 项「百乘」是正确项；2022 年新高考Ⅱ卷 A 项「衔枚」是正确项，D 项「车驾」是正确项；2021 年新高考Ⅱ卷 D 项「传檄」是正确项。

解题抓手： ① 多义词（部曲、校尉、胄）先看语境；② 器物题分清「用途」：金是收兵，鼓是进军，刁斗是炊煮和巡更；③ 军事名词多为「量词」「编制」「文书」「器物」四类，先归类再判断。

6　真题 / 典型题

高考题型：选出「不正确的一项」。「仿真」是教辅仿真卷，不是真题。

真题 2021 年全国甲卷 · 文言文阅读第 11 题

1.下列对文中加点词语的相关内容的解说，不正确的一项是

  1. A.衅鼓，指古代战争时杀人或杀牲取血涂鼓上以举行祭祀仪式。
  2. B.庙社，庙指宗庙，社指社稷，庙社在古代常用来借指国家朝廷。
  3. C.闰月，农历逢闰年加一个月，闰某月指加在某月之前的那个月。
  4. D.辎重，文中指行军时随军运载的军械、粮草、被服等军用物资。
查看答案与解析

答案

C

解析

C项，“闰某月指加在某月之前那个月”错误，闰月加于某月之后叫“闰某月”。

真题 2021 年新高考Ⅱ卷 · 文言文阅读第 11 题

阅读材料

初范阳祖逖少有大志与刘琨俱为司州主簿同寝中夜闻鸡鸣蹴琨觉曰此非恶声也因起舞及渡江，左丞相睿以为军谘祭酒。逖居京口，纠合骁健，言于睿曰：“晋室之乱非上无道而下怨叛也，由宗室争权，自相鱼肉，遂使戎狄乘隙，毒流中土。今遗民既遭残贼，人思自奋，大王诚能命将出师，使如逖者统之以复中原，郡国豪杰必有望风响应者矣。”睿素无北伐之志，以逖为奋威将军、豫州刺史，给千人廪，布三千疋，不给铠仗，使自召募。秋八月，逖将其部曲百余家渡江，中流，击楫而誓曰：“祖逖不能清中原而复济者，有如大江！”遂屯淮阴，起冶铸兵，募得二千余人而后进。逖既入谯城，石勒遣石虎围谯，桓宣救之，虎解去。晋王传檄天下，称：“石虎敢帅犬羊，渡河纵毒，今遣九军，锐卒三万，水陆四道，径造贼场，受祖逖节度。”大兴三年，逖镇雍丘，数遣兵邀击后赵兵，后赵镇戍归逖者甚多，境土渐蹙。秋七月，诏加逖镇西将军。逖在军，与将士同甘苦，约己务施，劝课农桑，抚纳新附，虽疏贱者皆结以恩礼。逖练兵积谷，为取河北之计。后赵王勒患之，乃下幽州为逖修祖、父墓，置守冢二家，因与逖书，求通使及互市。逖不报书，而听其互市，收利十倍。禁诸将不使侵暴后赵之民。边境之间，稍得休息。四年秋七月，以尚书仆射戴渊为征西将军，镇合肥。逖以已翦荆棘收河南地，而渊一旦来统之，意甚怏怏。又闻王敦与刘、刁构隙，将有内难。知大功不遂，感激发病。九月，卒于雍丘。豫州士女若丧父母，谯、梁间皆为立祠。祖逖既卒，后赵屡寇河南，拔襄城、城父，围谯。豫州刺史祖约不能御，退屯寿春。后赵遂取陈留，梁、郑之间复骚然矣。 (节选自《通鉴纪事本末·祖逖北伐》)

  1. A.京口，古城名，在今江苏省镇江市，是古代长江下游军事重镇，为兵家所重。
  2. B.遗民，指改朝换代后仍然忠于前朝的人，也泛指沦陷区的人民，文中指后者。
  3. C.部曲，原指古代豪门大族和将领招募的私人军队，文中是指部队的编制单位。
  4. D.传檄，檄指檄文，是古代官府用以征召、晓谕、声讨的文书，传檄即传布檄文。

B

解析

B项，“文中指表现较差，不能令人满意”错。原文“上常曰：‘吴公差强人意，隐若一敌国矣。’”中“隐若一敌国”强调对国家有举足轻重的作用。所以“差强人意”不是“表现较差，不能令人满意”的意思，而是“还能振奋人们的意志”。

  • 校尉：汉代将军属官，也泛指统帅；将校＝将军＋校尉；左司马＝将军的属官；元戎＝主将。
  • 金（钲、锣）收兵；鼓进军；刁斗＝军中铜锅，夜间敲击巡更。
  • 衔枚：口中横衔枚，防喧哗；节（旄节）＝使者凭证；檄＝征召、晓谕、声讨的文书；羽书＝紧急军事文书。
  • 辎重＝随军物资；馈饷＝粮饷；斥候＝侦察兵；烽火＝报警信号。
  • 胄：头盔 / 后代；差强人意＝尚能振奋人心。
  • 口诀：一车四马叫一乘，五人为伍二十五行；金钲收兵鼓进军，刁斗夜里敲巡更。

教师备注 · 待裁定点（4）

JS01　乘：教材注「一车四马为一乘」；千乘之国「在春秋后期是中等国家」；「万乘」表示军事力量强大，也用来称天子或大国。题库教材清单还有「战国时期诸侯国小者称千乘，大者称万乘」的说法，本页照教材注并提示「随时代变化」。

JS02　部曲：2021 年新高考Ⅱ卷题的解析指出，文中「部曲」是祖逖的私家军队，不是「部队的编制单位」；旧说「部曲」原为汉代军队编制（将军营部下设部、曲），后来才指私兵。本页两义并写，并说明「要看语境，六朝以后多指私兵」。

JS03　校尉：教材《燕歌行并序》注「武官名，泛指统帅」；专项对点练 20「将校」题指汉代军制中将军属下的校尉。本页分开写：具体官名（汉代将军属官）与泛指（统帅）。

JS04　金鼓与刁斗：2023 年新课标Ⅱ卷题解析指出「金」一般指锣或钲，作战时击之为收兵信号，刁斗是行军用具（白天煮饭、夜间敲击巡逻）。教材《燕歌行并序》注刁斗为「三足长柄的锅，古代军中兼用于炊煮和巡更敲击」，与此一致。
