1　知识梳理

选官制度的主线：

  1. 先秦：世卿世禄。 贵族的后代世代做官；春秋战国出现「养士」，秦国以军功授爵。
  2. 汉：察举与征辟。 ① 察举：又称荐举，由地方长官在辖区内考察人才，推荐给朝廷，考核后任官；常科有孝廉（品行方正）、秀才（优秀人才，东汉避光武帝刘秀讳改称「茂才」）。② 征辟：由上向下直接聘用——皇帝征召称「征」，公府、州郡长官聘用称「辟」。
  3. 魏晋南北朝：九品中正制。 朝廷委派中正官按家世、品行把人才分成九品，选官时依品级，后来变成门阀垄断。
  4. 隋唐至清：科举制。 隋唐开始分科取士，因此叫科举，进士科逐渐成为重要科目；唐以进士、明经等科为主，宋代殿试成为定制；明清科举层次分明，与学校制度紧密结合，考试内容以四书五经为主，文体为八股文。

明清科举的路线（记这条线）：

童试（县试 → 府试 → 院试，取得生员〔秀才〕资格，入府、州、县学）→ 乡试（各省省城，秋，取举人，第一名解元）→ 会试（京城，春，礼部主持，取贡士，第一名会元）→ 殿试（皇帝主持，取进士，一甲三人：状元、榜眼、探花）。

  • 一甲三名赐「进士及第」，合称鼎甲（如鼎有三足）；二甲赐「进士出身」；三甲赐「同进士出身」。
  • 连中三元：乡试、会试、殿试都考第一名（解元、会元、状元）。
  • 乡试放榜称桂榜，会试放榜称杏榜，殿试放榜称金榜。

学校制度：

  • 官学： 中央有太学（汉武帝时设立，教授儒家经典）、国子学（西晋）、国子监（隋唐以后的中央官学机构，长官称祭酒，副职称司业；唐宋设国子监作为中央教育管理机构，太学等学校隶属其下，不同时期二者的名称、职能关系有所变化；明清又常以「太学」泛称国子监）；地方有府学、州学、县学；私学有私塾、书院。
  • 庠序： 古人常以庠序、乡学泛称地方学校，泛指教育。
  • 国学： 天子或诸侯所设的学校，教学内容以「六艺」为主（礼、乐、射、御、书、数）。
  • 诸生： 明清时指经考试录取而进入府、州、县各级学校学习的生员，有时也指国子监的监生。
  • 学使（学政、提学）： 主管一省学校事务，主持岁考、科考的官员。

读科举材料的三个提醒：

  • 「孝廉」「秀才」在汉代是察举的科目，在明清「秀才」指府、州、县学生员，「孝廉」常用来称举人。
  • 「贡士」≠「贡生」（明清）： 明清的贡士是会试中式者；贡生是府、州、县学生员中被选送进国子监读书的人。
  • **「监生」**是国子监的学生，也可以通过捐纳取得，不能等同于举人。

3　教材例子

词 出处 说明
孝廉、秀才 《陈情表》 「前太守臣逵察臣孝廉，后刺史臣荣举臣秀才」：教材注孝廉是「推举孝顺父母、品行方正的人」；两级地方长官先后推举李密，反映察举由地方长官推荐
任（以父任） 《苏武传》 「少以父任，兄弟并为郎」：教材注依汉制，二千石以上官员可保举子弟一人做郎官，这是「任子」的例子
童子业、学使、邑庠 《促织》 「操童子业，久不售」：成名还是童生，多年考不中；「又嘱学使俾入邑庠」：学使是主管一省学校的官，邑庠是县学，教材注「即取中秀才」
庠序 《齐桓晋文之事》 「谨庠序之教」：庠序是古代地方学校，说明孟子主张重视学校教育
教材外的常见例子
  • 《送东阳马生序》：「今诸生学于太学，县官日有廪稍之供」——太学指明代国子监，诸生指国子监的学生（该篇不在现行五册教材中，故不列入上表）。
  • 《后汉书·张衡传》：「举孝廉不行，连辟公府不就」——「举孝廉」是察举，「辟公府」是征辟。
  • 《史记》《汉书》中的「以孝廉为郎」「征拜为郎」，多用来交代人物出身与入仕途径。
  • 明清小说、传记中的「中举」「中进士」「点翰林」，按童试—乡试—会试—殿试的顺序读。

4　易混辨析

  • ✗ 征辟和察举都是地方长官推荐人才。→ ✓ 征辟是上级（皇帝、府主）直接征召、聘用；察举是地方长官考察后向朝廷推荐。
  • ✗ 孝廉是「学业优异」的人。→ ✓ 孝廉指孝顺亲长、廉能正直；察举科目，重在品行。
  • ✗ 察举是自上而下选拔人才的制度。→ ✓ 按题库答案的口径，察举是地方长官向朝廷推举（自下而上），征辟是上级直接征聘（自上而下）；这是本站常用的解题说法，不是对察举的无条件定义。
  • ✗ 「秀才」在任何时代都指县学生员。→ ✓ 汉代是察举科目（东汉改称茂才）；明清才指府、州、县学生员。
  • ✗ 乡试中了叫贡士，会试中了叫举人。→ ✓ 乡试中举人，会试中贡士，殿试中进士。
  • ✗ 贡士就是贡生。→ ✓ 贡士是会试中式者；贡生是被选送国子监的生员。
  • ✗ 殿试第一名是解元。→ ✓ 解元是乡试第一名，会元是会试第一名，状元是殿试第一名。
  • ✗ 会试由皇帝主持。→ ✓ 会试由礼部主持；殿试才由皇帝主持。
  • ✗ 童生就是秀才。→ ✓ 童生是尚未考取生员的读书人；院试录取后才是生员（秀才）。
  • ✗ 「太学」和「国子监」在任何朝代都是同一个机构。→ ✓ 汉代有太学；唐宋国子监是中央教育管理机构，太学等学校隶属其下，具体关系各时期有变化；明清常以「太学」泛称国子监。掌管其教育的官员称祭酒。
  • ✗ 「六艺」永远是《诗》《书》《礼》《乐》《易》《春秋》。→ ✓ 六艺有两个义项：礼乐射御书数六种技能，也指六部经书，要看语境。

设错方式 本专题的典型错项 出处
内容偷换 「孝廉……推举孝顺父母、学业优异的人」（应为品行方正） 教材小练《陈情表》

名号错配 把解元、会元、状元与乡试、会试、殿试错位对应 常见误判（本站归纳）
概念混同 把庠序说成某朝专有学校；把「贡士」「贡生」混用 常见误判（本站归纳）

解题抓手： ① 汉代科目看「察举、征辟」；明清科考按「童试—乡试—会试—殿试」排顺序；② 记住每一级的「场所、主持者、中式者称谓、第一名称谓」；③ 遇到「孝廉」「秀才」先问朝代。

6　真题 / 典型题

高考题型：选出「不正确的一项」。「仿真」是教辅仿真卷，不是真题。

仿真 · 教辅练习 2024 年高考仿真卷 8 · 文言文阅读第 11 题（教辅仿真，非真题）

阅读材料

材料一： 古者学士之于六艺，射能弧矢之事矣，又当善其揖让之节。御能车马之事矣，又当善其驱驰之节。书非能肆笔而已，又当辨其体而皆通其意。数非能布策而已，又当知其用而各尽其法。而五礼之威仪，至于三千，六乐之节文可谓微且多矣。噫！何其烦且劳如是！然古之学者必能此，亦可谓难矣。 然习其射御于礼，习其干戈于乐，则少于学，长于朝，其于武备固修矣。其于家有塾，于党有庠，于乡有序，于国有学，于教有师，于视听言动有其容，于衣冠饮食有其度，几杖有铭，盘杆有戒。在舆有和鸾之声，行步有佩玉之音，燕处有《雅》《颂》之乐。而非其故，琴瑟未尝去于前也。盖其出入进退，俯仰左右，接于耳目，达于其心者，所以养之至如此其详且密也。 孔子曰：“兴于《诗》，立于《礼》，成于《乐》。”盖乐者，所以感人之心而使之化，故曰“成于《乐》”。昔舜命夔典乐，教胄子，曰：“直而温，宽而栗，刚而无虐，简而无傲。”则乐者非独去邪，又所以救其性之偏而纳之中也。故和鸾、佩玉、《雅》《颂》琴瑟之音，非其故不去于前，岂虚也哉！ (节选自曾巩《相国寺维摩院听琴序》) 材料二： 予尝有幽忧之疾，退而闲居，不能治也。既而学琴于友人受宫声数引久而乐之不知疾之在其体也。 夫琴之为技小矣，及其至也，大者为宫，细者为羽，操弦骤作，忽然变之，急者凄然以促，缓者舒然以和，如崩崖裂石、高山出泉，而风雨夜至也。如怨夫寡妇之叹息，雌雄雍雍之相鸣也。其忧深思远，则舜与文王、孔子之遗音也；悲愁感愤，则伯奇孤子、屈原忠臣之所叹也。喜怒哀乐，动人必深。其能听之以耳，应之以手，取其和者，道其堙郁，写其忧思，则感人之际，亦有至者焉。 (节选自欧阳修《送杨置》)

1.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  1. A.布策，即布列算筹。策，是我国最早的计算工具，与《归去来兮辞并序》“策扶老以流憩”中的“策”意思不同。
  2. B.五礼，古代的五种礼制，文中指古代汉族礼仪总称，即吉礼、凶礼、军礼、宾礼、嘉礼。
  3. C.庠序，古代的地方学校，后泛指学校，与《齐桓晋文之事》“谨庠序之教”中的“庠序”意思相同。
  4. D.度，在本文指“标准、限度”，与《谏太宗十思疏》“乐盘游则思三驱以为度”中的“度”意思不同。

9　速记清单

  • 汉：察举（地方长官推荐）+ 征辟（皇帝征、府主辟）；科目：孝廉（品行）、秀才（茂才，避刘秀讳）。
  • 魏晋：九品中正制；隋唐：科举（分科取士）。
  • 明清路线：童试（生员/秀才）→ 乡试（秋，举人，解元）→ 会试（春，礼部主持，贡士，会元）→ 殿试（皇帝，进士，状元）。
  • 一甲三名：状元、榜眼、探花（鼎甲）；连中三元＝解元、会元、状元。
  • 榜：桂榜（乡试）、杏榜（会试）、金榜（殿试）。
  • 学校：太学（汉）→ 国子监（隋唐以后，祭酒、司业；唐宋太学等隶属国子监，明清常以太学泛称国子监）；庠序泛称地方学校；诸生指生员或监生。
  • 明清贡士≠贡生；童生≠秀才；解元≠状元。
  • 口诀：孝廉察，秀才举；乡试举人，会试贡士，殿试进士；一鼎三足状榜探。

教师备注 · 待裁定点（3）

K01　征辟与察举：旧资料 A 称征辟制「自上而下」，题库教材清单称察举「自下而上」。两者并不冲突——征辟是上级（皇帝、府主）直接征召、聘用；察举是地方长官在辖区内考察、向上推荐。本页按此分开写。

K02　「庠序」：题库待审校的教材清单题（《齐桓晋文之事》）称「商代叫序，周代叫庠」；不同典籍说法不一。本页只写「庠序泛称地方学校」，不写各朝对应关系；该题继续留在待审校题库。

K03　乡试、会试、殿试的月份：旧资料写乡试八月、会试次年三月、殿试同年四月，明清各朝略有出入，本页表格写「秋」「春」「会试后」，只保留高考需要的大致时间。
