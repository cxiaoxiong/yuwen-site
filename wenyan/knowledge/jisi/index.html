1　知识梳理

五礼中的两礼： 古代把礼分为吉、凶、军、宾、嘉五类。祭祀之事是吉礼，丧葬之事是凶礼。

祭祀：祭谁、怎么祭、用什么祭

  1. 祭谁： 天神（祭天）、地祇（祭社稷、祭地）、人鬼（祭祖先，在宗庙）。
  2. 祭天地——封禅： 帝王祭天地的典礼，一般到泰山举行。封是在泰山顶上筑坛祭天，禅是在泰山脚下的梁父山上辟场祭地；第一个举行大规模封禅仪式的帝王是秦始皇。
  3. 祭土地和谷神——社稷： 社是土神，稷是谷神，古代帝王、诸侯所祭；后来用「社稷」指国家。
  4. 祭祖先——宗庙： 天子、诸侯供奉祖先牌位的处所。按古制，天子七庙、诸侯五庙、大夫三庙、士一庙，庶人不设庙。七庙（太祖庙居中，左三昭、右三穆）后来成为王朝的代称，「宗庙社稷」「庙社」「七庙」都可指国家。太庙是天子的祖庙。
  5. 祭品： 牺牲指祭祀用的纯色体全的牲畜；三牲指牛、羊、猪；太牢是牛、羊、猪各一头，少牢是羊、猪各一头；玉帛（玉器、丝织品）也是祭品。
  6. 祭祀的仪式：
    • 衅（xìn）：杀牲取血涂在新做成的器物上举行祭祀。新钟铸成叫衅钟；出征前涂在战鼓上叫衅鼓。
    • 斋戒：祭祀或进行重大活动前，沐浴更衣，不饮酒不食荤，洁净身心，表示虔诚。
    • 告庙：天子或诸侯遇出巡、战争等重大事件，祭告祖庙（如《五代史伶官传序》「以一少牢告庙」）。
    • 祖：出行前祭祀路神，引申为饯行、送别。
    • 雩（yú）：求雨的祭祀，伴以乐舞，所以叫舞雩；舞雩是鲁国求雨的坛。
    • 血食： 享受祭祀（古代杀牲取血以祭，称血食）；国家灭亡、祭祀断绝，叫不再血食。

丧葬：死、殓、葬、祭

  1. 死亡的称谓要看身份。 依《礼记·曲礼》：「天子死曰崩，诸侯曰薨，大夫曰卒，士曰不禄，庶人曰死。」此外还有委婉说法：见背（尊长去世）、不幸（教材《苏武传》「太夫人已不幸」）、晏驾（帝王去世）、捐馆、弃世等。
  2. 居丧礼俗： 亲人去世后要服丧、守孝；席薪枕块是居丧时睡在柴草上、枕土块，表示悲哀；在墓旁筑庐守墓叫庐墓；官员遭父母丧要解职守制（丁忧）。
  3. 入殓与安葬： 依次有入殓（小殓、大殓）、停灵（殡）、下葬。棺外还有椁，帝王的坟墓称陵；夫妻同葬一处叫合葬；随葬叫陪葬，用人殉葬叫殉葬。
  4. 吊唁与祭奠： 前往吊丧的钱物叫赙；祭奠时烧纸钱、献酒食叫奠、荐。

读祭祀丧葬材料的提醒：

  • 看到「牛、羊、猪」先辨「太牢」还是「少牢」；看到「衅」先想「涂血」；看到「封」「禅」先想一天一地。
  • 「崩、薨、卒、不禄」是身份等级，不能混用；但史书、传记里用词并不一定严格，高考多以《礼记》的等级说法为准。
  • 祭祀相关的「庙」多是祖庙，与今天的寺庙不同；「庙堂」则借指朝廷。

3　教材例子

词 出处 说明
告庙、少牢、太庙 《五代史伶官传序》 「遣从事以一少牢告庙」：教材注少牢是羊、猪各一头，太牢是牛、羊、猪各一头，告庙是遇重大事件祭告祖庙；「入于太庙，还矢先王，而告以成功」：太庙是天子祖庙，写庄宗大胜后祭告祖先
宗庙、会同 《子路、曾皙、冉有、公西华侍坐》 「宗庙之事，如会同」：教材注宗庙是天子、诸侯供奉祖宗牌位的处所，宗庙之事指诸侯祭祀祖先，是古代国家重要政事
舞雩 《子路、曾皙、冉有、公西华侍坐》 「风乎舞雩」：教材注舞雩是鲁国求雨的坛，雩是求雨的祭祀仪式，伴以乐舞
七庙 《过秦论》 「一夫作难而七庙隳」：教材注「宗庙毁灭，就是国家灭亡的意思」，七庙代指王朝
衅钟 《齐桓晋文之事》 「将以衅钟」：教材注「古代新钟铸成，宰杀牲口，取血涂钟行祭」
见背、不幸 《陈情表》《苏武传》 「慈父见背」：教材注「弃我而去，指尊长去世」；《苏武传》「太夫人已不幸」：不幸是对去世的委婉说法
送葬、阳陵 《苏武传》 「陵送葬至阳陵」：李陵告诉苏武，其母去世时他送葬到阳陵，说明古人重视丧葬
合葬 《孔雀东南飞并序》 「两家求合葬，合葬华山傍」：焦、刘两家将二人合葬，「东西植松柏，左右种梧桐」是墓旁种树的习俗
祭祀、福礼、祭品 《祝福》 「祝福」是鲁镇年终的大典；「四叔家里最重大的事件是祭祀」：祭祀中分配酒杯、筷子的事，寡妇不许沾手，反映了祭祀礼俗对人的束缚
岱祠 《登泰山记》 「亭西有岱祠」：教材注岱祠是东岳大帝庙，泰山是古代帝王封禅、祭祀之地

4　易混辨析

  • ✗ 「封」是祭地，「禅」是祭天。→ ✓ 封是在泰山顶上祭天，禅是在泰山脚下梁父山上祭地。
  • ✗ 太牢用羊、猪各一头，少牢用牛、猪各一头。→ ✓ 太牢是牛、羊、猪各一头；少牢是羊、猪各一头。
  • ✗ 衅鼓是敲鼓助威。→ ✓ 衅鼓是杀牲（或杀人）取血涂在鼓上举行祭祀。
  • ✗ 庙社就是庙里的神社。→ ✓ 庙指宗庙，社指社稷，庙社借指国家朝廷。
  • ✗ 天子、诸侯、大夫、士、庶人都可设宗庙。→ ✓ 按古制，天子七庙、诸侯五庙、大夫三庙、士一庙，庶人不设庙。
  • ✗ 七庙是七座寺庙。→ ✓ 七庙是天子供奉七代祖先的宗庙，借指王朝、国家。
  • ✗ 「崩」「薨」「卒」是同一个意思，可以互换。→ ✓ 天子崩，诸侯薨，大夫卒，士不禄，庶人死，按身份区分。
  • ✗ 「舞」是求雨的祭祀仪式。→ ✓ 「雩」才是求雨的祭祀；因为伴以乐舞，所以叫「舞雩」。
  • ✗ 血食指吃血制的食品。→ ✓ 血食指享受祭祀，因古代杀牲取血以祭得名；「不血食」指没有后人祭祀。
  • ✗ 「席薪枕块」是贫穷时的睡法。→ ✓ 是居丧时的礼俗，睡柴草、枕土块，表示悲哀。

5　高考常见设错

设错方式 本专题的典型错项 出处
牲畜互换 「用牛、猪各一头，叫『少牢』」（应为羊、猪） 《导与练》《五代史伶官传序》课时作业
求雨仪式错位 「舞，古代求雨的一种祭祀仪式」（应为「雩」） 一轮讲义即时训练（宗法礼俗）
宗庙等级错位 「大夫、士、庶人皆可设庙，以祭先祖」（应为大夫三庙、士一庙、庶人无庙） 教材清单《子路、曾皙……》
身份错位 把「崩」用于诸侯、把「薨」用于大夫，或不分身份泛用「卒」 教辅常见
位置、方向错位 「闰某月指加在某月之前的那个月」（应为之后） 2021 年全国甲卷（真题）
古今相混 把「庙堂」「庙社」理解成寺庙、庙会 教辅常见

真题： 2021 年全国甲卷 A 项「衅鼓」、B 项「庙社」都是正确项，错在 C 项「闰月」；2023 年全国乙卷 C 项「血食」是正确项，错在 A 项实词比较；2023 年全国甲卷 A 项「席薪枕块」是正确项。

解题抓手： ① 把祭祀名词归到「祭什么」（天、地、祖先、器物、路神）；② 记住牲畜、等级、身份的数量对应；③ 遇到「崩、薨、卒、不禄」先看被称呼者的身份。

真题 2023 年全国甲卷 · 文言文阅读第 11 题

2.下列对文中加点的词语及相关内容的解说，不正确的一项是

  1. A.席薪枕块，文中指居丧时睡在柴草上，枕在土块上，以表示悲伤哀苦之意。
  2. B.何怨，怨恨什么。“多歧路，今安在”中“安在”表示在哪里，两者结构相同。
  3. C.蔽，有涵盖、概括之义。文中“一言以蔽之”意思是用一句话来概括《诗经》。
  4. D.逆，意为揣度、预料。与《送东阳马生序》中“寓逆旅”的“逆”意义相同。
查看答案与解析

答案

D

解析

本题考查学生理解文言实词在文中的意义和用法，了解并掌握常见的文学文化常识的能力。A项，正确。B项，正确。“何怨”是宾语前置的用法，应为“怨何”。“安在”也是宾语前置，应为“在安”；“多歧路，今安在”句意为“歧路纷杂，真正的大道究竟在哪边”。二者的结构是相同的。C项，正确。D项，错误。《送东阳马生序》中“寓逆旅”的意思是“寄居在迎接客人的旅馆里”，“逆”的意思是“迎接”，和文中的“逆”意思不同。故选D。

真题 2023 年全国乙卷 · 文言文阅读第 11 题

3.下列对文中加点的词语及相关内容的解说，不正确的一项是

  1. A.穷，指困窘、困厄，与《送东阳马生序》中“穷冬烈风”的“穷”意思相同。
  2. B.出入，表示“大约”，与《愚公移山》中“出入之迂也”的“出入”意思不同。
  3. C.血食，指受享祭品，古代祭祀时宰杀牛、羊等做祭品，取血以祭，称为血食。
  4. D.绝世，指断绝了诸侯的世系传承，与成语“绝世无双”的“绝世”意思不同。
查看答案与解析

答案

A

解析

本题考查学生理解文言词语意思以及识记文学文化常识的能力。A项，“意思相同”错误。“穷冬烈风”的“穷”意思是“深”，“穷冬”即“深冬”“隆冬”。句意：现在困窘逃亡，路过曹国。/隆冬时节，刮着猛烈的寒风。B项，正确。“出入之迂也”的“出入”，出来进去。句意：大约十年了。/出来进去都要绕道。C项，正确。D项，正确。“绝世无双”的“绝世”，冠绝当代。句意：这就是断绝了诸侯的世系传承的原因。/姿才超众，天下无与伦比。故选A。

阅读材料

材料一： 古者学士之于六艺，射能弧矢之事矣，又当善其揖让之节。御能车马之事矣，又当善其驱驰之节。书非能肆笔而已，又当辨其体而皆通其意。数非能布策而已，又当知其用而各尽其法。而五礼之威仪，至于三千，六乐之节文可谓微且多矣。噫！何其烦且劳如是！然古之学者必能此，亦可谓难矣。 然习其射御于礼，习其干戈于乐，则少于学，长于朝，其于武备固修矣。其于家有塾，于党有庠，于乡有序，于国有学，于教有师，于视听言动有其容，于衣冠饮食有其度，几杖有铭，盘杆有戒。在舆有和鸾之声，行步有佩玉之音，燕处有《雅》《颂》之乐。而非其故，琴瑟未尝去于前也。盖其出入进退，俯仰左右，接于耳目，达于其心者，所以养之至如此其详且密也。 孔子曰：“兴于《诗》，立于《礼》，成于《乐》。”盖乐者，所以感人之心而使之化，故曰“成于《乐》”。昔舜命夔典乐，教胄子，曰：“直而温，宽而栗，刚而无虐，简而无傲。”则乐者非独去邪，又所以救其性之偏而纳之中也。故和鸾、佩玉、《雅》《颂》琴瑟之音，非其故不去于前，岂虚也哉！ (节选自曾巩《相国寺维摩院听琴序》) 材料二： 予尝有幽忧之疾，退而闲居，不能治也。既而学琴于友人受宫声数引久而乐之不知疾之在其体也。 夫琴之为技小矣，及其至也，大者为宫，细者为羽，操弦骤作，忽然变之，急者凄然以促，缓者舒然以和，如崩崖裂石、高山出泉，而风雨夜至也。如怨夫寡妇之叹息，雌雄雍雍之相鸣也。其忧深思远，则舜与文王、孔子之遗音也；悲愁感愤，则伯奇孤子、屈原忠臣之所叹也。喜怒哀乐，动人必深。其能听之以耳，应之以手，取其和者，道其堙郁，写其忧思，则感人之际，亦有至者焉。 (节选自欧阳修《送杨置》)

4.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  1. A.布策，即布列算筹。策，是我国最早的计算工具，与《归去来兮辞并序》“策扶老以流憩”中的“策”意思不同。
  2. B.五礼，古代的五种礼制，文中指古代汉族礼仪总称，即吉礼、凶礼、军礼、宾礼、嘉礼。
  3. C.庠序，古代的地方学校，后泛指学校，与《齐桓晋文之事》“谨庠序之教”中的“庠序”意思相同。
  4. D.度，在本文指“标准、限度”，与《谏太宗十思疏》“乐盘游则思三驱以为度”中的“度”意思不同。

5.下列对词语相关内容的解说，不正确的一项是

  1. A.会同，古代诸侯朝见天子的通称。会，诸侯在非规定时间朝见天子。同，诸侯一起朝见天子。(必修下册《子路、曾皙、冉有、公西华侍坐》)
  2. B.行宫，古代帝王出行时临时居住的地方，可能由其他建筑改造而成，也指帝王出京后临时寓居的官署或住宅。(必修上册《登泰山记》)
  3. C.衅钟，古代新钟铸成，宰杀牲口，取血涂钟行祭，叫作“衅钟”。(必修下册《齐桓晋文之事》)

9　速记清单

  • 五礼：吉（祭祀）、凶（丧葬）、军、宾、嘉（冠婚）。
  • 封（泰山顶祭天）、禅（梁父山祭地）；秦始皇第一个大规模封禅。
  • 社（土神）、稷（谷神）→ 国家；宗庙（祖先）、七庙、庙社→ 国家、朝廷。
  • 古制：天子七庙、诸侯五庙、大夫三庙、士一庙、庶人无庙；七庙左三昭右三穆。
  • 太牢＝牛羊猪；少牢＝羊猪；牺牲＝纯色体全的牲畜。
  • 衅＝取血涂器物：衅钟、衅鼓；雩＝求雨祭祀；祖＝饯行祭路神；血食＝享受祭祀。
  • 斋戒：沐浴更衣，不饮酒不食荤；告庙：遇大事祭告祖庙。
  • 崩（天子）、薨（诸侯）、卒（大夫）、不禄（士）、死（庶人）；见背、不幸、晏驾为委婉说法。
  • 居丧：席薪枕块、庐墓；丧服五服见「宗法、亲属与丧服」；合葬、陪葬、殉葬；赙助丧、奠祭奠。
  • 口诀：封天禅地看泰山，社稷宗庙国家在；太牢三牲少牢二，衅钟衅鼓涂鲜血。
教师备注 · 待裁定点（3）

J01　宗庙等级：天子七庙、诸侯五庙、大夫三庙、士一庙、庶人不设庙，是《礼记·王制》等古礼的说法，各朝实际执行不同。本页作为「古制」写，不当作历代通行的制度。题库教材清单题（《子路、曾皙……》）据此设错，答案为 ×。

J02　「太牢」「少牢」：教材《五代史伶官传序》注：太牢＝牛、羊、猪各一头，少牢＝羊、猪各一头。题库教材清单题中「一般天子祭祀社稷用太牢，诸侯祭祀用少牢」按 √ 处理，本页不展开这种等级对应，只写牲的组成。

J03　封禅的第一人：旧资料与题库教材清单都写「第一个举行大规模封禅仪式的帝王是秦始皇」，本页照此写；「封」是祭天、「禅」是祭地，不能颠倒。
