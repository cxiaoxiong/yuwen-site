1　知识梳理

一句话： 文体题要抓三点：这类文章给谁看（皇帝、朋友、公众）、写来做什么（陈情、劝谏、记事、议论）、有什么形式特点（骈偶、押韵、分条）。

一、上书言事类（臣下对君主）：

  • 书： 战国时期臣下上书统称为「书」，如李斯《谏逐客书》；「书」也用于朋友、亲人之间的往来信件（如《答司马谏议书》《与妻书》）。
  • 章、奏、表、议： 汉代把上书分为四类。章用于谢恩；奏用于陈事、弹劾；表用于陈情言事；议用于议论政事、提出不同意见。
  • 表： 特指臣下向帝王陈情言事的文体，如李密《陈情表》。
  • 疏： 分条陈述自己的意见，如魏征《谏太宗十思疏》。
  • 奏议： 臣子向皇帝上书言事、条议是非的文字的统称，包括奏、议、疏、表等。

二、书信与序跋类（朋友、亲人、读者）：

  • 书（书信）： 写给朋友、亲人，如《答司马谏议书》（论辩性书信）、《与妻书》（家书）。
  • 序： 常用于著作的前言，或题赠、送别。书序是为著作作的前言，如《兰亭集序》（为《兰亭集》诗作的序）、《五代史伶官传序》（史传之序，兼有议论）；赠序用于赠别、送行。并序表示诗、辞前另有序言，如《归去来兮辞并序》《孔雀东南飞并序》《琵琶行并序》《燕歌行并序》。
  • 跋： 写在书籍、字画后面的文字。

三、记叙类：

  • 记： 以记叙为主，可叙事、状物、写景、记人，来表达作者的感情和见解。如《登泰山记》《石钟山记》（游记）。
  • 志： 记述事或人的文章、著作，如地方志、墓志、《三国志》；也有「记」的意思，如《项脊轩志》。
  • 传： 记述人物生平的文体：史书中的「列传」（《屈原列传》《苏武传》）；也有文人写的寓言化传记（《种树郭橐驼传》）。注意：「传」还有一义，是解释经书的著作（见「经史子集与诸子百家」）。

四、议论类：

  • 论： 议论性的文体，议论当前政治问题、向朝廷进言献策，也是宋代以来常用的科举文体，如《过秦论》《六国论》（史论）。
  • 说： 陈述看法、阐发道理的文体，如《师说》。
  • 其他议论文： 教材《劝学》是先秦诸子的议论说理文，不属于「论」「说」这类后世文体名。

五、韵文类：

  • 赋： 讲究辞采、体物铺陈，介于诗歌和散文之间；句式以四六为主，追求骈偶，声律谐协，文辞上讲究藻饰和用典。萌生于战国，兴盛于汉唐；在古文运动的影响下出现了清新流畅的文赋，代表作是杜牧《阿房宫赋》、苏轼《赤壁赋》。
  • 辞： 介于散文与诗歌之间的一种文体，起源于战国的楚国，故称楚辞；汉代常把辞与赋合称「辞赋」，但辞重言情，赋重铺陈。如陶渊明《归去来兮辞》。
  • 《楚辞》与《离骚》： 《楚辞》是刘向整理的屈原、宋玉等人作品的汇编，是我国文学史上第一部浪漫主义诗歌总集；《离骚》是屈原的代表作，是政治抒情诗，「离骚」意为「离忧」（司马迁）。
  • 铭： 刻在器物或碑石上，用来称颂功德、自警或纪事，多为韵文。

六、官方文书类（了解）：

  • 诏、令、策、制： 君主发布的命令。秦以前上下都可用「诏」，秦始皇之后专为皇帝所用。
  • 檄： 古代官府用来征召、晓谕、声讨的文书，传檄即传布檄文（2021 年新高考Ⅱ卷）。
  • 露布： 不封缄、公开宣布的文书。

七、诗体（常见标题字）：

  • 古体诗： 唐人把唐以前的乐府民歌、文人诗以及唐以后文人仿照这种体式写的诗，统称为古体诗；歌、行、吟是古诗的一种体式，形式活泼，不拘一格（《琵琶行》《燕歌行》《梦游天姥吟留别》）。
  • 留别： 临行前留下诗文向朋友话别。
  • 词牌： 词调的名称，如《声声慢》《念奴娇》，与词的题目不同。
  • 杂剧： 元代戏曲，如《窦娥冤》。

八、文体演变的一条线： 先秦诸子散文 → 汉赋、汉乐府 → 六朝骈文 → 唐宋古文运动（韩愈、柳宗元倡导，反对六朝以来的骈俪文，主张恢复先秦两汉散文的传统）→ 明清小品、小说。

4　易混辨析

  • ✗ 「表」是下级向上级陈述的一般文体。→ ✓ 表特指臣下向帝王陈情言事的文体。
  • ✗ 疏和表完全相同。→ ✓ 疏是分条陈述意见，表是陈述某种意见或事情，都属奏议，侧重不同。
  • ✗ 战国时臣下上书称「表」。→ ✓ 战国时统称为「书」，汉代才分章、奏、表、议。
  • ✗ 「书」只指书信。→ ✓ 「书」还可指上书（《谏逐客书》）。
  • ✗ 序都是为别人的书作的前言。→ ✓ 序有书序（前言）和赠序（送别题赠）；《兰亭集序》是为诗集所作的序，不是朋友之间唱和的赠言。
  • ✗ 「传」就是人物传记。→ ✓ 「传」也指解释经书的著作（「六艺经传」）。
  • ✗ 「记」和「志」毫无关系。→ ✓ 「志」有「记」的意思，《项脊轩志》属记叙类。
  • ✗ 「论」和「说」都是议论，没有区别。→ ✓ 论多议论政治得失、史事；说重在阐发道理，如《师说》。
  • ✗ 「赋」和「辞」完全等同。→ ✓ 辞重言情，赋重铺陈，汉代合称辞赋。
  • ✗ 《阿房宫赋》是骈赋，不是文赋。→ ✓ 教材清单题指出杜牧《阿房宫赋》是文赋的代表。
  • ✗ 《离骚》是政治叙事诗。→ ✓ 《离骚》是政治抒情诗。
  • ✗ 「吟」「行」「歌」是同一个诗体的不同写法，没有区别。→ ✓ 都是古体诗的体式，形式活泼、不拘一格，相似但不完全等同。
  • ✗ 「留别」是抒发惜别之情。→ ✓ 「留别」是临行前留下诗文向朋友话别；《梦游天姥吟留别》主要写梦游与态度，并未表达惜别之感（《导与练》该题解析）。

5　高考常见设错

设错方式 本专题的典型错项 出处
范围扩大 「表，就是『奏表』……是古代下级向上级陈情言事的一种特殊文体」 教材清单《陈情表》
体裁错位 「《离骚》……是一篇宏伟壮丽的政治叙事诗」（应为抒情诗） 教材清单《离骚》
概念偷换 「《兰亭集序》是朋友之间互相唱和的赠言」（应为书序） 《导与练》选必中册课时作业
概念混同 把「传」当人物传记，忽略「解释经书」的义项 《导与练》必修上册课时作业
体裁混同 把「辞」的特点说成铺陈、把「赋」的特点说成言情（应为辞重言情、赋重铺陈） 教辅常见；教材清单《归去来兮辞并序》辞题（表述正确，用来对照）
义项错配 「留别」理解为「抒发惜别之感」 《导与练》必修上册课时作业

真题： 2021 年新高考Ⅱ卷 D 项「传檄，檄指檄文，是古代官府用以征召、晓谕、声讨的文书，传檄即传布檄文」是正确项。

解题抓手： ① 上书类先分「书、章、奏、表、议、疏」；② 序分「书序」「赠序」；③ 「传」「记」「志」按「人物 / 事物」判断；④ 赋、辞分「铺陈」与「言情」。

6　真题 / 典型题

高考题型：选出「不正确的一项」。「仿真」是教辅仿真卷，不是真题。

9　速记清单

  • 战国上书称「书」；汉代上书分章、奏、表、议；奏议包括奏、议、疏、表。
  • 表：臣下向帝王陈情言事（《陈情表》）；疏：分条陈述意见（《谏太宗十思疏》）。
  • 序：书序（《兰亭集序》）、赠序；并序：辞或诗前有序。
  • 记：游记、记事（《登泰山记》）；志：与记相通（《项脊轩志》）；传：人物传记或解释经书。
  • 论：史论、政论（《过秦论》《六国论》）；说：阐发道理（《师说》）。
  • 赋：铺陈辞采、骈偶声律（文赋：《阿房宫赋》《赤壁赋》）；辞：重言情；《楚辞》＝屈原、宋玉作品汇编。
  • 《离骚》＝政治抒情诗，屈原代表作。
  • 诗体：歌、行、吟为古体诗体式；留别＝临行留赠；词牌不是题目。
  • 唐宋古文运动：韩愈、柳宗元倡导，反对骈文。
  • 口诀：表疏书议向上陈，序记志传各不同；论说讲理赋辞铺，古文运动韩柳兴。
教师备注 · 待裁定点（5）

WT01　表：题库教材清单题答案指出，「表」特指臣下向帝王陈情言事的文体，不是「下级向上级」的一般文体。本页照此写，并与「疏」「书」分开：战国时统称「书」，汉代分章、奏、表、议四类。

WT02　疏与表的区分：教材清单题写「疏是分条陈述自己的意见，如《谏太宗十思疏》；表是陈述某种意见或事情，如《出师表》」，本页据此写；不写「疏比表更重要」等题库没有的说法。《出师表》不在现行五册教材中，仅作对比例子。

WT03　《离骚》：题库教材清单题答案指出《离骚》是政治抒情诗（不是叙事诗）。本页照此写。

WT04　赋与辞：题库教材清单题写「辞重言情，赋重铺陈」，并说明汉代常把辞与赋合称辞赋。《赤壁赋》《阿房宫赋》属「文赋」（在古文运动影响下出现的清新流畅的赋体）。本页照此写，不展开赋体的完整分类。

WT05　「志」与「记」：教材清单题答案：志既是记述事或人的文章（地方志、墓志），也有「记」的意思，如《项脊轩志》。本页把「志」放在「记叙类」，并说明「志」「记」有相通处。
