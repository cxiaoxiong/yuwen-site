1　知识梳理

先看题：刑罚题有两类。 ① 刑名题：黥是什么、大辟是什么、弃市是什么；② 制度题：谁审案、谁复核、谁牵连（连坐、族）。

一、两套五刑

  1. 先秦五刑（通行说法，肉刑为主）： 墨（也叫黥）、劓、刖（也写作剕）、宫、大辟。各书对五刑的说法不完全一致，这里取高中阶段常用的一种。
    • 墨（黥）： 用刀刺刻犯人额面，再涂上墨，用来惩治犯轻罪的人。
    • 劓（yì）： 割鼻。
    • 刖（yuè）： 砍去脚或脚趾。
    • **膑（bìn）**是另一种酷刑，剔去膝盖骨（孙膑因此得名），不与「刖」当作同一个词，也不一定列在上面的「五刑」里。
    • 宫： 破坏生殖机能的酷刑（宫刑）。
    • 大辟： 砍头，也是死刑的通称。
    • 另有髡（kūn）：剃去犯人头发的刑罚，属轻刑。
  2. 隋唐以后五刑： 笞、杖、徒、流、死，由轻到重。
    • 笞（chī）： 用荆条、竹板抽打臀腿。杖： 用大板责打，比笞重。
    • 徒： 服劳役，有期限。流： 流放远方。死： 处死，分绞、斩等。
    • 汉文帝、景帝以后，肉刑逐渐废除，笞、杖等刑逐步替代；后来五刑成了「笞杖徒流死」。

二、死刑的种类（常见）：

  • 斩： 斩首；腰斩： 拦腰斩断；弃市： 在闹市执行死刑并陈尸示众；枭首： 斩首悬挂示众。
  • 车裂： 以车分裂人体，也叫「辕裂」，俗称「五马分尸」；汤镬（huò）： 投入沸水中煮死（「臣请就汤镬」）。
  • 凌迟： 分割身体至死，是最重的死刑，五代、宋以后逐渐入法通行。
  • 绞： 用绳勒死；赐死： 皇帝令犯人自尽。
  • 「极刑」与「大辟」： 按 2021 年全国乙卷的解析口径，「极刑」即死刑（抵极刑＝判处死刑）；「大辟」曾作为死刑的通称。后世个别文献里「极刑」也可能特指凌迟等最重的刑罚，做题以高考口径为准。

三、株连： 一人犯罪，亲属连带受刑。

  • 族（族诛、夷族）： 一人犯死罪而牵连其父母妻子等整个家族被杀。教材《阿房宫赋》「族秦者秦也」的「族」，教材注为灭族。
  • 连坐（相坐）： 一人犯罪，与犯罪者有一定关系的人连带受刑；又称随坐、从坐、缘坐。商鞅变法时立相坐之法，起源更早。
  • 夷三族、诛九族： 株连亲族的说法，范围各书说法不同。教材《苏武传》「大臣亡罪夷灭者数十家」的「夷灭」注为「诛灭，这里指全家杀尽」。

四、其他刑罚与处置：

  • 刺配： 脸上刺字（黥），发配到远地充军（教材《林教头风雪山神庙》注）。
  • 充军、流放： 发配到边远地区；谪：贬官流放（与官职变动相关）。
  • 系、囚、下狱： 拘押；下吏：交付狱官处置（《过秦论》「委命下吏」）；保宫：汉代囚禁犯罪大臣及其眷属的处所。
  • 赎： 交财物抵罪（折罪、抵罪）；赦： 赦免；大赦： 普遍赦免。
  • 追比： 旧时地方官限期交税、交差，过期以杖责、监禁等方式追逼（教材《促织》注）。

五、司法机构： 见下表，主线是：廷尉 → 大理寺 → 刑部 + 三法司。

  • 廷尉： 秦置，掌刑狱，九卿之一；汉承秦制，后改称大理。
  • 大理寺： 北齐以后的最高审判机关；大理丞是其属官。（2021 年全国乙卷「大理丞，大理丞是大理寺的重要官员，大理寺是我国古代掌管刑狱的官署」是正确项。）
  • 刑部： 六部之一，主管刑法、狱讼。
  • 御史台（都察院）： 监察机构，纠察、弹劾，参与重大案件的审理。
  • 三法司： 作为固定称谓，主要指明清的刑部、大理寺、都察院；唐代遇重大案件有刑部、大理寺、御史台「三司会审」的做法，不要与明清的「三法司」等同。
  • 地方： 郡守、县令兼理司法；狱官（狱吏）负责监狱和案件。

六、审判用语（了解）： 论（判罪）、坐（因……获罪）、劾（检举、弹劾）、鞫（审讯）、系（拘押）、诛（杀）、赦（赦免）、抵罪（按罪抵偿）。

3　教材例子

词 出处 说明
族 《阿房宫赋》 「族秦者秦也，非天下也」：教材注「族，灭族」；族指一人犯死罪牵连全家被杀，此处用作动词，意为灭族
夷灭、系保宫 《苏武传》 「大臣亡罪夷灭者数十家」：教材注夷灭是诛灭，这里指全家杀尽；「老母系保宫」：教材注保宫是汉代囚禁犯罪大臣及其眷属的处所，可见株连范围之广
下吏 《过秦论》 「委命下吏」：教材注下吏是下级官吏，这里指狱官，说明百越之君被囚禁、听凭处置
刺配 《林教头风雪山神庙》 教材注刺配是脸上刺字，发往远地充军；刺是古时的肉刑，在罪犯额面或肌肤上刺字并染墨；刺配沿用了黥刺的做法，再加发配，并不等同于先秦的墨刑
追比、扑责 《促织》 「宰严限追比」：教材注追比是限期追逼，过期以杖责、监禁；「扑责」是杖击的责罚；成名「杖至百，两股间脓血流离」是地方官追比时的责打，不能简单等同于法定的「杖」刑
罪愆 《窦娥冤（节选）》 「念窦娥葫芦提当罪愆」：教材注窦娥被官府糊里糊涂判了死罪；剧中有监斩官、刽子手，展示斩刑执行的场景
教材外的常见例子
  • 《史记·廉颇蔺相如列传》：「臣请就汤镬」——汤镬是把人投入沸水中煮死的酷刑。
  • 《报任安书》：「孙子膑脚，而论兵法」——「膑脚」指膑刑；司马迁自己受的是宫刑。
  • 《史记·商君列传》：商鞅在秦国推行什伍连坐之法——连坐制度的典型例子。

4　易混辨析

  • ✗ 五刑只有一套：笞杖徒流死。→ ✓ 有先秦和隋唐以后两套：先秦（通行说法）为墨（黥）、劓、刖（剕）、宫、大辟；隋唐以后为笞、杖、徒、流、死。
  • ✗ 大辟是流放。→ ✓ 大辟是砍头，古代死刑的通称。
  • ✗ 「抵极刑」是死刑外加暴尸示众。→ ✓ 极刑即死刑，「抵」是达到；尸体示众叫弃市。
  • ✗ 弃市是流放边地。→ ✓ 弃市是在闹市处死并陈尸示众。
  • ✗ 黥、墨刑和宫刑是同一种刑罚。→ ✓ 黥（墨）是刺面涂墨；宫是破坏生殖机能。
  • ✗ 刖和膑是割鼻。→ ✓ 割鼻是劓；刖是砍脚，膑是剔去膝盖骨。
  • ✗ 笞和杖完全相同。→ ✓ 都是用棍板责打，笞用荆条竹板，较轻；杖用大板，较重。
  • ✗ 「族」只是一个姓氏。→ ✓ 在刑罚中「族」指灭族，一人犯死罪牵连全家被杀。
  • ✗ 连坐和族是一回事。→ ✓ 连坐（相坐）是与犯罪者有关系的人连带受刑，不一定处死；族是株连全家处死。
  • ✗ 廷尉和大理寺是两个完全不同的机构。→ ✓ 廷尉是秦汉掌刑狱之官，汉后改称大理；北齐以后称大理寺。
  • ✗ 御史台负责审判案件。→ ✓ 御史台是监察机构，负责纠察、弹劾；审判由廷尉、大理寺、刑部承担。
  • ✗ 三法司是历代不变的一组机构。→ ✓ 「三法司」固定指明清的刑部、大理寺、都察院；唐代是「三司会审」，成员和名称不同。

5　高考常见设错

设错方式 本专题的典型错项 出处
概念扩大 「抵极刑指犯人受到死刑外加上尸体示众的极端刑罚」（极刑即死刑；尸体示众叫弃市） 2021 年全国乙卷（真题，本项是错项）
概念偷换 把连坐说成一律处死，把「族」说成只是罚款或降职 常见误判（本站归纳）
程度错位 把笞、杖、徒、流、死的次序或含义颠倒 常见误判（本站归纳）
官署混淆 把大理寺、御史台、刑部的职责互换 常见误判（本站归纳）
古今相混 把「族」理解为家族，把「系」理解为系统 常见误判（本站归纳）

真题： 2021 年全国乙卷 B 项设错，D 项「大理丞」是正确项。

解题抓手： ① 死刑相关词分「名称」（斩、弃市、车裂）和「性质」（极刑＝死刑）；② 株连类先区分「连坐（连带受刑）」与「族（灭族）」；③ 机构类先分「审判（廷尉、大理寺）」「司法行政（刑部）」「监察（御史台、都察院）」。

教师备注 · 待裁定点（4）

XF01　两套五刑：旧资料 A 只列了髡、黥、刖、膑、宫、大辟、汤镬、车裂、刺配、笞杖等具体刑名，没有明写「先秦五刑」与「隋唐五刑」的分套。本页按通行说法补写：先秦五刑＝墨（黥）、劓、刖（剕）、宫、大辟（膑另列，不与刖混同）；隋唐以后五刑＝笞、杖、徒、流、死。这一分套是本页整理，请教师复核。

XF02　极刑与弃市：2021 年全国乙卷题的解析指出「极刑即死刑」，「尸体示众叫弃市」。本页照此写：抵极刑＝判处死刑，不一定含暴尸；弃市是在闹市处死并陈尸示众。「极刑」在后世有时特指凌迟，正文已提示以高考口径为准。

XF03　夷三族、诛九族：三族、九族的范围各书说法不同，教材《苏武传》「夷灭」注为「诛灭，这里指全家杀尽」。本页只写「株连亲族」，不列具体范围。

XF04　三法司：作为固定称谓以明清的刑部、大理寺、都察院为准；唐代只写「三司会审」。注意「中央官制与三省六部」一页仍写「隋唐以后……合称三法司」，「中央官制与三省六部」页已同步改为明清称谓、唐代三司会审。
