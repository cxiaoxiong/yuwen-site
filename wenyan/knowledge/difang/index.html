1　知识梳理

读地方官名的办法：先看辖区，再看朝代。 「太守」管郡，「知县」管县，「知府」管府；同一个「州」字，在汉代、唐代、明清指的层级并不一样。

一条主线看地方行政区划的演变：

  1. 先秦：分封。 诸侯国、卿大夫的封邑；春秋以前县比郡大，战国以后郡比县大，郡逐渐成为县的上级。
  2. 秦：郡县制。 分天下为三十六郡（后增至四十余），郡下设县；郡长官称郡守，县长官称令（大县）或长（小县）。
  3. 汉：郡国并行。 郡由朝廷直辖，国封给诸侯王、列侯；汉代郡守称太守。汉武帝分天下为十三州部，每州派刺史巡视，州在当时基本是监察区；东汉末州牧、刺史掌握一州军政，州成为郡之上的一级政区。
  4. 隋唐：州县为主。 隋废郡，以州统县；唐前期设「道」作监察区，唐天宝年间曾一度改州为郡、刺史称太守，后来恢复；唐后期在重镇设节度使，兼管军政、财政，属官有判官、推官、掌书记。
  5. 宋： 地方有路、府、州（军、监）、县；朝廷派文官「知」某州、某府、某县的事务，称知州、知府、知县；又设通判，辅佐并监督知州。
  6. 元： 设行中书省（行省），是「省」成为地方行政区的开始。
  7. 明清： 明改行省为承宣布政使司，习惯仍称「省」；省下有府、州、县。清代省的长官是巡抚（一省），总督总管一省或数省军政；知府管府，知州管州，知县管县。

四个提醒：

  • 州≠今天的州： 汉代的州偏重监察；唐代的州是一级行政区，长官刺史；明清的州有直隶州、散州之分，级别不同。
  • 郡、州、府常常是同一地方的不同名称： 文言文里作者常用古称（如宋人称「巴陵郡」，实际是岳州）；要看具体语境，不要按一个朝代的制度硬套。
  • 官名有正式名称，也有习称： 明清称知府为「太守」、称知县为「县令」「邑宰」，都是习惯的雅称。
  • 「知」是主持之义： 宋代「知县」是主持一县事务，与今天的「知」（知道）无关。

4　易混辨析

  • ✗ 州、郡、县是一回事，只是叫法不同。→ ✓ 郡、州、府是县之上的政区，层级和辖区随朝代变化；县是基层政区。
  • ✗ 春秋战国时期都是郡比县大。→ ✓ 春秋以前县大于郡；战国以后郡才大于县，县隶属于郡。
  • ✗ 「郡县」和「郡县制」没有区别。→ ✓ 「郡县」是政区名称；「郡县制」是继分封制之后出现的两级地方管理制度。
  • ✗ 汉代刺史就是一州的行政长官。→ ✓ 汉代刺史是巡视州部的监察官；东汉末以后才掌握一州军政；隋唐才是州的长官。
  • ✗ 刺史、太守、知州都是一个级别。→ ✓ 太守管郡；刺史管州（汉为监察官）；知州、知府是宋以后的称呼，不能拿来直接对号。
  • ✗ 大县的长官称「长」，小县的长官称「令」。→ ✓ 大县称「令」，小县称「长」。
  • ✗ 「从事」都是指汉代刺史的属吏。→ ✓ 「从事」汉代确指刺史属官，但后世也泛指一般属官，要看语境。
  • ✗ 唐代的司马是一州的实权长官。→ ✓ 唐代州司马是刺史之佐，实为闲职。
  • ✗ 节度使是宋代设立的地方民政长官。→ ✓ 节度使是唐代在军事重镇设立的军政长官，兼管军政财政。
  • ✗ 明清的抚军是掌管一府的官。→ ✓ 抚军是巡抚的别称，管一省。

5　高考常见设错

设错方式 本专题的典型错项 出处
大小颠倒 「大县的长官称『长』，小县的长官称『令』」 教材清单《种树郭橐驼传》
词义张冠李戴 「从事……与《五代史伶官传序》中的『从事』意思一致」（汉代专指刺史属吏，课文中指一般属官） 教材清单《五代史伶官传序》
范围扩大或错位 「山东，……指泰山以东地区」（应为崤山、函谷关以东） 一轮讲义（天文地理）即时训练
层级混同 把「郡」「州」「府」当作同一朝代的并列层级 教辅常见
概念混淆 把「郡县」与「郡县制」等同 专项对点练 23（本条表述本身正确，用来对照）
以今释古 把「宰」理解成「宰相」，把「守」理解成「防守」 教辅常见

解题抓手： ① 先看官名管什么（郡、州、县、府），再判断朝代；② 「监察」与「行政」分开：汉代刺史是监察官；③ 「令大长小」「郡大于县（战国以后）」这类数值性、层级性判断，最容易被设错。

6　真题 / 典型题

仿真 · 教辅练习 2024 年高考仿真卷 1 · 文言文阅读第 11 题（教辅仿真，非真题）

阅读材料

材料一： 答毛宪副书① [明]王守仁 昨承遣人喻以祸福利害，且令勉赴大府请谢。此非道谊深情，决不至此。感激之至，言无所容！ 但差人至龙场凌侮，此自差人挟势擅威，非大府使之也。龙场诸夷与之争斗，此自诸夷愤愠不平，亦非某使之也。然则大府固未尝辱某，某亦未尝傲大府，何所得罪而遽请谢乎？ 跪拜之礼，亦小官常分，不足以为辱，然亦不当无故而行之。不当行而行，与当行而不行，其为取辱一也。废逐小臣，所守以待死者，忠信礼义而已。又弃此而不守，祸莫大焉！凡祸福利害之说，某亦尝讲之。君子以忠信为利，礼义为福。苟忠信礼义之不存，虽禄之万钟，爵以侯王之贵，君子犹谓之祸与害；如其忠信礼义之所在，虽剖心碎首，君子利而行之，自以为福也，况于流离窜逐之微乎？ 某之居此，盖瘴疠蛊毒之与处，魑魅魍魉之与游，日有三死焉。然而居之泰然未尝以动其中者诚知生死之有命不以一朝之患而忘其终身之忧也。大府苟欲加害，而在我诚有以取之，则不可谓无憾；使吾无有以取之而横罹焉，则亦瘴疠而已尔，蛊毒而已尔，魑魅魍魉而已尔，吾岂以是而动吾心哉！ 执事之喻，虽有所不敢承，然因是而益知所以自励，不敢苟有所隳堕。则某也受教多矣，敢不顿首以谢！ (节选自《王文成公全书》) 材料二： 先生曰：“……至于‘夭寿不贰其心’，乃是教学者一心为善，不可以穷通夭寿之故，便把为善的心变动了，只去修身以俟命；见得穷通寿夭有个命在，我亦不必以此动心……此便是初学立心之始……” (节选自《传习录》②) 【注】　①毛宪副：毛伯温，时任都察院左副都御史。都察院在明代以前称为御史台，也称宪台，故称毛伯温为宪副。本文是作者在贵州龙场任驿丞时写给毛伯温的回信。②《传习录》：由王阳明的门人弟子对其语录和信件进行整理编撰而成的哲学著作。

1.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  2. B.“其为取辱一也”与“乃是教学者一心为善”两句中，“一”的意思不相同。
  3. C.“虽禄之万钟”与孟子《鱼我所欲也》中“万钟于我何加焉！”的“万钟”意思相同。
  4. D.“夭寿不贰其心”与《烛之武退秦师》中“且贰于楚”的“贰”意思不同。

答案

D

解析

阅读材料

材料一： 初平之元，董卓杀主鸩后，荡覆王室。是时四海既困中平之政兼恶卓之凶逆家家思乱人人自危。山东牧守咸以《春秋》之义言人人皆得讨贼。于是大兴义兵。名豪大侠，富室强族，飘扬云会，万里相赴。兖豫之师，战于荥阳。河内之甲，军于孟津。卓遂迁大驾，西都长安。而山东大者连郡国，中者婴城邑，小者聚阡陌，以还相吞并。会黄巾盛于海岱，山寇暴于并冀。乘胜转攻，席卷而南。乡邑望烟而奔，城郭睹尘而溃。百姓死亡，暴骨如莽。时余年五岁。上以世方扰乱，教余学射，六岁而知射。又教余骑马，八岁而能骑射矣。以时之多难，故每征，余常从。 夫文武之道，各随时而用。生于中平之季，长于戎旅之间，是以少好弓马，于今不衰，逐禽辄十里，驰射常百步。日多体健，心每不厌。后军南征，次曲蠡，尚书令荀彧奉使犒军，见余，谈论之末，彧言：“闻君善左右射，此实难能。”余曰：“埒有常径，的有常所，虽每发辄中，非至妙也。若驰平原，赴丰草，要狡兽，截轻禽，使弓不虚弯，所中必洞，斯则妙矣。”时军祭酒张京在坐，顾彧拊手曰：“善。” 余于他戏弄之事少所喜，唯弹棋略尽其巧，少为之赋。上雅好诗书文籍，虽在军旅，手不释卷。每每定省从容，常言：“人少好学则思专，长则善忘。长大而能勤学者，唯吾与袁伯业耳。”余是以少诵诗、论。及长而备历五经、四部、史、汉、诸子百家之言，靡不毕览。所著书论诗赋，凡六十篇。 (节选自《典论·自序》) 材料二： 迁生龙门，耕牧河山之阳。年十岁则诵古文。二十而南游江、淮，上会稽，探禹穴，窥九嶷，浮于沅、湘；北涉汶、泗，讲业齐、鲁之都，观孔子之遗风，乡射邹、峄；厄困鄱、薛、彭城，过梁、楚以归。于是迁仕为郎中，奉使西征巴、蜀以南，南略邛、笮、昆明，还报命。 (节选自《太史公自序》)

2.下列对材料中加点的词语及相关内容的解说，不正确的一项是

  1. A.郡国，郡和国的并称。汉兼采封建及郡县制，分天下为郡与国，后用来泛指地方行政区划。
  2. B.次，行军途中停留，与《〈论语〉十则》“多见而识之，知之次也”中的“次”含义相同。
  3. C.戏弄，指玩耍逗引，与《廉颇蔺相如列传》“传之美人，以戏弄臣”中的“戏弄”含义不同。
  4. D.略，文中指巡行，巡视，与《送东阳马生序》“略无慕艳意”中的“略”意思不同。

B

解析

A项，正确。B项，错误。行军途中停留。/次等。C项，正确。玩耍逗引。/耍笑捉弄，玩弄。D项，正确。巡行，巡视。/略微、稍微。

3.下列对词语相关内容的解说，不正确的一项是

  1. A.中国，最早指西周京畿地区，即京城、国都，后来指黄河中下游的中原地区，“中国”以外的地方则称为“四夷”。(必修下册《齐桓晋文之事》)
  2. B.八州，是指雍州以外的其他八个州。相传古代把“天下”分为九州，分别为豫州、青州、徐州、扬州、荆州、梁州、雍州、冀州、兖州。秦居雍州。(选择性必修中册《过秦论》)
  3. C.山东，战国、秦汉时指泰山以东地区；战国时除秦外，韩、赵、魏、齐、楚、燕等国都在泰山以东，故称“山东之国”。(必修下册《鸿门宴》)
  4. D.郡，是古代的行政区域，始见于春秋时期，不同朝代称谓不同。秦始皇统一六国后设立郡，汉增加郡的数量，隋唐废郡设州，明清称府。(必修下册《六国论》)
查看答案与解析

答案

C

解析

C项，“指泰山以东地区”“都在泰山以东”错误。山东，战国、秦汉时指崤山以东地区；战国时除秦外，韩、赵、魏、齐、楚、燕等国都在崤山函谷关以东，故称“山东之国”。

9　速记清单

  • 春秋以前县大于郡；战国以后郡大于县；秦行郡县制。
  • 郡：秦称郡守、汉称太守；县：大县令、小县长。
  • 汉：郡国并行；刺史巡州部（监察官）→ 东汉末州牧掌军政。
  • 隋唐：州县；州长官刺史；唐司马多闲职；唐后期重镇设节度使。
  • 宋：知州、知府、知县（朝廷派文官「知」某地）；通判辅佐并监督知州。
  • 元：行中书省（行省）；明清：布政使司习称省；巡抚管一省，总督管一省或数省。
  • 明清：知府、知州、知县；「抚军」是巡抚，「邑宰」是县令。
  • 属官：郡丞、长史、督邮；县丞、主簿、县尉；基层：亭长、里正。
  • 口诀：郡大县小要分朝代，刺史巡视太守管郡；令大长小别颠倒，抚军管省不管府。

教师备注 · 待裁定点（2）

D01　州、郡、府的层级随朝代变化很大（汉代州是监察区，东汉末渐成一级政区；隋废郡；唐天宝年间一度改州为郡；宋有府、州、军、监；明清有府、直隶州、散州）。本页只写高中阶段的大脉络，并把「监察区／行政区」「正式官名／雅称」分开写，不写成一条直线。

D02　刺史：汉代是巡视州部的监察官，隋唐是州的长官，宋以后州长官称知州，「刺史」成为习称。本页按朝代分列，不写「刺史就是某某官」。
